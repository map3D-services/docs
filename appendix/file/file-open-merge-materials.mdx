---
title: "File > Open > Merge Materials"
---

If this option is checked, as the new model file is loaded, the material data in the new file is merged with the current material data.

If this option is not checked, as the new model file is loaded, the material data in the new file will replace the current material data.

This allows you to keep your material models in separate data files then incorporate them into models as required.
