---
title: "File > Open > Merge Geometries"
---

If this option is checked, as the new model file or construction line file is loaded, the geometric data is merged with the current geometric data.

If this option is not checked, as the new model file or construction line file is loaded, the geometric data will replace/overwrite the current geometric data.

This allows you to construct your model or construction line database in small pieces and merge them as required.
