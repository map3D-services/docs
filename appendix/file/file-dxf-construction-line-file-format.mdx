---
title: "File > DXF Construction Line File Format"
---

DXF format is an AutoCAD drawing exchange file with the extension ".DXF".

This format is useful for exchanging model data with other CAD software.

Construction lines are saved as a series of AutoCAD DXF POLYLINE entities.

Construction lines can be imported as a series of AutoCAD DXF POLYLINE, LINE, 3DLINE or 3DFACE entities.
