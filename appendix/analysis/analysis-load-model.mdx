---
title: "Analysis > Load Model"
---

Loads a model from a file (INP or DXF format). Once loaded the user can use

Analysis > Go to CAD

to add or edit mining blocks and set up the Map3D analysis.

While loading the model Map3D checks for basic consistency of the modelling parameters (e.g. if a material is used, its properties must be specified in the material list).

Options:

Analysis > Options > Reunmber Analysis > Options > Collinearity
