title: "Analysis > Options > Precondition"
---

Precondition the matrix – during Map3D BEM analysis.

This option instructs Map3D to search through the matrix for unreasonably large off diagonal coefficients. These normally result from construction errors and are disabled when this option is check.

Notes:

This function must be checked before conducting the Map3D BEM analysis

#### Analysis > BEM Analysis

It is recommended that this option be used.
