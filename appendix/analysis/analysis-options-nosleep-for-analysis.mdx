---
title: "Analysis > Options > Nosleep for Analysis"
---

Controls Windows Sleep setting.

Windows "Power, sleep and battery settings" can be instructed to put your computer to sleep after a specified interval of keyboard and/or mouse inactivity. This will normally put your computer to sleep during longer Map3D analyses, and hence interrupt the analysis. When this option is checked, Map3D will not allow Windows to put the computer to sleep during a Map3D analysis.

Notes:

This function must be checked before conducting the Map3D BEM analysis

Analysis > BEM Analysis
