---
title: "Analysis > Options > Accelerator"
---

Use the matrix accelerator – during Map3D BEM analysis.

This solver will accelerate convergence even for poorly conditioned problems and can reduce the total number of iterations by half or more. This option can be used in conjunction with the CGM option (Analysis > Options > CGM) to provide a reduction in the total number of iterations by a quarter or more.

Notes:

This function must be checked before conducting the Map3D BEM analysis

#### Analysis > BEM Analysis

It is recommended that this option be used.
