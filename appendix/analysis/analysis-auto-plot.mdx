---
title: "Analysis > Auto Plot"
---

Activates the auto plot feature.

When checked Map3D automatically plots the selected surface components as the Map3D BEM analysis proceeds. Any desired surface component can be plotted. By default the surface stress error is plotted

Plot > Surface Components > Serr Stress Error.

To change the surface component that is plotted:

1. During analysis select Analysis > Suspend

2. Select the desired component from the solve toolbar Tools > Solve Toolbar

3. To continue the analysis, select Analysis > Resume

Notes

You must check Tools > Solve Toolbar for the solve toolbar to be displayed when you suspend the analysis.

To have Map3D automatically modify the contour range as the Map3D BEM analysis proceeds, check Analysis > Auto Range
