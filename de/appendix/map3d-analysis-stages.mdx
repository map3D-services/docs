---
title: "Analysephasen in Map3D"
---

Eine Map3D-Analyse verläuft in fünf Phasen:

#### Phase 1 – Modellaufbau und Bearbeitung

In dieser Phase wird die Map3D-Analyse vorbereitet.

#### Analysis > Go to CAD

Mit den in Map3D integrierten CAD-Funktionen können Sie neue Abbaublöcke hinzufügen und vorhandene Blöcke bearbeiten. Dazu gehören Tunnel, große unregelmäßig geformte Hohlräume, Erzzonen, massive und tabulare Abbauhohlräume, Tagebaue, Störungen, Klüfte und mehr.

Verschiedene Teile des Modells können in separaten Komponentendateien gespeichert und für die abschließende Analyse zusammengeführt werden.

#### Analysis > Load Model

In dieser Phase werden die Materialeigenschaften zugewiesen und die gewünschte Abbaufolge festgelegt. Dazu gehören das Einbringen von Erz, der Abbau und der Versatz.

Feldpunktgitter werden an den Stellen positioniert, an denen Ergebnisse abseits des Flözes gewünscht sind. Bei tabularen Abbauhohlräumen werden oft nur Ergebnisse im Flöz benötigt. Feldpunktgitter sind daher optional.

#### Phase 2 – Kontakt- und Schnittanalyse

#### Analysis > Intersections.

Zwischen Blöcken, die einander durchdringen, werden Schnitte erzeugt. Boolesche Operationen lösen die Abbaufolge auf. Außerdem erfolgt eine umfassende Prüfung der Modellintegrität.

#### Phase 3 – Diskretisierung von Blöcken und Gittern

#### Analysis > Discretization.

Das Modell wird in Randelemente für die BEM-Analyse diskretisiert. Sie haben die volle Kontrolle darüber, wie das Modell diskretisiert wird. Die Diskretisierung kann automatisch durch das Programm erfolgen, das die Elemente nur dort konzentriert, wo Ergebnisse angefordert werden, oder manuell festgelegt werden.

#### Phase 4 – Map3D-BEM-Analyse

#### Analysis > BEM Analysis.

Führt die Randelementanalyse durch. Dieselben Eingabedaten können für die elastische, die thermische/Fluidströmungs-Analyse oder die nichtlineare Analyse verwendet werden

#### Map3D-Versionen

#### Phase 5 – Nachbearbeitung

#### Analysis > Graphics.

In dieser Phase werden die Ergebnisse der Map3D-Analyse angezeigt und weiterverarbeitet. Konturdarstellungen von Spannung, Dehnung, Verschiebung und Festigkeitsfaktoren oder einer beliebigen Kombination dieser Komponenten können auf Randflächen und auf benutzerdefinierten Feldpunktgittern erzeugt werden. Die Ergebnisse können entweder als Gesamtwerte oder als Wertdifferenz zwischen Abbauschritten dargestellt werden.

Ergebnisse früherer Analysen können zur Ansicht geladen werden

File > Open Analysis Results.
