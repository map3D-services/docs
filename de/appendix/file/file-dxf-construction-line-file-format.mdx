---
title: "Datei > DXF-Dateiformat für Konstruktionslinien"
---

Das DXF-Format ist eine AutoCAD-Zeichnungsaustauschdatei mit der Erweiterung ".DXF".

Dieses Format eignet sich für den Austausch von Modelldaten mit anderer CAD-Software.

Konstruktionslinien werden als Reihe von AutoCAD-DXF-Objekten vom Typ POLYLINE gespeichert.

Konstruktionslinien lassen sich als Reihe von AutoCAD-DXF-Objekten vom Typ POLYLINE, LINE, 3DLINE oder 3DFACE importieren.
