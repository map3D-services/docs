---
title: "Datei > Öffnen > Zuletzt verwendete Verzeichnisse"
---

Bei jedem Öffnen einer Modelldatei oder Neustartdatei wird deren Arbeitsverzeichnis für den schnellen Zugriff in einer späteren Sitzung gespeichert. Um eines dieser Verzeichnisse erneut zu öffnen, wählen Sie es einfach aus der Liste aus.

Verwandte Themen:

File > Open > Recent Files
