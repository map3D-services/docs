---
title: "Datei > PNT-Dateiformat für Konstruktionslinien"
---

Das PNT-Format ist eine universelle ASCII-Datendatei mit der Erweiterung ".PNT".

Dieses Format eignet sich für den Austausch von Rohmodelldaten mit anderer CAD-Software.

Kommentarzeilen müssen in Spalte 1 mit einem Sternchen "*" beginnen.

Konstruktionslinien werden als Reihe von Polylinien wie folgt gespeichert:

**x1 y1 z1 3 colour x2 y1 z1 2 x3 y3 z3 2 x4 y4 z4 2**

xi yi zi stehen für die Koordinaten jedes Punkts. 3 bedeutet, dass dieser Punkt der Anfang einer neuen Linie ist. 2 bedeutet, dass dieser Punkt die Fortsetzung derselben Linie ist. colour legt die Farbnummer fest, mit der die Konstruktionslinie angezeigt wird.

Für die Anzeige stehen insgesamt 10 Farben zur Verfügung.

Sie sind nummeriert mit 1 bis 10, 11 bis 20, 21 bis 30 usw., sodass für die Nummern 1, 11, 21, 31..., 2, 22, 32... usw. dieselbe Farbe angezeigt wird.

Für jede Polylinie kann eine beliebige Anzahl von Punkten angegeben werden.

Weitere Polylinien werden durch Wiederholen der Sequenz angegeben (d. h. eine neue Linie beginnt mit der Zahl 3).

Hinweise

Für logische Gruppierungen von Konstruktionslinien (z. B. für verschiedene Sohlen, Schnitte oder logische Abbaueinheiten wie Vortrieb, Abbau usw.) sollten unterschiedliche Farbnummern verwendet werden. Diese Farben sind benutzerdefinierbar mit

#### Tools > Custom Colours.

Da sich die Anzeige bestimmter Farbnummern von Konstruktionslinien leicht ein- und ausschalten lässt, bietet dies eine effiziente Methode zum Arbeiten mit komplexen Konstruktionslinien-Daten

#### View > Hide Cline Colours.
