---
title: "Datei > PNT-Ausgabedateiformat"
---

Das PNT-Format ist eine universelle ASCII-Datendatei mit der Erweiterung ".PNT".

Dieses Format eignet sich für den Austausch von Rohmodelldaten mit anderer CAD-Software.

Kommentarzeilen beginnen in Spalte 1 mit einem Sternchen "*".

Oberflächen werden als Reihe von Polylinien wie folgt gespeichert:

x1 y1 z1 3 value1 x2 y2 z2 2 value2 x3 y3 z3 2 value3 x4 y4 z4 2 value4

xI yI zI stehen für die Koordinaten jedes Punkts.

3 bedeutet, dass dieser Punkt der Anfang einer neuen Linie ist. 2 bedeutet, dass dieser Punkt die Fortsetzung derselben Linie ist. valuei steht bei geometrischen Objekten für die Farbnummer der Oberfläche

Bei Isolinien steht es für den Wert des dargestellten Parameters an jeder Ecke der Oberfläche.
