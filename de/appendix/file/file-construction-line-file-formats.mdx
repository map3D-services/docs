---
title: "Datei > Dateiformate für Konstruktionslinien"
---

Konstruktionslinien lassen sich in mehreren Dateitypen speichern:

Das Punktdateiformat ist eine universelle ASCII-Datendatei mit der Erweiterung ".PNT". Dieses Format eignet sich für den Austausch von Rohdaten zu Konstruktionslinien mit anderer CAD-Software.

Das AutoCAD-DXF-Format ist eine weit verbreitete Zeichnungsaustauschdatei mit der Erweiterung ".DXF". Dieses Format eignet sich für den Austausch von Konstruktionslinien-Daten mit anderer CAD-Software.

Konstruktionslinien aus verschiedenen Dateien lassen sich zusammenführen. Die Option zum Zusammenführen

#### File > Open > Merge

befindet sich am unteren Rand des Dialogfelds zum Öffnen von Dateien.

Verwandte Themen:

File > Open (Construction Lines).

File > Save As.
