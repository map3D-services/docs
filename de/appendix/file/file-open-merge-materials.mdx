---
title: "Datei > Öffnen > Materialien zusammenführen"
---

Ist diese Option aktiviert, werden beim Laden der neuen Modelldatei die Materialdaten der neuen Datei mit den aktuellen Materialdaten zusammengeführt.

Ist diese Option nicht aktiviert, ersetzen die Materialdaten der neuen Datei beim Laden der neuen Modelldatei die aktuellen Materialdaten.

So können Sie Ihre Materialmodelle in separaten Datendateien aufbewahren und bei Bedarf in Modelle einbinden.

Verwandte Themen:

File > Open > Merge Geometries.
