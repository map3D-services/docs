---
title: "Datei > Modelldateiformate"
---

Modelle lassen sich aus mehreren Dateitypen laden:

Das Map3D-INP-Format ist eine bearbeitbare ASCII-Datendatei mit der Erweiterung ".INP". Dies ist das empfohlene Map3D-Modellformat. Mit diesem Format werden alle Funktionen von Map3D unterstützt.

Das AutoCAD-DXF-Format ist eine weit verbreitete Zeichnungsaustauschdatei mit der Erweiterung ".DXF". Dieses Format eignet sich für den Austausch von Modelldaten mit anderer CAD-Software.

Das Punktdateiformat ist eine universelle ASCII-Datendatei mit der Erweiterung ".PNT". Dieses Format eignet sich für den Austausch von Rohmodelldaten mit anderer CAD-Software.

Modelle aus verschiedenen Dateien lassen sich zusammenführen. Die Option zum Zusammenführen

File > Open > Merge

befindet sich am unteren Rand des Dialogfelds zum Öffnen von Dateien.

Verwandte Themen:

File > Open File > Save As
