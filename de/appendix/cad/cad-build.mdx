---
title: "CAD > Erstellen"
---

Aktiviert die Symbolleiste Build.

Diese Symbolleiste bietet schnellen Zugriff auf die Funktionen zum Erstellen von Objekten, die in der Phase des Modellaufbaus und der Modellbearbeitung der Map3D-BEM-Analyse verwendet werden Analysis > Go to CAD.

CAD > Build > FF Loop Erstellt einen mehreckigen, dreidimensionalen Block vom Typ FF für Hohlräume und Zonen mit abweichendem Material.

CAD > Build > DD Loop Erstellt einen mehreckigen Block vom Typ DD für den tabularen Abbau, dünne Flöze oder Störungsflächen.

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane Erstellt eine Rasterebene, auf der Analyseergebnisse berechnet werden.

![Figure from page 320](/images/page-320-img-13.png)

CAD > Build > Grid Line Erstellt eine Rasterlinie, auf der Analyseergebnisse berechnet werden.

CAD > Build > Construction Lines Erstellt Konstruktionslinien, um die genaue Lage unterirdischer Strukturen wie Hohlräume, Kontakte usw. zu definieren.

CAD > Build > Enter Point Gibt Koordinatenwerte für einen Punkt ein.

CAD > Build > Offset Remaining Versetzt die verbleibenden Punkte.

CAD > Build > Undo Point Macht die letzte Punktauswahl rückgängig.

CAD > Build > Redo Point Stellt die letzte Punktauswahl wieder her.

Durch Drücken der Leertaste wird automatisch die zuletzt verwendete Funktion zum Erstellen von Objekten aktiviert.
