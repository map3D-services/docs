---
title: "CAD > Bearbeiten > Liste der zu bearbeitenden Objekte erstellen"
---

Diese Routine lässt sich entweder durch Auswahl einer beliebigen Bearbeitungsfunktion (z. B. einer Schaltfläche) oder einfach durch Rechtsklick auf ein beliebiges Objekt starten.

Beim Start einer Routine zur Objektbearbeitung werden Sie zunächst aufgefordert, eine Liste der Objekte zu erstellen, die Sie bearbeiten möchten

![Figure from page 132](/images/page-132-img-1.png)

- Wenn Tools > Shift-key Selection aktiviert ist, müssen Sie für Mehrfachauswahlen die Umschalttaste gedrückt halten.

- Standardmäßig werden ausgewählte Objekte zur Liste hinzugefügt. Wenn Sie jedoch die Strg-Taste gedrückt halten, werden ausgewählte Objekte aus der Liste entfernt.

- Während Sie die Umschalttaste oder die Strg-Taste gedrückt halten, können Sie ein Kreuzungsfenster aufziehen.

- Durch Drücken der Leertaste wird automatisch die zuletzt verwendete Bearbeitungsfunktion aktiviert.

- Wenn Sie beim Rechtsklick die Alt-Taste gedrückt halten, wird die zuletzt verwendete Bearbeitungsfunktion automatisch wiederholt.

Diese Symbolleiste steuert die verschiedenen Funktionen zum Erstellen der Liste.

Bricht die Bearbeitung ab. Wählt Objekte aus, indem jeweils eine Oberfläche angeklickt wird. Wählt Objekte aus, indem ganze Gruppen angeklickt werden, die einen Block bilden. Schließt alle Objekte mit der ausgewählten Nummer ein.

Schließt alle Objekte mit der ausgewählten Farbe ein.

Schließt alle Objekte mit der ausgewählten Materialnummer ein.

- Derselbe Block kann je nach aktuell aktivem Abbauschritt unterschiedliche Materialien enthalten.

- Stellen Sie bei Verwendung dieser Funktion sicher, dass Sie den passenden Abbauschritt auswählen File > Mining Step

Schließt alle Objekte ein, die mit der ausgewählten Abbauschrittnummer abgebaut wurden.

Schließt alle Objekte innerhalb des ausgewählten Fensters ein.

- Objekte werden nur ausgewählt, wenn das gesamte Objekt innerhalb des Fensters liegt.

- Ist (Oberflächenauswahlmodus) aktiv, werden nur Oberflächen eingeschlossen.

- Ist (Objektauswahlmodus) aktiv, werden alle Oberflächen eingeschlossen, die den Block bilden.

Schließt alle Objekte innerhalb des Kreuzungsfensters ein.

- Objekte werden ausgewählt, wenn auch nur ein Teil des Objekts innerhalb des Fensters liegt.

- Diese Funktion lässt sich auch aktivieren, indem Sie die Umschalttaste oder die Strg-Taste gedrückt halten und ein Kreuzungsfenster aufziehen.

- Ist (Oberflächenauswahlmodus) aktiv, werden nur Oberflächen eingeschlossen.

- Ist (Objektauswahlmodus) aktiv, werden alle Oberflächen eingeschlossen, die den Block bilden.

- Ausgewählte Objekte werden zur Liste hinzugefügt.

Ausgewählte Objekte werden aus der Liste entfernt. Macht die letzte Auswahl rückgängig.

Stellt die letzte Auswahl wieder her.

Sobald Sie die gewünschten Objekte ausgewählt haben, können Sie eine der Bearbeitungsschaltflächen wählen:

CAD > Edit > Entity Properties Bearbeitet Blocktyp, Farbe, Abbaufolge usw. 

CAD > Edit > Erase Entities Löscht ausgewählte Objekte. CAD > Edit > Move Entities Verschiebt ausgewählte Objekte. CAD > Edit > Copy Entities Kopiert ausgewählte Objekte. CAD > Edit > Scale Entities Skaliert ausgewählte Objekte. CAD > Edit > Rotate Azimuth Dreht den Azimut ausgewählter Objekte. CAD > Edit > Rotate Dip Dreht das Einfallen ausgewählter Objekte. CAD > Edit > Dump to File Schreibt ausgewählte Objekte in eine Datei. CAD > Edit > Group Fasst ausgewählte Objekte zu einem einzelnen Block zusammen.

- Doppelklicken Sie auf einen beliebigen Eckpunkt, um die hervorgehobene Funktion auszuführen,

- klicken Sie mit der rechten Maustaste, um eine Liste mit Optionen anzuzeigen.

Nach Abschluss eines Bearbeitungsvorgangs haben Sie eine Möglichkeit, die Änderungen rückgängig zu machen, indem Sie

#### Undo

auswählen. Sie können auch dieselbe Auswahl wiederherstellen und dieselben Objekte erneut bearbeiten, indem Sie

Redo

auswählen. Die Doppelklickzeit lässt sich einstellen mit

Tools > Double Click Time
