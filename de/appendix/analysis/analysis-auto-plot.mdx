---
title: "Analyse > Automatische Darstellung"
---

Aktiviert die automatische Darstellung.

Ist diese Option aktiviert, stellt Map3D die ausgewählten Oberflächenkomponenten während der Map3D-BEM-Analyse automatisch dar. Es kann jede gewünschte Oberflächenkomponente dargestellt werden. Standardmäßig wird der Oberflächenspannungsfehler dargestellt

Plot > Surface Components > Serr Stress Error.

So ändern Sie die dargestellte Oberflächenkomponente:

1. Wählen Sie während der Analyse Analysis > Suspend.

2. Wählen Sie die gewünschte Komponente in der Symbolleiste Solve aus Tools > Solve Toolbar.

3. Um die Analyse fortzusetzen, wählen Sie Analysis > Resume.

Hinweise

Sie müssen Tools > Solve Toolbar aktivieren, damit die Symbolleiste Solve angezeigt wird, wenn Sie die Analyse unterbrechen.

Damit Map3D den Konturbereich während der Map3D-BEM-Analyse automatisch anpasst, aktivieren Sie Analysis > Auto Range
