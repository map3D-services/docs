---
title: "Analyse > Diskretisierung"
---

Diskretisiert das Modell.

Alle Hohlraumoberflächen werden automatisch diskretisiert, indem Elemente dort konzentriert werden, wo Ergebnisse angefordert werden

View > Render > Discretize

Die Analyseergebnisse werden auf DD-Oberflächen und auf einer Reihe benutzerdefinierter Rasterebenen berechnet

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane

oder an benutzerdefinierten Punkten

#### Analysis > Options > MSCALC

Die Rasterebenen werden automatisch in eine Reihe von Feldpunkten diskretisiert, an denen Verschiebungen, Dehnungen und Spannungen berechnet werden.

Die Diskretisierungsanalyse kann beliebig oft mit unterschiedlichen Steuerparametern wiederholt werden.

Der Benutzer hat die vollständige Kontrolle darüber, wie das Modell diskretisiert wird, indem er verschiedene Steuerparameter festlegt (Elementlänge _AL_ , Rasterabstand _AG_ , Elementdiskretisierung _DON_ , Rasterdiskretisierung _DOL_ )

#### Analysis > CParams

sowie die maximale Elementbreite für 3D-FF-Blöcke und DD-Ebenen angibt

CAD > Edit > Entities > Maximum Element Width

und ebenso für Feldpunktraster

CAD > Edit > Entities > Maximum Element Width

Eine ausführliche Erläuterung zur Festlegung dieser Steuerparameter finden Sie unter Discretization and Lumping.

Optionen:

Analysis > Options > MSCALC Analysis > Options > LERD/LSS Analysis > Options > Lumping

Verwandte Themen:

Analysedialog Analysis > Suspend Analysis > ABORT Analysis > Restart
