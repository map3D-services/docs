---
title: "Analyse > Optionen > P-RAM"
---

Speichert einen Teil der Koeffizientenmatrix im physischen RAM – während der Map3D-BEM-Analyse.

Wenn in Ihrem Computer viel RAM installiert ist, kann diese Option die Ausführung erheblich beschleunigen, da Daten wesentlich schneller aus dem RAM als von der Festplatte abgerufen werden können. Obwohl 32-Bit-Windows jedem Prozess nur die Adressierung von 2 GB erlaubt, kann Benutzern mit viel RAM im Computer über AWE (Address Windowing Extensions) auf den physischen RAM zugegriffen werden. AWE ermöglicht den Zugriff auf den gesamten verfügbaren RAM Ihres Computers. Die meisten Systeme unterstützen 4 GB RAM. Einige unterstützen mehr als 64 GB. Die verschiedenen Windows-Versionen bieten unterschiedliche AWE-Unterstützung von 1 GB bis zu 512 GB. AWE wird in den folgenden Windows-Versionen unterstützt:

- Windows 10 Professional und Server (maximal 4 GB).

- Windows NT 4.0, Windows 2000 Professional und Server (maximal 4 GB).

- Windows 2000 Advanced Server (maximal 8 GB).

- Windows 2000 Datacenter Server (maximal 32 GB).

- Windows XP Professional und Windows Server 2003 (maximal 4 GB).

- Windows Server 2003 Enterprise Edition (maximal 32 GB).

- Windows Server 2003 Datacenter Edition (maximal 64 GB).

- Windows 7 & 8.

- Windows 10 & 11 Pro (die Home-Version unterstützt dies nicht).

AWE erfordert das Recht „SE_LOCK_MEMORY“. Um AWE zu aktivieren, gehen Sie wie folgt vor:

Control Panel > Administrative Tools > Local Security Policies

Legen Sie dann fest

Local Policies > User Rights Assignment > Lock Pages in Memory > Add User or Group > Everyone

Sie müssen den Computer neu starten, damit diese Einstellung wirksam wird.

Hinweise:

Diese Funktion muss vor der Durchführung der Map3D-BEM-Analyse aktiviert werden

#### Analysis > BEM Analysis.

Sie sollten nur so viel RAM zuweisen, wie Map3D verwenden soll, und dabei ausreichend Platz für alle anderen Anwendungen lassen, die Sie ausführen möchten.

Sie sollten diesen Parameter niemals größer als den verfügbaren RAM einstellen, da dies zu übermäßigem Auslagern (Paging) durch Ihr Betriebssystem führt und die Analyse erheblich verlangsamt.
