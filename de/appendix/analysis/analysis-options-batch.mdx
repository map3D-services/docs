---
title: "Analyse > Optionen > Stapelverarbeitung"
---

Richtet die Analyse-Stapelwarteschlange ein.

Müssen mehrere Modelle berechnet werden, können sie in dieser Stapelwarteschlange festgelegt werden. Durch Auswahl von

Analysis > Options > Batch > Execute Batch Queue

werden alle aktivierten Modelle ohne interaktive Rückfrage an den Benutzer berechnet.

Wenn Sie eine Stapeldatei zur Ausführung aktivieren, werden Sie aufgefordert, nach Modelldateiname, Speicherort und Dateiformat zu suchen. Verläuft die Suche erfolgreich, wird das Modell aktiviert.

In der zweiten Spalte des Dialogfensters Batch File Setup können Sie bei Bedarf Analyseoptionen festlegen. Diese Einstellungen überschreiben alle Optionen, die im Dialogfenster Analysis > Options festgelegt sind.

#### Konsolenmodus:

Map3D kann bei Bedarf über die Windows-Eingabeaufforderung oder aus einer *.bat-Datei gestartet werden. Befehlszeilenoptionen können in einem Textdateiskript verwendet oder in einer Eingabeaufforderung eingegeben werden. Dazu wird einfach eine *.bat-Datei wie folgt erstellt:

**Map3D filename.inp -option1 - option2 ...** (wobei "filename.inp" der Name der Modelldatei ist, die Sie analysieren möchten).

Die Optionen lauten wie folgt:

- **-analysis** (weist Map3D an, eine Analyse auszuführen – Sie müssen außerdem "filename.inp" angeben).

- **-console** (zeigt während der Ausführung von Map3D nur den "Analysis Dialog" an).

   - (zeigt während der Ausführung von Map3D überhaupt nichts an und beendet sich nach Abschluss der Analyse).

- **-stop** (beendet Map3D nach Abschluss der Analyse).

Ergebnisdateien können ebenfalls wie folgt geöffnet werden:

**Map3D filename.001** (wobei "filename.001" der Name der Ergebnisdatei ist, die Sie anzeigen möchten).

Wenn Sie beispielsweise eine Map3D-Analyse mit nur einem Protokollfenster ausführen möchten, starten Sie sie wie folgt:

#### Map3D filename.inp -console -analysis

Wenn Sie beispielsweise eine Map3D-Analyse ohne Protokollfenster ausführen möchten, starten Sie sie wie folgt:

#### Map3D filename.inp -silent -analysis

#### Hinweise:

Die Dateinamen der Stapelmodelle werden bei jeder Ausführung von Map3D gespeichert und wiederhergestellt.

Nicht aktivierte Modelldateien werden im Stapelmodus nicht ausgeführt.

Die Stapelwarteschlange kann jederzeit unterbrochen werden, indem die aktuelle Analyse abgebrochen wird

Analysis > Abort
