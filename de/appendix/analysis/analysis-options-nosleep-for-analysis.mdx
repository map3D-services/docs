---
title: "Analyse > Optionen > Kein Ruhezustand während der Analyse"
---

Steuert die Ruhezustandseinstellung von Windows.

Die Windows-Einstellungen für „Netzbetrieb, Energiesparmodus und Akku“ können so konfiguriert werden, dass der Computer nach einer festgelegten Zeitspanne ohne Tastatur- und/oder Mausaktivität in den Ruhezustand wechselt. Dadurch wechselt der Computer bei längeren Map3D-Analysen normalerweise in den Ruhezustand, und die Analyse wird unterbrochen. Wenn diese Option aktiviert ist, lässt Map3D während einer Map3D-Analyse nicht zu, dass Windows den Computer in den Ruhezustand versetzt.

Hinweise:

Diese Funktion muss vor der Durchführung der Map3D-BEM-Analyse aktiviert werden

Analysis > BEM Analysis
