---
title: "Analyse > Optionen > Laufwerk Nr."
---

Legt Arbeitslaufwerke für die Koeffizientenmatrix fest – während der Map3D-BEM-Analyse.

Sind mehrere Festplattenlaufwerke installiert, kann mit dieser Option festgelegt werden, wo Map3D die Koeffizientenmatrix speichert. Ist das erste Laufwerk voll, schreibt Map3D den Rest der Matrix auf das nächste Arbeitslaufwerk.

Passt die Lösungsmatrix nicht in den Arbeitsspeicher (siehe Analysis > Options > VRAM und Analysis > Options > PRAM), wird die Matrixlösung zu einer E/A-intensiven Operation, die nur von der E/A-Rate Ihres Computers abhängt. In diesem Fall kann ein großer Teil der Analysedauer wegen der geringen Festplattenleistung auf die Lösungsphase entfallen.

Um dieses Problem zu beheben, ist es unerlässlich, mehrere schnelle Festplatten zu installieren.

Map3D unterstützt Parallelverarbeitung und parallele Festplatten-E/A mit der Mehrprozessor-/Mehrlaufwerksoption vollständig.

Verfügen Sie über eine Lizenz für die Mehrprozessor-/Mehrlaufwerksoption, richtet Map3D diese Laufwerke als RAID-Verbund ein, sodass die E/A überlappend auf allen Laufwerken parallel zu den Berechnungen erfolgt.

Bei dieser Einrichtung steigt die E/A-Leistung proportional zur Anzahl der Laufwerke im Verbund.

Im folgenden Benchmark wird dasselbe Modell mit 1, 2 und 4 Festplatten berechnet.

||1 disk|2 disks|4 disks|8GB PRAM|
|---|---|---|---|---|
|Measured Disk Throughput (MB/sec)|55|112|206|3000 equivalent|
|Matrix Solution (hours)|0.546|0.282|0.163|0.033|
|Solution Speed Increase|1x|1.9x|3.3x|16x|
|Total Analysis Time (4 cores)|0.640|0.376|0.257|0.107|
|Total Speed Increase|1x|1.7x|2.5x|6x|

Die in diesem Benchmark verwendeten Festplatten sind ältere Laufwerke mit 50-60 MB/s (Seagate Barracuda 7200.7). Neuere mechanische Laufwerke erreichen 100 MB/s (Seagate Momentus 7200.4). SATA2-SSDs können über 250 MB/s pro Laufwerk liefern. SATA3-SSDs können über 500 MB/s pro Laufwerk liefern. Mehrere SSDs und/oder NVMe-Laufwerke erreichen erwartungsgemäß nahezu die Geschwindigkeit von PRAM. Beachten Sie, dass einige Hauptplatinen Einschränkungen beim gesamten kombinierten Durchsatz haben und möglicherweise zusätzliche Controller-Adapter erfordern.

Ob Sie für die Mehrprozessor-/Mehrlaufwerksoption lizenziert sind, prüfen Sie unter Analysis > Options > #Threads.

Verfügen Sie über eine Lizenz für die Mehrprozessor-/Mehrlaufwerksoption, lassen sich höhere Festplattenraten erzielen, wenn Sie das Privileg SE_MANAGE_VOLUME_NAME setzen.

Diese Möglichkeit steht in den folgenden Windows-Versionen zur Verfügung:

- Windows NT 4.0, Windows 2000 Professional und Server (maximal 4 GB).

- Windows 2000 Advanced Server (maximal 8 GB).

- Windows 2000 Datacenter Server (maximal 32 GB).

- Windows XP Professional und Windows Server 2003 (maximal 4 GB).

- Windows Server 2003 Enterprise Edition (maximal 32 GB).

- Windows Server 2003 Datacenter Edition (maximal 64 GB).

- Windows 10 & 11 Pro (die Home-Version unterstützt dies nicht).

So setzen Sie das Privileg "SE_MANAGE_VOLUME_NAME":

Control Panel > Administrative Tools > Local Security Policies

Legen Sie anschließend fest

Local Policies > User Rights Assignment > Perform Volume Maintenance Tasks > Add User or Group > Everyone

Damit diese Einstellung wirksam wird, müssen Sie neu starten.

Hinweise:

Diese Funktion muss aktiviert sein, bevor die Map3D-BEM-Analyse durchgeführt wird

#### Analysis > BEM Analysis

Geben Sie das schnellste Laufwerk Ihres Systems an. Die Leistung Ihres Laufwerks können Sie testen mit

Tools > Disk Performance Test
