---
title: "Länge"
---

View > Length   aktiviert ein grafisches Werkzeug zur Längenmessung. Sie werden aufgefordert, die beiden Enden des Längenvektors jeweils mit einem Mausklick auszuwählen. Diese Punkte müssen auf dem Modell oder auf einer Kontur liegen. Länge, Fallen und Fallrichtung des gewählten Vektors werden angezeigt. Wenn Sie beim Auswählen der Punkte die Umschalttaste gedrückt halten, können Sie eine Linie aus mehreren Segmenten definieren und deren Gesamtlänge ermitteln. Definieren Sie (mit gedrückter Umschalttaste) ein geschlossenes Polygon auf einer Konturdarstellung, wird der mittlere Konturwert innerhalb des Polygons angezeigt (siehe Plot > Polygon Box). Einfache Rechteckfenster lassen sich mit gedrückter Umschalttaste durch Aufziehen eines Fensters definieren.

Im PDF führt dieser Eintrag zum Abschnitt [Zoom](/de/menu-commands/view-menu/zoom).
