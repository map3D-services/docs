---
title: "XY-Ebene anzeigen"
---

Richtet die Modellansicht auf eine spezielle Ansichtsposition aus:

View > View XY Plane: Ansicht mit x-Achse nach rechts und y-Achse nach oben.

View > View YZ Plane: Ansicht mit y-Achse nach rechts und z-Achse nach oben. View > View ZX Plane: Ansicht mit x-Achse nach rechts und z-Achse nach oben. View > View Grid Plane: die ausgewählte Rasterebene füllt den Bildschirm

#### CAD > Grid Selection

#### Plot > Grid Selection

View > View Digitizer Plane   der aktuelle Digitalisierbereich füllt den Bildschirm

#### CAD > Digitizer Setup.

Hinweise:

Die aktuelle Ansichtsposition kann zwischen Sitzungen gespeichert

#### File > Save View

oder wiederhergestellt werden

File > Restore View
