Download: Map3D-Update (Map3D.zip, 8 MB)

Lädt das neueste Map3D-Update von der Map3D-Website [www.map3d.com/update.htm](https://www.map3d.com/update.htm) herunter

Es enthält weder die Installationsroutinen noch das Map3D-Benutzerhandbuch im HTML-Format noch die Treiber für den Sentinel-SuperPro-Schlüssel. Beachten Sie, dass das HTML-Benutzerhandbuch von Map3D (Map3D.chm) für die kontextbezogene Hilfe in Map3D erforderlich ist.

Download: Map3D-Update (setup.exe, 18 MB)

Das vollständige Update enthält alle ausführbaren Map3D-Dateien, automatische Installationsroutinen, das Map3D-Benutzerhandbuch im HTML-Format und die Treiber für den Sentinel-SuperPro-Schlüssel sowie einige Beispieldateien.

Das Benutzerhandbuch kann in mehreren Formaten heruntergeladen werden:

Benutzerhandbuch als HTML herunterladen (Map3D.chm, 4 MB)

Das HTML-Benutzerhandbuch kann über Help > Download HTML User's Manual heruntergeladen werden. Es liegt im nativen HTML-Hilfeformat von Windows vor.

Benutzerhandbuch als PDF herunterladen (Map3D_Help.pdf, 7 MB)

Das PDF-Benutzerhandbuch kann über Help > Download PDF User's Manual heruntergeladen werden. Es liegt im PDF-Format vor und eignet sich gut zum Drucken.

Benutzerhandbuch als E-Book herunterladen (Map3D_Help.exe, 5 MB)

Das E-Book-Benutzerhandbuch kann über Help > Download Ebook User's Manual heruntergeladen werden. Es liegt in einem eigenständigen E-Book-Format vor.
