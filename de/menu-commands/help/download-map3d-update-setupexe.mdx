Download: Map3D-Update (setup.exe 18MB)

Lädt das neueste Map3D-Update von der Map3D-Website [www.map3d.com/update.htm](https://www.map3d.com/update.htm) herunter.

Das vollständige Update enthält alle ausführbaren Map3D-Dateien, automatisierte Installationsroutinen, das Map3D-Benutzerhandbuch im HTML-Format und die Treiber für den Sentinel-SuperPro-Schlüssel sowie einige Beispieldateien.

Da das vollständige Update (setup.exe) recht groß ist (8MB), können Sie alternativ nur die aktualisierten ausführbaren Dateien herunterladen (Map3D.zip).

Download: Map3D-Update (Map3D.zip 8MB)

Dieses

enthält weder die Installationsroutinen noch das Map3D-Benutzerhandbuch im HTML-Format noch die Treiber für den Sentinel-SuperPro-Schlüssel. Beachten Sie, dass das HTML-Benutzerhandbuch von Map3D (Map3D.chm) erforderlich ist, damit die kontextsensitive Hilfe in Map3D funktioniert.

Das Benutzerhandbuch kann in mehreren Formaten heruntergeladen werden:

HTML-Benutzerhandbuch herunterladen (Map3D.chm 4MB)

Das HTML-Benutzerhandbuch kann über Help > Help > Download HTML User's Manual heruntergeladen werden. Dieses Handbuch liegt im nativen HTML-Hilfeformat von Windows vor.

PDF-Benutzerhandbuch herunterladen (Map3D_Help.pdf 7MB)

Das PDF-Benutzerhandbuch kann über Help > Download PDF User's Manual heruntergeladen werden. Dieses Handbuch liegt im PDF-Format vor und eignet sich gut zum Drucken.

E-Book-Benutzerhandbuch herunterladen (Map3D_Help.exe 5MB)

Das E-Book-Benutzerhandbuch kann über Help > Download Ebook User's Manual heruntergeladen werden. Dieses Handbuch liegt in einem eigenständigen E-Book-Format vor.
