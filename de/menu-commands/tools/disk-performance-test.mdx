---
title: "Festplatten-Leistungstest"
---

Testet die Leistung des Festplattensystems.

Dieser Test simuliert das Verhalten von Map3D während der Lösungsphase der BEM-Analyse.

Buffer Size – Größe des Puffers für Lese- und Schreibvorgänge auf dem Datenträger. Map3D verwendet für seine Datei-Lese- und Schreibvorgänge einen Puffer von 256K.

Write Through – weist das System an, an allen Zwischenspeichern vorbei direkt auf den Datenträger zu schreiben. Map3D verwendet „Write Through“ für seine Dateischreibvorgänge.

No Buffering – weist das System an, ohne Zwischenpufferung oder Caching in die Datei zu schreiben. Map3D verwendet „No Buffering“ für seine Dateischreibvorgänge.

Asynchronous I/O – weist das System an, mehrere Lese- und/oder Schreibvorgänge gleichzeitig zuzulassen. Diese Option wird nur unter Windows NT/2000 unterstützt. Map3D kann angewiesen werden, diese Funktion zu nutzen, mit

#### Analysis > Options > Async I/O

Size MB – für den Test verwendete Dateigröße. Es wird empfohlen, diesen Test mit einer großen Datei durchzuführen (deutlich größer als der verfügbare Arbeitsspeicher). Drive – für den Test verwendetes Laufwerk.

Die wichtigen Ergebnisse sind:

Write rate – die Anzahl der pro Sekunde auf den Datenträger geschriebenen MByte. Sie sollten mehr als 5–10 MB/Sekunde erwarten.

Read rate – die Anzahl der pro Sekunde vom Datenträger gelesenen MByte. Sie sollten mehr als 5–10 MB/Sekunde erwarten.

Multiply/sec – die Anzahl der pro Sekunde ausgeführten Gleitkomma-Multiplikationen. Sie sollten mehr als 50 MFLOPS erwarten.
