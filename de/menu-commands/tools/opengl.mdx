title: "OpenGL"

## 5.6.4.1 OpenGL &lt;On/Off>

Aktiviert die OpenGL-Unterstützung.

OpenGL ist eine Industriestandard-Schnittstelle für hochwertiges 3D-Grafik-Rendering. Die Hauptvorteile von OpenGL sind die Hardwarebeschleunigung der Grafikanzeige und die Unterstützung des Z-Buffers. Für die Hardwarebeschleunigung benötigen Sie natürlich einen Grafikadapter, der OpenGL unterstützt, und einen installierten OpenGL-Anzeigetreiber.

Siehe Tools > OpenGL Parameters, um die OpenGL-Einrichtung anzuzeigen.

Siehe Tools > OpenGL Anti-aliasing, um Linien zu glätten.

## 5.6.4.2 OpenGL-Parameter

Gibt Auskunft über die OpenGL-Einrichtung:

Support OpenGL – zeigt an, ob ein OpenGL-Treiber installiert und aktiviert ist.

Driver or Hardware Support - zeigt an, ob OpenGL von Ihrem Grafikadapter unterstützt wird.

Double Buffered – zeigt an, dass genügend Speicher für Doppelpufferung vorhanden ist.

Color Buffer Bits – zeigt die Anzahl der Bits an, die für den Farbpuffer verwendet werden.

Depth Buffer Bits – zeigt die Anzahl der Bits an, die für den Z-Buffer verwendet werden.

## 5.6.4.3 OpenGL-Kantenglättung

Aktiviert die Glättung von Punkten, Linien und Polygonkanten.

Diese OpenGL-Funktion verbessert das Erscheinungsbild, verlangsamt aber das Rendering.

Mit View > Render > Line Width lässt sich das Zeichnen breiterer Linien aktivieren. Dies trägt ebenfalls zur Glättung der Liniendarstellung bei, mit ähnlichen Auswirkungen auf die Leistung.

## 5.6.4.4 OpenGL-Neuzeichnen

Aktiviert das Neuzeichnen des Bildschirms per OpenGL, wenn das Fenster aktualisiert werden muss.

Das Map3D-Anzeigefenster muss jedes Mal aktualisiert werden, wenn ein Dialogfeld verschoben oder entfernt wird. Diese Aktualisierung kann entweder erfolgen, indem das Anzeigefenster in einem Hintergrundpuffer gespeichert wird (diese Option ist nicht aktiviert), oder indem der Bildschirm einfach neu gezeichnet wird (diese Option ist aktiviert).

Diese Option sollte normalerweise aktiviert sein, kann aber bei problematischen Grafikadaptern deaktiviert werden.

## 5.6.4.5 OpenGL-Auswahl

Ermöglicht es OpenGL, Grafikobjekte auf dem Bildschirm zu lokalisieren.

Wenn Sie mit der linken Maustaste auf ein Objekt klicken, muss Map3D ermitteln, welches Objekt Sie ausgewählt haben. Dies kann entweder durch OpenGL oder intern durch Map3D erfolgen.

Diese Option sollte normalerweise aktiviert sein, kann aber bei problematischen Grafikadaptern deaktiviert werden.

## 5.6.4.6 OpenGL-Fadenkreuz

Schaltet zwischen dem Zeichnen des Cursor-Fadenkreuzes über OpenGL und über die Windows-API um.

Diese Option sollte normalerweise aktiviert sein, kann aber bei problematischen Grafikadaptern deaktiviert werden.

Um das Zeichnen des Cursor-Fadenkreuzes vollständig zu deaktivieren, wählen Sie Tools > Crosshairs.

## 5.6.4.7 Interaktive OpenGL-Bearbeitung

Aktiviert das interaktive Zeichnen geänderter Formen per OpenGL während Bearbeitungsvorgängen.

Diese Option sollte normalerweise aktiviert sein, kann aber bei problematischen Grafikadaptern deaktiviert werden.
