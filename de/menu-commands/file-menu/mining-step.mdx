---
title: "Abbauschritt Nr."
---

Wählt einen anderen Abbauschritt zur Anzeige aus.

Ist die Map3D-BEM-Analyse für den gewählten Abbauschritt abgeschlossen, wird die Neustartdatei dieses Schritts geladen. Existiert die Neustartdatei nicht (weil die Analyse nicht abgeschlossen ist), wird nur die Geometrie dieses Abbauschritts angezeigt.

Das Wechseln zwischen Abbauschritten mit dieser Funktion ist schneller als das Laden einer Neustartdatei mit

#### File > Open Analysis Results

da die Sortierung von Elementen und Rastern für dasselbe Modell nicht wiederholt werden muss.

Für den schnellen Zugriff auf verschiedene Abbauschritte verwenden Sie

#### File > Mining Step.

in der Ansichts-Symbolleiste

#### Tools > View Toolbar.

Bei Bedarf können einzelne Abbauschritt-Schaltflächen in der Ansichts-Symbolleiste platziert werden mit

#### Tools > View Toolbar Configure.

Mit gedrückter Alt-Taste und der Taste + bzw. – können Sie schnell einen Abbauschritt vor- oder zurückgehen.
