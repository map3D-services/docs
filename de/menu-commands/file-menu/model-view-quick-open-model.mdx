---
title: "MODELLANSICHT (Modell schnell öffnen)..."
---

Lädt ein Modell schnell aus einer Datei, überspringt jedoch die gesamte Vorverarbeitung. Beachten Sie, dass Sie keine CAD-Funktionen verwenden können, bis Sie die Datei mit Open Model (CAD) geladen oder im Hauptmenü des Programms „Go To CAD“ gewählt haben.

#### Mehrere Dateien zu einem Modell zusammenführen

Sie können mehrere Dateien gleichzeitig auswählen, indem Sie die Windows-Standardtasten „Umschalt“ oder „Strg“ gedrückt halten.

Diese Dateien werden zu einem Modell bzw. einer Datenbank zusammengeführt.

So können Sie Teile der Modelldaten in getrennten Dateien halten und sie anschließend einfach zu einem Modell bzw. einer Datenbank zusammenführen.

Eine weitere Möglichkeit zum Zusammenführen mehrerer Dateien besteht darin, die Option „Merge Geometries“ zu wählen, bevor Sie die zusätzliche Datei auswählen, die Sie dem bestehenden Modell bzw. der Datenbank hinzufügen möchten.

Dies ist nützlich, wenn bereits ein Modell geöffnet ist und Sie weitere Modelldaten hinzufügen möchten.
