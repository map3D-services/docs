---
title: "Bildbetrachter"
---

Zeigt PNG- (Portable Network Graphics, *.PNG), GIF- (Graphics Interchange Format) oder BMP-Dateien (geräteunabhängige Windows-Bitmap, *.BMP) in einem Fenster an.

Beim Start des Betrachters wird das aktuelle Bildschirmbild angezeigt.

Mit dem Betrachter lassen sich einzelne Bilder, animierte GIFs und Bildfolgen anzeigen.

Bildschirmbilder können in Dateien gespeichert werden mit

- File > Output > PNG, GIF or BMP Image

- File > Output > PNG, GIF or BMP (B&W flipped)

- File > Output > Image Recorder
