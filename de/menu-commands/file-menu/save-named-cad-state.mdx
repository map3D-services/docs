---
title: "Benannten CAD-Zustand speichern"
---

Speichert den aktuellen CAD-Zustand in einer *.sav-Datei.

Dazu gehören alle Informationen der aktuellen Sitzung, z. B. Geometrie, Steuerparameter, Materialeigenschaften, Konstruktionslinien usw.

So können Sie genau dort weitermachen, wo Sie in einer zuvor gespeicherten Map3D-Sitzung oder nach einem Programmabsturz aufgehört haben.

#### Verwandte Themen:

Restore Auto-Save CAD State – stellt den zuletzt automatisch gespeicherten CAD-Zustand wieder her. Siehe Automatisch gespeicherten CAD-Zustand wiederherstellen

Restore named CAD State – stellt einen benannten CAD-Zustand aus einer *.sav-Datei wieder her. Siehe Benannten CAD-Zustand wiederherstellen
