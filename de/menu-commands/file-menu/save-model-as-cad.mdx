---
title: "Modell speichern unter (CAD)"
---

Speichert das aktuelle Modell unter einem anderen Dateinamen, an einem anderen Ort und in einem anderen Format.

Modelle können in mehreren Dateitypen gespeichert werden:

- Das Map3D-INP-Format ist eine bearbeitbare ASCII-Datendatei mit der Endung „.INP“. Dies ist das empfohlene Map3D-Modellformat. Alle Map3D-Funktionen werden mit diesem Format unterstützt.

- Das AutoCAD-DXF-Format ist ein verbreitetes Zeichnungsaustauschformat mit der Endung „.DXF“. Dieses Format eignet sich zum Austausch von Modelldaten mit anderer CAD-Software.

- Das Punktdateiformat ist eine universelle ASCII-Datendatei mit der Endung „.PNT“. Dieses Format eignet sich zum Austausch roher Modelldaten mit anderer CAD-Software.

Um unter demselben Namen, am selben Ort und im selben Format zu speichern, verwenden Sie

#### File > Save Model.
