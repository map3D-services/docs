---
title: "Analyseergebnisse öffnen"
---

Lädt Analyseergebnisse aus einer Neustartdatei.

Sie werden aufgefordert, Name, Speicherort und Format der Neustartdatei auszuwählen.

Nach dem Laden kann der Benutzer die Analyseergebnisse anzeigen und auswerten. Es lassen sich Konturdarstellungen jeder gewünschten Kombination von Spannungs-, Dehnungs- und Verschiebungskomponenten erzeugen. Ergebnisse können als Gesamtwerte oder als Differenz zwischen Abbauschritten angezeigt werden.

Um von einem Abbauschritt zu einem anderen zu wechseln, verwenden Sie

#### File > Mining Step.

Hinweise:

Für den schnellen Zugriff in einer späteren Sitzung wird der Name jeder geöffneten Datei gespeichert unter

#### File > Recent Files

und das Arbeitsverzeichnis unter

#### File > Open > Recent Directories.

Um die Modelldatei zum Bearbeiten von Abbaublöcken und zum Einrichten der Map3D-Analyse erneut zu laden, verwenden Sie

#### Analysis > Go to CAD.

Um eine andere Modelldatei zu laden, verwenden Sie

#### File > Open (Model).

Um eine Analyse neu zu starten, die abgebrochen oder durch einen Stromausfall oder Systemabsturz unterbrochen wurde, verwenden Sie

File > Restart an Analysis.
