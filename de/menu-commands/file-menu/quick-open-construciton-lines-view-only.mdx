---
title: "Konstruktionslinien schnell öffnen (nur Anzeige)"
---

Lädt Konstruktionsliniendaten schnell aus einer Datei, überspringt aber die gesamte Vorverarbeitung. Beachten Sie, dass Sie keine der CAD-Funktionen verwenden können, bis Sie die Datei mit Open Construction Lines geladen haben,

Konstruktionslinien dienen dazu, die genaue Lage untertägiger Elemente wie Hohlräume, Kontakte, Strukturen usw. festzulegen. Ein Map3D-Modell wird normalerweise auf diesen Konstruktionsliniendaten aufgebaut.

Sie werden aufgefordert, Name, Speicherort und Format der Konstruktionsliniendatei auszuwählen. Konstruktionslinien können aus mehreren Dateitypen geladen werden:

- Das Punktdateiformat ist eine universelle ASCII-Datendatei mit der Erweiterung „.PNT“. Dieses Format eignet sich zum Austausch roher Konstruktionsliniendaten mit anderer CAD-Software.

- Das AutoCAD-DXF-Format ist ein verbreitetes Zeichnungsaustauschformat mit der Erweiterung „.DXF“. Dieses Format eignet sich zum Austausch von Konstruktionsliniendaten mit anderer CAD-Software.

Die geladenen Konstruktionsliniendaten können die vorhandenen Daten entweder überschreiben oder mit ihnen zusammengeführt werden. Die Option Überschreiben/Zusammenführen

#### File > Open > Merge Geometires

erscheint unten im Dialogfeld zum Öffnen von Dateien.

#### Mehrere Dateien in einer Datenbank zusammenführen

Sie können mehrere Dateien gleichzeitig auswählen, indem Sie für die Mehrfachauswahl die üblichen Windows-Tasten „Umschalt“ oder „Strg“ gedrückt halten.

Diese Dateien werden in einer Datenbank zusammengeführt.

So können Sie einzelne Teile der Konstruktionsliniendaten in verschiedenen Dateien aufbewahren und sie dann einfach in einer Datenbank zusammenführen.

Eine weitere Möglichkeit, mehrere Dateien zusammenzuführen, besteht darin, die Option „Merge Geometries“ auszuwählen, bevor Sie die zusätzliche Datei auswählen, die Sie der vorhandenen Datenbank hinzufügen möchten.

Dies ist nützlich, wenn Sie bereits Konstruktionsliniendaten geöffnet haben und weitere hinzufügen möchten
