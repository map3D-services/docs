---
title: "Modell öffnen (CAD)"
---

Lädt ein Modell aus einer Datei.

Nach dem Laden können Sie jede gewünschte Map3D-Analysephase ausführen.

Um Abbaublöcke hinzuzufügen oder zu bearbeiten und die Map3D-Analyse einzurichten, verwenden Sie

#### Analysis > Go to CAD.

Beim Laden des Modells prüft Map3D die grundlegende Konsistenz der Modellierungsparameter (z. B. müssen die Eigenschaften eines verwendeten Materials in der Materialliste angegeben sein).

Sie werden aufgefordert, Name, Speicherort und Format der Modelldatei auszuwählen. Modelle können aus mehreren Dateitypen geladen werden:

- Das Map3D-INP-Format ist eine bearbeitbare ASCII-Datendatei mit der Erweiterung „.INP“. Dies ist das empfohlene Map3D-Modellformat. Mit diesem Format werden alle Map3D-Funktionen unterstützt.

- Das AutoCAD-DXF-Format ist ein verbreitetes Zeichnungsaustauschformat mit der Erweiterung „.DXF“. Dieses Format eignet sich zum Austausch von Modelldaten mit anderer CAD-Software.

- Das Punktdateiformat ist eine universelle ASCII-Datendatei mit der Erweiterung „.PNT“. Dieses Format eignet sich zum Austausch roher Modelldaten mit anderer CAD-Software.

Die geladenen geometrischen und Materialdaten des Modells können die vorhandenen Modelldaten entweder überschreiben oder mit ihnen zusammengeführt werden. Die Optionen Überschreiben/Zusammenführen:

- File > Open > Merge Geometries

- File > Open > Merge Materials

erscheinen unten im Dialogfeld zum Öffnen von Dateien.

#### Mehrere Dateien zu einem Modell zusammenführen

Sie können mehrere Dateien gleichzeitig auswählen, indem Sie für die Mehrfachauswahl die üblichen Windows-Tasten „Umschalt“ oder „Strg“ gedrückt halten.

Diese Dateien werden zu einem Modell bzw. einer Datenbank zusammengeführt.

So können Sie einzelne Teile der Modelldaten in verschiedenen Dateien aufbewahren und sie dann einfach zu einem Modell bzw. einer Datenbank zusammenführen.

Eine weitere Möglichkeit, mehrere Dateien zusammenzuführen, besteht darin, die Option „Merge Geometries“ auszuwählen, bevor Sie die zusätzliche Datei auswählen, die Sie dem vorhandenen Modell bzw. der vorhandenen Datenbank hinzufügen möchten.

Dies ist nützlich, wenn Sie bereits ein Modell geöffnet haben und weitere Modelldaten hinzufügen möchten.

#### Hinweise:

Für den schnellen Zugriff in einer späteren Sitzung wird bei jedem Öffnen einer Datei ihr Name unter

#### File > Recent Files

und das Arbeitsverzeichnis unter

File > Open > Recent Directories gespeichert.

Zum Laden von Analyseergebnissen verwenden Sie

File > Open Analysis Results.

Um eine Analyse neu zu starten, die abgebrochen oder durch einen Stromausfall oder Betriebssystemabsturz unterbrochen wurde, verwenden Sie

File > Restart an Analysis.
