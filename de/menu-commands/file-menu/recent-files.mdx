---
title: "Zuletzt verwendete Dateien"
---

Jedes Mal, wenn Sie eine Modelldatei öffnen, wird ihr Name für den schnellen Zugriff in einer späteren Sitzung gespeichert. Um eine dieser Dateien erneut zu öffnen, wählen Sie sie einfach aus der Liste.

Verwandte Themen:

File > Open > Recent Directories
