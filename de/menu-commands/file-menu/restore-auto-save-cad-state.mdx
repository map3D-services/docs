---
title: "Automatisch gespeicherten CAD-Zustand wiederherstellen"
---

Stellt den zuletzt automatisch gespeicherten CAD-Zustand wieder her.

Bei der Modellbearbeitung wird der aktuelle CAD-Zustand bei jeder Geometrieänderung in einer temporären Datei gespeichert, die zwischen Map3D-Sitzungen erhalten bleibt.

Dazu gehören alle Informationen der aktuellen Sitzung, z. B. Geometrie, Steuerparameter, Materialeigenschaften, Konstruktionslinien usw.

So können Sie in einer neuen Map3D-Sitzung oder nach einem Programmabsturz genau dort weitermachen, wo Sie aufgehört haben.

#### Verwandte Themen:

Save named CAD State – speichert den CAD-Zustand manuell in einer *.sav-Datei. Siehe Benannten CAD-Zustand speichern

Restore named CAD State – stellt einen benannten CAD-Zustand aus einer *.sav-Datei wieder her. Siehe Benannten CAD-Zustand wiederherstellen
