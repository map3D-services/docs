## 5.3.8.1 Delem Abstand zum nächsten Element auf Oberflächen

Stellt den Abstand zum nächsten Element von jeder Oberfläche aus als Konturen dar.

_Delem_ wird von Map3D als kleinster Abstand zwischen benachbarten Modelloberflächen bestimmt.

Während der Diskretisierung werden alle Modelloberflächen (Oberflächen von FF-Blöcken und DD-Ebenen) in Randelemente mit der Seitenlänge

_Delem /DON_

unterteilt.

Beim Aufbau der Matrix werden alle Elemente, die in die Abmessung

_Delem/DOC_

passen, zusammengefasst (Lumping).

Weitere Einzelheiten finden Sie unter

CAD > Properties > Control Parameters.

#### Verwandte Themen:

Plot > Miscellaneous > Delem/Lelem - DON ratio on surfaces

## 5.3.8.2 Dgrid Abstand zum nächsten Raster auf Oberflächen

Stellt den Abstand zum nächsten Raster von jeder Oberfläche aus als Konturen dar.

_Dgrid_ wird von Map3D als kleinster Abstand zwischen Modelloberflächen und Rasterebenen bestimmt.

Während der Diskretisierung werden alle Modelloberflächen (Oberflächen von FF-Blöcken und DD-Ebenen) in Randelemente mit der Seitenlänge

_Dgrid/DOL_

unterteilt.

Beim Rasteraufbau werden alle Elemente, die in die Abmessung

_Dgrid/DOE_

passen, zusammengefasst (Lumping).

Beim Rasteraufbau werden alle Rasterpunkte, die in die Abmessung

_Dgrid/DOG_

passen, zusammengefasst (Lumping).

Weitere Einzelheiten finden Sie unter

CAD > Properties > Control Parameters

#### Verwandte Themen:

Plot > Miscellaneous > Delem/Lelem - DON ratio on surfaces

## 5.3.8.3 Delem/Lelem DON-Verhältnis auf Oberflächen

Stellt den Abstand zum nächsten Element _Delem_ geteilt durch die Elementbreite _Lelem_ als Konturen dar.

_Delem_ wird von Map3D als kleinster Abstand zwischen benachbarten Modelloberflächen bestimmt.

Kleine Werte von _DON_ können mit Konvergenzproblemen zusammenhängen.

Weitere Einzelheiten finden Sie unter

CAD > Properties > Control Parameters.

## 5.3.8.4 Dgrid/Lelem DOL-Verhältnis auf Oberflächen

Stellt den Abstand zum nächsten Raster _Dgrid_ geteilt durch die Elementbreite _Lelem_ als Konturen dar.

_Dgrid_ wird von Map3D als kleinster Abstand zwischen Modelloberflächen und Rasterebenen bestimmt.

Kleine Werte von _DOL_ können auf Vorhersagen mit geringer Genauigkeit hinweisen ( _DOL_ =1 für 10–20 % Fehler, _DOL_ =2 für 5–10 % Fehler, _DOL_ =4 für &lt; 5 % Fehler).

Weitere Einzelheiten finden Sie unter

CAD > Properties > Control Parameters.

## 5.3.8.5 Dratio auf Oberflächen

Stellt das Koeffizientenverhältnis auf Oberflächen als Konturen dar.

Dieses Verhältnis zeigt Stellen, an denen Oberflächen sehr nahe beieinander liegen, was auf mögliche Konstruktionsfehler hindeutet.

## 5.3.8.6 Dgrid Abstand zum nächsten Element auf Rastern

Stellt den Abstand zur nächsten Oberfläche von jedem Rasterpunkt aus als Konturen dar.

_Dgrid_ wird von Map3D als kleinster Abstand zwischen Rasterebenen und Modelloberflächen bestimmt.

Während der Diskretisierung werden alle Rasterebenen in Elemente mit der Seitenlänge _Dgrid/DOL_ unterteilt.

Beim Rasteraufbau werden alle Elemente, die in die Abmessung _Dgrid/DOE_

passen, zusammengefasst (Lumping).

Beim Rasteraufbau werden alle Rasterpunkte, die in die Abmessung

_Dgrid/DOG_

passen, zusammengefasst (Lumping).

Weitere Einzelheiten finden Sie unter

CAD > Properties > Control Parameters

#### Verwandte Themen:

Plot > Miscellaneous > Dgrid/Lgrid DOL ratio on grids

_Dgrid_ wird von Map3D als kleinster Abstand zwischen Modelloberflächen und Rasterebenen bestimmt.
