---
title: "Polygonfeld"
---

Berechnet den gewichteten Mittelwert aller ausgewählten Konturpunkte. Diese Funktion kann auch über View > Length aktiviert werden.

Sie werden aufgefordert, eine Reihe von Eckpunkten auszuwählen, um ein geschlossenes Polygon zu definieren, indem Sie jeden mit einem einfachen Mausklick anklicken:

- Sie müssen die Umschalttaste gedrückt halten, damit mehrere Liniensegmente ausgewählt werden können.

- Eine geschlossene Polygonform wird definiert, indem Sie die Polylinie durch Auswahl des Startpunkts schließen.

- Wenn Sie eine geschlossene Polygonform definieren, werden die im Polygon eingeschlossenen Konturpunkte in die Mittelung einbezogen.

- Die Mittelungsroutine funktioniert nicht, wenn Sie eine offene Polylinie definieren (indem Sie den Startpunkt nicht auswählen).

- Um die Lage der tatsächlichen Konturpunkte anzuzeigen, aktivieren Sie die Anzeige der Trajektorien (Plot > Options > Trajectories). Die Konturpunkte liegen dort, wo die Trajektorien gezeichnet werden.

Die Mittelung erfolgt, indem jeder ausgewählte Wert mit der Fläche der zugehörigen Oberfläche bzw. Rasterzelle multipliziert und die Produkte anschließend aufsummiert werden. Dieses Ergebnis wird als „Weighted Sum“ ausgegeben. Der „Average“ ergibt sich aus der gewichteten Summe geteilt durch die Gesamtfläche.

Alle Werte werden als Vektorkomponenten aufsummiert. Hauptspannungen werden aus dem gewichteten Mittel der kartesischen Komponenten bestimmt. Verschiebungs-, Fluss- und Oberflächenscherkomponenten werden aus dem gewichteten Mittel der Vektorkomponenten bestimmt.

Beachten Sie, dass bei Spannungen die „Weighted Sum“ tatsächlich der Gesamtkraft entspricht, die auf die Fläche wirkt.

Wenn Sie mit dem Schubmodul multiplizieren, entspricht die „Weighted Sum“ der plastischen Scherverschiebung (ride) tatsächlich dem seismischen Moment.
