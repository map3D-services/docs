---
title: "Archivo > Formato PNT de líneas de construcción"
---

El formato PNT es un archivo de datos ASCII universal con la extensión ".PNT".

Este formato es útil para intercambiar datos sin procesar del modelo con otro software CAD.

Las líneas de comentario deben comenzar con un asterisco "*" en la columna 1.

Las líneas de construcción se almacenan como una serie de polilíneas de la siguiente manera:

**x1 y1 z1 3 colour x2 y1 z1 2 x3 y3 z3 2 x4 y4 z4 2**

xi yi zi representan las coordenadas de cada punto. 3 indica que este punto es el inicio de una nueva línea. 2 indica que este punto es una continuación de la misma línea. colour especifica el número de color que se usará para mostrar la línea de construcción.

Hay un total de 10 colores disponibles para la visualización.

Se numeran del 1 al 10, del 11 al 20, del 21 al 30, etc., de modo que se muestra el mismo color para los números 1, 11, 21, 31..., 2, 22, 32..., etc.

Se puede especificar cualquier número de puntos para cada polilínea.

Las polilíneas adicionales se especifican repitiendo la secuencia (es decir, iniciando una nueva línea con el número 3).

Notas

Se deben usar distintos números de color para representar agrupaciones lógicas de líneas de construcción (por ejemplo, para distintos niveles, secciones o unidades lógicas de minería, como desarrollo, tajeo, etc.). Estos colores son definibles por el usuario mediante

#### Tools > Custom Colours.

Como es fácil activar y desactivar la visualización de números de color específicos de líneas de construcción, esto ofrece un método eficiente para trabajar con datos complejos de líneas de construcción

#### View > Hide Cline Colours.
