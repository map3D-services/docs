---
title: "Archivo > Formatos de archivo de modelo"
---

Los modelos se pueden cargar desde varios tipos de archivo:

El formato Map3D-INP es un archivo de datos ASCII editable con la extensión ".INP". Es el formato de modelo recomendado para Map3D. Este formato admite toda la funcionalidad de Map3D.

El formato AutoCAD-DXF es un archivo de intercambio de dibujos muy utilizado, con la extensión ".DXF". Este formato es útil para intercambiar datos del modelo con otro software CAD.

El formato de archivo de puntos es un archivo de datos ASCII universal con la extensión ".PNT". Este formato es útil para intercambiar datos sin procesar del modelo con otro software CAD.

Se pueden combinar modelos de distintos archivos. La opción de combinar

File > Open > Merge

aparece en la parte inferior del cuadro de diálogo de apertura de archivos.

Temas relacionados:

File > Open File > Save As
