---
title: "Archivo > Formato DXF de líneas de construcción"
---

El formato DXF es un archivo de intercambio de dibujos de AutoCAD con la extensión ".DXF".

Este formato es útil para intercambiar datos del modelo con otro software CAD.

Las líneas de construcción se guardan como una serie de entidades POLYLINE de AutoCAD DXF.

Las líneas de construcción se pueden importar como una serie de entidades POLYLINE, LINE, 3DLINE o 3DFACE de AutoCAD DXF.
