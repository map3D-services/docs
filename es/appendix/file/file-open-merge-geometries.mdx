---
title: "Archivo > Abrir > Combinar geometrías"
---

Si esta opción está marcada, al cargar el nuevo archivo de modelo o de líneas de construcción, los datos geométricos se combinan con los datos geométricos actuales.

Si esta opción no está marcada, al cargar el nuevo archivo de modelo o de líneas de construcción, los datos geométricos reemplazan o sobrescriben los datos geométricos actuales.

Esto permite construir el modelo o la base de datos de líneas de construcción en partes pequeñas y combinarlas según sea necesario.

Temas relacionados:

File > Open > Merge Materials.
