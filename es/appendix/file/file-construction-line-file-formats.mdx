---
title: "Archivo > Formatos de archivo de líneas de construcción"
---

Las líneas de construcción se pueden guardar en varios tipos de archivo:

El formato de archivo de puntos es un archivo de datos ASCII universal con la extensión ".PNT". Este formato es útil para intercambiar datos sin procesar de líneas de construcción con otro software CAD.

El formato AutoCAD-DXF es un archivo de intercambio de dibujos muy utilizado, con la extensión ".DXF". Este formato es útil para intercambiar datos de líneas de construcción con otro software CAD.

Se pueden combinar líneas de construcción de distintos archivos. La opción de combinar

#### File > Open > Merge

aparece en la parte inferior del cuadro de diálogo de apertura de archivos.

Temas relacionados:

File > Open (Construction Lines).

File > Save As.
