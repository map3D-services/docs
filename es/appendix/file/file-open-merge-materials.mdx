---
title: "Archivo > Abrir > Combinar materiales"
---

Si esta opción está marcada, al cargar el nuevo archivo de modelo, los datos de materiales del nuevo archivo se combinan con los datos de materiales actuales.

Si esta opción no está marcada, al cargar el nuevo archivo de modelo, los datos de materiales del nuevo archivo reemplazan los datos de materiales actuales.

Esto permite mantener los modelos de materiales en archivos de datos independientes e incorporarlos a los modelos según sea necesario.

Temas relacionados:

File > Open > Merge Geometries.
