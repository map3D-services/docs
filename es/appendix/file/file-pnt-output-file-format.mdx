---
title: "Archivo > Formato de archivo de salida PNT"
---

El formato PNT es un archivo de datos ASCII universal con la extensión ".PNT".

Este formato es útil para intercambiar datos sin procesar del modelo con otro software CAD.

Las líneas de comentario comienzan con un asterisco "*" en la columna 1.

Las superficies se almacenan como una serie de polilíneas de la siguiente manera:

x1 y1 z1 3 value1 x2 y2 z2 2 value2 x3 y3 z3 2 value3 x4 y4 z4 2 value4

xI yI zI representan las coordenadas de cada punto.

3 indica que este punto es el inicio de una nueva línea. 2 indica que este punto es una continuación de la misma línea. valuei en el caso de entidades geométricas representa el número de color de la superficie

En el caso de contornos, representa el valor del parámetro contorneado en cada esquina de la superficie.
