El formato PNT es un archivo de datos ASCII universal con la extensión ".PNT".

Este formato es útil para intercambiar datos sin procesar del modelo con otro software CAD.

Las líneas de comentario deben comenzar con un asterisco "*" en la columna 1.

Los bloques FF y los planos DD de Map3D se almacenan como una serie de polilíneas de la siguiente manera:

**x1 y1 z1 3 colour mtype x2 y1 z1 2 x3 y3 z3 2 x4 y4 z4 2 x5 y5 z5 1 x6 y6 z6 1 x7 y7 z7 1 x8 y8 z8 1**

donde **xi yi zi** representan las coordenadas de cada punto,

- **3** indica que este punto es el inicio de una nueva polilínea,

**2** indica que este punto forma parte de la base del bloque,

- **1** indica que este punto forma parte de la parte superior del bloque. Este elemento solo se usa para definir formas de bloques 3D.

**colour** especifica el número de color que se usará para mostrar el bloque.

Hay un total de 10 colores disponibles para la visualización.

- Se numeran del 1 al 10, del 11 al 20, del 21 al 30, etc., de modo que se muestra el mismo color para los números 1, 11, 21, 31..., 2, 22, 32..., etc.

**mtype** especifica el tipo de elemento de contorno que se usará para el bloque.

Para elementos tridimensionales, como excavaciones, zonas de material alternativo, tajeos rellenados, etc., se deben usar elementos de fuerza ficticia (Fictitious Force) de tipo 1

CAD > Build > Block y CAD > Build > Block para obtener más detalles.

- Se deben usar elementos de discontinuidad de desplazamiento (Displacement Discontinuity) de tipo 2 para excavaciones de minería tabular, fracturas y planos de falla

CAD > Build > DDLoop para obtener más detalles.

Los elementos inactivos (98 para bloques 3D inactivos y 99 para planos DD inactivos) se pueden usar para mostrar elementos que se incluyen solo con fines de visualización y que no se usan en el análisis de esfuerzos propiamente dicho.

Las polilíneas adicionales se especifican repitiendo la secuencia (es decir, iniciando una nueva línea con el número **3** ).

#### Notas

Se deben usar distintos números de color para representar agrupaciones lógicas de bloques (por ejemplo, para distintos niveles, secciones o unidades lógicas de minería, como desarrollo, tajeo, etc.). Estos colores son definibles por el usuario mediante

#### Tools > Custom Colours

Map3D combina automáticamente los bloques con el mismo número de color en formas complejas únicas.

Como es fácil activar y desactivar la visualización de números de color específicos de bloques, esto ofrece un método eficiente para trabajar con datos complejos del modelo
