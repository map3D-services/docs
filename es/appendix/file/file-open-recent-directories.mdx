---
title: "Archivo > Abrir > Directorios recientes"
---

Cada vez que se abre un archivo de modelo o un archivo de reinicio, su directorio de trabajo se guarda para acceder a él rápidamente en una sesión posterior. Para volver a abrir uno de estos directorios, basta con elegirlo de la lista.

Temas relacionados:

File > Open > Recent Files
