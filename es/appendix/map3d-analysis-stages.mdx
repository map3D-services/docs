---
title: "Etapas de análisis de Map3D"
---

Un análisis en Map3D se desarrolla en cinco etapas:

#### Etapa 1 – Construcción y edición del modelo

Esta etapa sirve para configurar el análisis de Map3D.

#### Analysis > Go to CAD

Se pueden agregar nuevos bloques de explotación y editar los existentes mediante las funciones CAD integradas en Map3D. Esto incluye túneles, excavaciones grandes de forma irregular, zonas de mineral, excavaciones masivas y tabulares, tajos abiertos, fallas, fracturas y más.

Se pueden guardar distintas partes del modelo en archivos de componentes independientes y fusionarlas para el análisis final.

#### Analysis > Load Model

En esta etapa se asignan las propiedades de los materiales y se configura la secuencia de explotación deseada. Esto puede incluir la colocación de mineral, la excavación y el relleno.

Las mallas de puntos de campo se ubican en las posiciones donde se desean resultados fuera de la veta. En el caso de excavaciones tabulares, a menudo solo se requieren resultados sobre la veta, por lo que las mallas de puntos de campo son opcionales.

#### Etapa 2 – Análisis de contactos e intersecciones

#### Analysis > Intersections.

Se generan intersecciones entre los bloques que se cortan entre sí. Se realizan operaciones booleanas para resolver la secuencia de explotación. Se lleva a cabo una verificación exhaustiva de la integridad del modelo.

#### Etapa 3 – Discretización de bloques y mallas

#### Analysis > Discretization.

El modelo se discretiza en elementos de contorno para el análisis BEM. Se tiene control total sobre la forma en que se discretiza el modelo. La discretización puede realizarla automáticamente el programa, concentrando los elementos solo donde se solicitan resultados, o especificarse manualmente.

#### Etapa 4 – Análisis BEM de Map3D

#### Analysis > BEM Analysis.

Realiza el análisis de elementos de contorno. Los mismos datos de entrada se pueden usar para análisis elástico, térmico/de flujo de fluidos o no lineal

#### Etapa 5 – Posprocesamiento

#### Analysis > Graphics.

Esta etapa sirve para visualizar y procesar los resultados del análisis de Map3D. Se pueden generar gráficos de contornos de esfuerzo, deformación, desplazamiento y factores de resistencia, o cualquier combinación de estas componentes, sobre superficies de contorno y sobre mallas de puntos de campo definidas por el usuario. Los resultados se pueden mostrar como valores totales o como la diferencia de valor entre etapas de explotación.

Se pueden cargar resultados de análisis anteriores para visualizarlos

File > Open Analysis Results.
