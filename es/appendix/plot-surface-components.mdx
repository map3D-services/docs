Active la barra de herramientas de componentes de superficie, después del análisis BEM de Map3D.

Esta barra de herramientas ofrece acceso rápido a los gráficos de componentes de superficie.

Plot > Surface Components > Serr Error de esfuerzo Plot > Surface Components > Ferr Error de falla Plot > Surface Components > Ts Esfuerzo cortante Plot > Surface Components > Sn Esfuerzo normal

Plot > Surface Components > Es Deformación cortante Plot > Surface Components > En Deformación normal Plot > Surface Components > Ds Desplazamiento cortante (deslizamiento) Plot > Surface Components > Dn Desplazamiento normal (cierre)

Plot > Surface Components > Strength/Stress Plot > Surface Components > dTs Esfuerzo cortante en exceso Plot > Surface Components > dEs Deformación cortante incremental Plot > Surface Components > dTs / dEs Tasa de esfuerzo/deformación Plot > Surface Components > Temperature/Head Plot > Surface Components > qn Flujo normal Plot > Surface Components > Value > Elastic Plot > Surface Components > Value > Plastic Plot > Surface Components > Value > Total

#### Notas:

La barra de herramientas de componentes de superficie solo se puede activar después de la etapa de construcción del modelo (CAD)

Etapas de análisis de Map3D

Cualquiera de estas componentes se puede agregar a la barra de herramientas de contornos si se desea
