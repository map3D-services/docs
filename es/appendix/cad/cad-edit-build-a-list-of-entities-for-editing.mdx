---
title: "CAD > Editar > Crear una lista de entidades para editar"
---

Esta rutina se puede iniciar seleccionando cualquier función de edición (por ejemplo, un botón) o simplemente haciendo clic derecho sobre cualquier entidad.

Al iniciar cualquier rutina de edición de entidades, primero se solicita crear una lista de las entidades que se desea editar

![Figure from page 132](/images/page-132-img-1.png)

- Si Tools > Shift-key Selection está marcado, se debe mantener presionada la tecla Shift para realizar selecciones múltiples.

- De forma predeterminada, las entidades seleccionadas se agregan a la lista; sin embargo, si se mantiene presionada la tecla Ctrl, las entidades seleccionadas se eliminan de la lista.

- Mientras se mantiene presionada la tecla Shift o Ctrl, se puede arrastrar para abrir una ventana de cruce.

- Al presionar la barra espaciadora se activa automáticamente la última función de edición utilizada.

- Al mantener presionada la tecla Alt mientras se hace clic derecho, se repite automáticamente la última función de edición utilizada.

Esta barra de herramientas controla las diversas funciones que se usan para crear la lista.

Cancela la edición. Selecciona entidades eligiendo una superficie a la vez. Selecciona entidades eligiendo los grupos completos que forman un bloque. Incluye todas las entidades con el número seleccionado.

Incluye todas las entidades con el color seleccionado.

Incluye todas las entidades con el número de material seleccionado.

- Un mismo bloque puede tener materiales distintos según el paso de minería activo en ese momento.

- Al usar esta función, asegúrese de seleccionar el paso de minería apropiado File > Mining Step

Incluye todas las entidades excavadas con el número de paso de minería seleccionado.

Incluye todas las entidades dentro de la ventana seleccionada.

- Las entidades solo se seleccionan si están contenidas por completo dentro de la ventana.

- Si el (modo de selección de superficies) está activo, solo se incluyen las superficies.

- Si el (modo de selección de entidades) está activo, se incluyen todas las superficies que forman el bloque.

Incluye todas las entidades dentro de la ventana de cruce.

- Las entidades se seleccionan aunque solo una parte de la entidad esté dentro de la ventana.

- Esta función también se puede activar manteniendo presionada la tecla Shift o Ctrl y arrastrando para abrir una ventana de cruce.

- Si el (modo de selección de superficies) está activo, solo se incluyen las superficies.

- Si el (modo de selección de entidades) está activo, se incluyen todas las superficies que forman el bloque.

- Las entidades seleccionadas se agregan a la lista.

Las entidades seleccionadas se eliminan de la lista. Deshace la última selección.

Rehace la última selección.

Una vez seleccionadas las entidades deseadas, se puede elegir cualquiera de los botones de edición:

CAD > Edit > Entity Properties Edita el tipo de bloque, el color, la secuencia de minería, etc.

CAD > Edit > Erase Entities Borra las entidades seleccionadas. CAD > Edit > Move Entities Mueve las entidades seleccionadas. CAD > Edit > Copy Entities Copia las entidades seleccionadas. CAD > Edit > Scale Entities Escala las entidades seleccionadas. CAD > Edit > Rotate Azimuth Rota el azimut de las entidades seleccionadas. CAD > Edit > Rotate Dip Rota el buzamiento de las entidades seleccionadas. CAD > Edit > Dump to File Vuelca las entidades seleccionadas a un archivo. CAD > Edit > Group Agrupa las entidades seleccionadas en un solo bloque.

- haga doble clic en cualquier vértice para ejecutar la función resaltada,

- haga clic derecho para ver una lista de opciones.

Una vez completada cualquier operación de edición, se tiene una oportunidad de deshacer las modificaciones seleccionando

#### Undo

También se puede restaurar el mismo conjunto de selección y modificar de nuevo el mismo conjunto de entidades seleccionando

Redo

Se puede ajustar el tiempo de doble clic mediante

Tools > Double Click Time
