---
title: "CAD > Construir"
---

Activa la barra de herramientas Build.

Esta barra de herramientas ofrece acceso rápido a las funciones de construcción de entidades que se usan en la etapa de construcción y edición del modelo del análisis BEM de Map3D Analysis > Go to CAD.

CAD > Build > FF Loop Construye un bloque 3D de tipo FF con varias esquinas, que se usa para excavaciones y zonas de material alternativo.

CAD > Build > DD Loop Construye un bloque de tipo DD con varias esquinas, que se usa para minería tabular, vetas delgadas o planos de falla.

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane Construye un plano de malla donde se calculan los resultados del análisis.

![Figure from page 320](/images/page-320-img-13.png)

CAD > Build > Grid Line Construye una línea de malla donde se calculan los resultados del análisis.

CAD > Build > Construction Lines Construye líneas de construcción para definir ubicaciones detalladas de elementos subterráneos, como excavaciones, contactos, estructuras, etc.

CAD > Build > Enter Point Ingresa los valores de coordenadas de un punto.

CAD > Build > Offset Remaining Desplaza los puntos restantes.

CAD > Build > Undo Point Deshace la última selección de punto.

CAD > Build > Redo Point Rehace la última selección de punto.

Al presionar la barra espaciadora se activa automáticamente la última función de construcción o edición utilizada.
