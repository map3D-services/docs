---
title: "CAD > Editar > Propiedades de entidad > Espesor del plano DD"
---

Especifica el espesor del material insertado en el elemento DD (es decir, relleno de falla, ancho de veta, ancho de explotación o altura de pilar).

El desplazamiento normal (cierre) de la estructura cuando está rellena se limitará a este espesor. Además, el desplazamiento normal (cierre) y el desplazamiento de corte (deslizamiento) se dividen entre el espesor para determinar la deformación que ocurre en el material de relleno.

Este parámetro se debe especificar en las mismas unidades que se usan para especificar las posiciones de las coordenadas (por ejemplo, metros o pies). Este parámetro no se usa en bloques 3D FF.

Temas relacionados:

CAD > Edit > Entity Properties
