---
title: "Análisis > Gráfico automático"
---

Activa la función de gráfico automático.

Cuando se marca, Map3D grafica automáticamente las componentes de superficie seleccionadas a medida que avanza el análisis BEM de Map3D. Se puede graficar cualquier componente de superficie. De forma predeterminada se grafica el error de esfuerzo en la superficie

Plot > Surface Components > Serr Stress Error.

Para cambiar la componente de superficie que se grafica:

1. Durante el análisis, seleccione Analysis > Suspend

2. Seleccione la componente deseada en la barra de herramientas de solución Tools > Solve Toolbar

3. Para continuar el análisis, seleccione Analysis > Resume

Notas

Debe marcar Tools > Solve Toolbar para que se muestre la barra de herramientas de solución cuando suspenda el análisis.

Para que Map3D modifique automáticamente el rango de contornos a medida que avanza el análisis BEM de Map3D, marque Analysis > Auto Range
