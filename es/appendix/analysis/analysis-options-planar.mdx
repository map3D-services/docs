---
title: "Análisis > Opciones > Planar"
---

Subdivide los cuadriláteros no planos en triángulos, durante el análisis de intersecciones.

Las superficies moderadamente no planas no representan un problema para Map3D. Sin embargo, el alabeo extremo de las superficies puede interferir con el análisis de intersecciones.

#### Notas

Esta función debe estar activada antes de realizar el análisis de intersecciones

Analysis > Intersections.

Esto puede aumentar el tamaño del problema y, por tanto, el tiempo de análisis.

Se recomienda no activar esta opción, a menos que quieras eliminar específicamente las características no planas.
