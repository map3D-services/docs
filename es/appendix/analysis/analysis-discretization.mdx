Discretiza el modelo.

Todas las superficies de excavación se discretizan automáticamente concentrando elementos donde se solicitan resultados

View > Render > Discretize

Los resultados del análisis se calculan en superficies DD y en una serie de planos de malla definidos por el usuario

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane

o en puntos definidos por el usuario

#### Analysis > Options > MSCALC

Los planos de malla se discretizan automáticamente en una serie de puntos de campo en los que se calculan desplazamientos, deformaciones y esfuerzos.

El análisis de discretización se puede repetir tantas veces como se desee con distintos parámetros de control.

El usuario tiene control total sobre la forma en que se discretiza el modelo mediante la especificación de varios parámetros de control (longitud del elemento _AL_ , espaciamiento de la malla _AG_ , discretización del elemento _DON_ , discretización de la malla _DOL_ )

#### Analysis > CParams

y mediante la especificación del ancho máximo de elemento para bloques FF 3D y planos DD

CAD > Edit > Entities > Maximum Element Width

así como para las mallas de puntos de campo

CAD > Edit > Entities > Maximum Element Width

Consulte Discretization and Lumping para una explicación detallada de cómo definir estos parámetros de control.

Opciones:

Analysis > Options > MSCALC Analysis > Options > LERD/LSS Analysis > Options > Lumping

Temas relacionados:

Analysis Dialog Analysis > Suspend Analysis > ABORT Analysis > Restart
