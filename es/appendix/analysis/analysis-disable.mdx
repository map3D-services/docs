---
title: "Análisis > Deshabilitar"
---

Deshabilita los elementos de contorno cuyo error de esfuerzo en la superficie ( _Serr_ ) es mayor que diez veces el valor cuadrático medio ( _Rms_ ) de todos los elementos.

Durante la solución de la matriz, Map3D intenta resolver progresivamente las ecuaciones simultáneas guardadas en la matriz de coeficientes, junto con cualquier otra ecuación que describa las zonas de material alterno, el deslizamiento de fallas, la fluencia, etc. Se supone que se ha obtenido una solución convergente cuando el error máximo de esfuerzo en la superficie y el error máximo del criterio de falla se reducen por debajo de la tolerancia de esfuerzo _STOL_ especificada por el usuario

Analysis > CParams > STOL

En algunos problemas, ciertos elementos no convergen a una solución debido a un acondicionamiento numérico excesivamente deficiente. Si el nivel de precisión actual le resulta aceptable, puede forzar una solución marcando esta opción.

Esta función indica a Map3D que deshabilite los elementos con valores de _Serr_ > 10 _Rm_ s. Pocas iteraciones después de ejecutar esta función, pueden aparecer otros elementos con el mismo problema, lo que obliga a ejecutarla de nuevo. Después de algunas repeticiones, todos los elementos quedarán deshabilitados y la solución podrá avanzar hasta la convergencia.

Use esta función con extrema precaución, ya que los resultados contendrán errores numéricos que podrían ser significativos.

Notas:

Puede mostrar la distribución del error de esfuerzo en la superficie seleccionando

Plot > Surface Components > Serr Stress Error

en la barra de herramientas de solución.

Puede mostrar la distribución del error del criterio de falla seleccionando

Plot > Surface Components > Ferr Failure Error

en la barra de herramientas de solución.

Durante el análisis, la barra de herramientas de solución se muestra al suspender el análisis

Analysis > Suspend

solo si se ha marcado
