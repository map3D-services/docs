title: "Análisis > Opciones > Unidad #"
---

Especifica las unidades de trabajo para la matriz de coeficientes – durante el análisis BEM de Map3D.

Si tiene varias unidades de disco instaladas, puede usar esta opción para indicar a Map3D dónde almacenar la matriz de coeficientes. Cuando la primera unidad se llena, Map3D escribe el resto de la matriz en la siguiente unidad de trabajo.

Cuando la matriz de solución es demasiado grande para caber en la RAM (consulte Analysis > Options > VRAM y Analysis > Options > PRAM) , la solución de la matriz se convierte en una operación intensiva en E/S que depende únicamente de la velocidad de E/S de su computadora. En este caso, una gran parte del tiempo de análisis puede dedicarse a la etapa de solución debido al bajo rendimiento del disco.

Para superar este problema, es imprescindible instalar varios discos de alta velocidad.

Map3D admite totalmente el procesamiento en paralelo y la E/S de disco en paralelo con la opción multiprocesador/multiunidad.

Si tiene licencia para usar la opción multiprocesador/multiunidad, Map3D configura estas unidades en una matriz RAID de modo que la E/S se realice de forma superpuesta en todas las unidades, en paralelo con los cálculos.

Con esta configuración, puede aumentar el rendimiento de E/S en proporción al número de unidades de la matriz.

En la siguiente prueba comparativa, el mismo modelo se ejecuta con 1, 2 y 4 discos.

||1 disco|2 discos|4 discos|8GB PRAM|
|---|---|---|---|---|
|Rendimiento de disco medido (MB/s)|55|112|206|3000 equivalente|
|Solución de la matriz (horas)|0.546|0.282|0.163|0.033|
|Aumento de la velocidad de solución|1x|1.9x|3.3x|16x|
|Tiempo total de análisis (4 núcleos)|0.640|0.376|0.257|0.107|
|Aumento total de velocidad|1x|1.7x|2.5x|6x|

Los discos usados en esta prueba comparativa son unidades más antiguas de 50-60 MB/s (Seagate Barracuda 7200.7). Las unidades mecánicas más recientes alcanzan los 100 MB/s (Seagate Momentus 7200.4). Los SSD SATA2 pueden ofrecer más de 250 MB/s por unidad. Los SSD SATA3 pueden ofrecer más de 500 MB/s por unidad. Se puede esperar que varios SSD y/o unidades NVMe sean casi tan rápidos como la PRAM. Tenga en cuenta que algunas placas base tienen limitaciones en el rendimiento combinado total y pueden requerir adaptadores de controladora adicionales.

Para determinar si tiene licencia para usar la opción multiprocesador/multiunidad, consulte Analysis > Options > #Threads.

Si tiene licencia para usar la opción multiprocesador/multiunidad, se pueden lograr velocidades de disco más altas si establece el privilegio SE_MANAGE_VOLUME_NAME.

Esta capacidad está disponible en las siguientes versiones de Windows:

- Windows NT 4.0, Windows 2000 Professional y Server (máximo de 4 GB).

- Windows 2000 Advanced Server (máximo de 8 GB).

- Windows 2000 Datacenter Server (máximo de 32 GB).

- Windows XP Professional y Windows Server 2003 (máximo de 4 GB).

- Windows Server 2003 Enterprise Edition (máximo de 32 GB).

- Windows Server 2003 Datacenter Edition (máximo de 64 GB).

- Windows 10 y 11 Pro (la versión Home no lo admite).

Para establecer el privilegio "SE_MANAGE_VOLUME_NAME", siga estos pasos:

Control Panel > Administrative Tools > Local Security Policies

Luego establezca

Local Policies > User Rights Assignment > Perform Volume Maintenance Tasks > Add User or Group > Everyone

Debe reiniciar para que este ajuste surta efecto.

Notas:

Esta función debe estar marcada antes de realizar el análisis BEM de Map3D

#### Analysis > BEM Analysis

Debe especificar la unidad más rápida de su sistema. Puede probar el rendimiento de su unidad con

Tools > Disk Performance Test
