---
title: "Cuadro de diálogo de análisis"
---

Muestra un cuadro de diálogo desplazable con la actividad del análisis, que incluye:

INFO: mensajes que describen las operaciones en curso. WARNING: mensajes que describen posibles inconsistencias que pueden causar problemas.

ERROR: mensajes que describen errores que provocarán la terminación de la ejecución del programa.

Durante la solución de la matriz, Map3D intenta resolver progresivamente las ecuaciones simultáneas guardadas en la matriz de coeficientes, junto con cualquier otra ecuación que describa las zonas de material alterno, el deslizamiento de fallas, la fluencia, etc. Se supone que se ha obtenido una solución convergente cuando el error máximo de esfuerzo en la superficie

Plot > Surface Components > Serr Stress Error

y el error máximo del criterio de falla

Plot > Surface Components > Ferr Failure Error

se reducen por debajo de la tolerancia de esfuerzo _STOL_ especificada por el usuario

Analysis > CParams > STOL

A medida que avanza la solución, se muestra información resumida sobre ella:

is=1   it=3   ser=-1.29E+01   fer= 0.00E+00   rms=5.85E+00   ratio=0.414   converging

is - número del paso de tiempo actual.

- Este contador solo se usa en análisis de fluencia no lineales (incluidos el deslizamiento de fallas y la no linealidad de materiales 3D).

- Map3D usa un método de solución implícito para resolver la parte viscoplástica de los problemas de fluencia.

- Cada vez que Map3D alcanza una solución de fluencia en equilibrio, los incrementos de deformación por fluencia se suman a las deformaciones plásticas totales y se inicia un nuevo paso de tiempo (es decir, se incrementa el contador is).

it - conteo de iteraciones actual.

- Map3D usa un método de solución iterativo para resolver las ecuaciones simultáneas guardadas en la matriz de coeficientes.

- Este contador indica el número acumulado de iteraciones ejecutadas.

ser - error máximo de esfuerzo en la superficie.

- Los solucionadores iterativos determinan el error de la solución actual de cada ecuación simultánea y luego reducen esos errores mediante un proceso de aproximaciones sucesivas.

- Este parámetro indica el error máximo de todas las ecuaciones.

fer - error máximo del criterio de falla.

- Este parámetro solo se usa en análisis de fluencia no lineales (incluidos el deslizamiento de fallas y la no linealidad de materiales 3D).

- Este parámetro siempre debe estar cerca de cero, a menos que se haya especificado alguna viscosidad y el problema se vuelva no lineal.

- En este último caso, la fluencia viscosa puede permitir estados de esfuerzo por encima del criterio de falla, lo que indica una falta de equilibrio estático.

- Este parámetro indica el esfuerzo viscoso máximo de todas las ecuaciones.

rms - raíz cuadrática media de todos los errores de esfuerzo en la superficie.

ratio - razón entre el valor actual de rms y el valor de rms en la iteración anterior.

- Esto indica la rapidez con que avanza la solución.

converging - indicador de que el problema converge.

- Este indicador también puede mostrar diverging si la razón es mayor que uno.

Notas:

Como el desplazamiento suave limita la velocidad a la que se puede escribir información en el área de información, puede ralentizar considerablemente el análisis de Map3D. Se recomienda no usar el desplazamiento suave

Tools > Smooth Scroll
