---
title: "Análisis > Opciones > P-RAM"
---

Almacena parte de la matriz de coeficientes en RAM física, durante el análisis BEM de Map3D.

Si tu equipo tiene instalada una gran cantidad de RAM, esta opción puede acelerar significativamente la ejecución, ya que los datos se recuperan de la RAM mucho más rápido que del disco. Aunque Windows de 32 bits solo permite que cada proceso direccione 2 GB, los usuarios con grandes cantidades de RAM en su equipo pueden acceder a la RAM física mediante AWE (Address Windowing Extensions). AWE permite acceder a toda la RAM disponible en tu equipo. La mayoría de los sistemas admiten 4 GB de RAM. Algunos admiten más de 64 GB. Las diversas versiones de Windows ofrecen distintos niveles de compatibilidad con AWE, desde 1 GB hasta 512 GB. La compatibilidad con AWE está disponible en las siguientes versiones de Windows:

- Windows 10 Professional y Server (máximo de 4 GB).

- Windows NT 4.0, Windows 2000 Professional y Server (máximo de 4 GB).

- Windows 2000 Advanced Server (máximo de 8 GB).

- Windows 2000 Datacenter Server (máximo de 32 GB).

- Windows XP Professional y Windows Server 2003 (máximo de 4 GB).

- Windows Server 2003 Enterprise Edition (máximo de 32 GB).

- Windows Server 2003 Datacenter Edition (máximo de 64 GB).

- Windows 7 y 8.

- Windows 10 y 11 Pro (la versión Home no admite esta función).

AWE requiere el privilegio "SE_LOCK_MEMORY". Para habilitar AWE, sigue estos pasos:

Control Panel > Administrative Tools > Local Security Policies

Luego establece

Local Policies > User Rights Assignment > Lock Pages in Memory > Add User or Group > Everyone

Debes reiniciar para que esta configuración surta efecto.

Notas:

Esta función debe estar activada antes de realizar el análisis BEM de Map3D

#### Analysis > BEM Analysis.

Solo debes asignar la cantidad de RAM que quieras que use Map3D, y dejar espacio suficiente para cualquier otra aplicación que pienses ejecutar.

Nunca debes establecer este parámetro por encima de la RAM disponible, ya que esto provoca una paginación excesiva del sistema operativo que ralentiza significativamente el análisis.
