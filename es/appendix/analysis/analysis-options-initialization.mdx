---
title: "Análisis > Opciones > Inicialización"
---

Inicializa el modelo para que el análisis continúe desde donde terminó un análisis anterior.

Esta opción te permite iniciar un nuevo análisis desde donde terminó un modelo anterior. Todos los componentes no lineales, de deformación cero y de carga sísmica (la carga sísmica solo en Map3Di) se transfieren al nuevo modelo desde el análisis anterior.

Para que esta función opere correctamente, el nuevo modelo debe tener todos los datos del modelo (geometría) que tiene el modelo de inicialización, además de cualquier dato nuevo, etapa de explotación o malla. No es necesario usar la misma discretización ni los mismos planos de malla.

Para inicializar, los siguientes archivos deben estar intactos:

file.00n, donde n representa el número de la etapa de explotación en la que terminó el análisis anterior. file.dms, este archivo solo se usa con la opción de deformación cero (Analysis > Options > Zero Strain Support Placement).

file.hms, este archivo solo lo usa Map3Di y sirve para acumular la carga de campo a medida que avanza el análisis.

Notas:

Esta función debe estar activada antes de realizar el análisis BEM de Map3D

#### Analysis > BEM Analysis

Esta opción requiere cálculos adicionales y, por lo tanto, aumenta el tiempo de análisis.

Consulta Analysis > Options > Restart para reiniciar un análisis que se abortó o se interrumpió por un corte de energía o una falla del sistema operativo.
