Usa las rutinas de E/S asíncrona de Windows – durante el análisis BEM de Map3D.

Windows permite realizar la E/S de disco de forma asíncrona respecto del análisis BEM. En teoría, esto permite que la E/S de disco se realice en paralelo con otros cálculos, lo que reduce el tiempo de solución de la matriz.

Notas:

Esta función debe estar marcada antes de realizar el análisis BEM de Map3D
