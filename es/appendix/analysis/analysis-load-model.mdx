---
title: "Análisis > Cargar modelo"
---

Carga un modelo desde un archivo (formato INP o DXF). Una vez cargado, puede usar

Analysis > Go to CAD

para agregar o editar bloques de minado y configurar el análisis de Map3D.

Al cargar el modelo, Map3D comprueba la consistencia básica de los parámetros de modelado (p. ej., si se usa un material, sus propiedades deben estar especificadas en la lista de materiales).

Opciones:

Analysis > Options > Reunmber Analysis > Options > Collinearity

Temas relacionados:

Analysis Dialog Analysis > Suspend Analysis > ABORT
