Realiza el análisis de contacto e intersección.

Una de las claves de la facilidad de uso de Map3D es la construcción de modelos mediante tecnología de modelado de sólidos. Esto permite construir modelos con una serie de bloques tridimensionales y planos DD. Estas entidades, que pueden tener cualquier forma, tamaño y orientación, se usan para construir excavaciones y accesos, así como para definir zonas no homogéneas (p. ej., zonas de mineral, diques y zonas de fluencia). El programa construye automáticamente las intersecciones entre excavaciones, fallas y múltiples zonas de material. Al combinar esta capacidad con las operaciones booleanas integradas, se pueden construir con facilidad secuencias de minado complejas de varios pasos.

Opciones:

Analysis > Options > Collapse Analysis > Options > Planarity Analysis > Options > Closure
