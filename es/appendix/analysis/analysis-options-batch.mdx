title: "Análisis > Opciones > Lote"
---

Configura la cola de lotes de análisis.

Si tiene varios modelos que deben ejecutarse, puede especificarlos en esta cola de lotes. Al seleccionar

Analysis > Options > Batch > Execute Batch Queue

se ejecutarán todos los modelos marcados sin solicitar ninguna respuesta interactiva del usuario.

Al marcar un archivo de lote para su ejecución, se le pedirá que busque el nombre, la ubicación y el formato del archivo del modelo. Si la búsqueda tiene éxito, el modelo quedará marcado.

La segunda columna del cuadro de diálogo Batch File Setup permite establecer opciones de análisis si lo desea. Estos ajustes anulan cualquier opción establecida en el cuadro de diálogo Analysis > Options.

#### Modo de consola:

Map3D se puede iniciar desde el símbolo del sistema de Windows o desde un archivo *.bat, si lo desea. Las opciones de línea de comandos se pueden usar en un script de archivo de texto o escribirse en un símbolo del sistema. El procedimiento consiste simplemente en crear un archivo *.bat de la siguiente manera:

**Map3D filename.inp -option1 - option2 ...** (donde "filename.inp" es el nombre del archivo del modelo que desea analizar).

Las opciones son las siguientes:

- **-analysis** (indica a Map3D que ejecute un análisis; también debe indicar "filename.inp").

- **-console** (muestra solo el "Analysis Dialog" mientras Map3D se ejecuta).

   - (no muestra nada mientras Map3D se ejecuta y se detiene al terminar el análisis).

- **-stop** (detiene Map3D al terminar el análisis).

También puede abrir archivos de resultados de la siguiente manera:

**Map3D filename.001** (donde "filename.001" es el nombre del archivo de resultados que desea mostrar).

Por ejemplo, si desea ejecutar un análisis de Map3D mostrando solo una ventana de registro, lo iniciaría de la siguiente manera:

#### Map3D filename.inp -console -analysis

Por ejemplo, si desea ejecutar un análisis de Map3D sin mostrar ninguna ventana de registro, lo iniciaría de la siguiente manera:

#### Map3D filename.inp -silent -analysis

#### Notas:

Los nombres de los archivos de modelo del lote se guardan y se restauran cada vez que se ejecuta Map3D.

Los archivos de modelo que no estén marcados no se ejecutarán en modo de lote.

La cola de lotes se puede interrumpir en cualquier momento simplemente abortando el análisis actual

Analysis > Abort
