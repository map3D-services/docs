---
title: "Traslación del modelo"
---

Traslación del modelo - El modelo se puede trasladar manteniendo presionado el botón derecho del mouse y esperando

a que aparezca el puntero de arrastre; luego se arrastra para trazar un vector de desplazamiento. Al arrastrar hacia arriba o hacia abajo, el modelo se traslada hacia arriba o hacia abajo. Al arrastrar hacia la izquierda o hacia la derecha, el modelo se traslada hacia la izquierda o hacia la derecha.

Zoom del modelo - El modelo se puede acercar o alejar girando la rueda del mouse, o manteniendo presionados a la vez los botones izquierdo y derecho del mouse y esperando

a que aparezca el puntero de arrastre; luego se arrastra para definir un factor de zoom. Al arrastrar hacia arriba, el modelo se aleja. Al arrastrar hacia abajo, el modelo se amplía.

El modelo también se puede trasladar y ampliar con la barra de herramientas de traslación o con las teclas del teclado

Tools > Translation Toolbar
