**Map3D Modeller** - ofrece capacidades de CAD 3D y base de datos visual.

Se incluye con todas las versiones de Map3D.

El sistema CAD 3D, fácil de usar (gráficos basados en OpenGL), incluye dibujo a mano alzada o selección de objetos para construir y editar 5 tipos básicos de entidades:

- bloques 3D (p. ej., tajeos, zonas de mineral, diques, túneles),

- características 2D (p. ej., fallas, explotación tabular, topografía, fracturas)

- planos de malla (p. ej., secciones transversales)

- líneas de malla (p. ej., sondajes, sostenimiento del terreno)

- líneas de construcción (p. ej., datos topográficos, líneas centrales de galerías)

Incluye un conjunto completo de funciones de edición, como copiar, mover, estirar, aplanar, escalar, rotar y más. Ofrece capacidad completa de importación y exportación de dxf y pnt para intercambiar datos con otros programas CAD.

La base de datos visual se puede usar para mostrar una base de datos con cualquier información deseada, incluida información sísmica o geológica como la ley, la calidad del macizo rocoso, etc. Los puntos 3D se pueden etiquetar con una serie de:

- valores numéricos (p. ej., color, magnitud, orientación, etc.),

- palabras clave (para filtrar),

- mensajes de texto,

- nombres de archivo (p. ej., archivos de gráficos, documentos, hojas de cálculo, etc.).

La visualización de estos elementos se puede filtrar de varias maneras. La ubicación de cada punto se puede mostrar como esferas o cuadrados sombreados en color. El tamaño y el color se pueden escalar según distintas combinaciones de parámetros. La densidad de magnitud de los puntos se puede representar con contornos sobre un plano según una función de densidad definida por el usuario. Se puede ajustar un plano de mejor ajuste mediante regresión lineal.

**Map3D Results Viewer** - ofrece visualización independiente de los resultados del análisis de esfuerzos.

Se incluye con todas las versiones de Map3D.

Incluye la base de datos visual, pero no el sistema CAD.

- visualiza los resultados de análisis de esfuerzos generados por cualquiera de los códigos de análisis de Map3D

- muestra contornos en planos de corte, a lo largo de líneas y en puntos específicos

- funciones de contorno definidas por el usuario

- vínculo directo a Excel para graficar en x-y

- visualización de trayectorias 3D

- visualización de todos los parámetros de esfuerzo, deformación, desplazamiento y resistencia, incluidas las componentes principales y los valores resultantes, en planos y líneas definidos por el usuario.

- exportación en formatos dxf y pnt para compatibilidad con otros sistemas CAD y de visualización

- contornos de probabilidad de falla

- contorno de factor de seguridad

- modelos con sombreado de fuente de luz

- contornos topográficos

**Map3D Fault-Slip** - agrega capacidades de análisis de esfuerzos en macizo rocoso elástico y fallas con deslizamiento totalmente plástico.

Incluye el modelador CAD 3D, el visualizador de resultados y la base de datos visual.

El análisis de esfuerzos utiliza el BEM (método de elementos de contorno) y tiene muchas características:

- capacidad de analizar problemas de tamaño muy grande (un millón de grados de libertad)

- formas de excavación 3D complejas y completas

- múltiples zonas elásticas con distintos módulos (diques rígidos o mineral blando)

- zonas con diferentes estados de esfuerzo previos a la explotación

- explotación tabular con pilares en fluencia

- planos de falla discretos no planares que se deslizan y se dilatan de forma elasto-visco-plástica (incluida la fluencia lenta)

- múltiples etapas de explotación (40)

- intersecciones automáticas que permiten que excavaciones y fallas se crucen y se superpongan

Hay disponible una versión de demostración de Map3D Fault-Slip sin cargo. Están disponibles todas las funciones, pero solo se permite ejecutar problemas de tamaño pequeño. Esta versión es sumamente útil para enseñar los fundamentos del modelado y del CAD 3D.

**Map3Di Integrated Seismicity** - permite superponer efectos de carga de campo externos en el análisis de esfuerzos.

Incluye todas las capacidades de Map3D Fault-Slip y agrega los efectos de carga de campo. La carga de campo puede provenir del calentamiento térmico, la presión de fluidos, el comportamiento no lineal y las deformaciones indicadas por la sismicidad. Estos efectos se pueden usar para caracterizar características geológicas, adaptarse a cambios de litología e incorporar los efectos de la carga sísmica en el análisis de esfuerzos.

**Map3D Thermal-Fluid Flow** - agrega análisis de esfuerzos térmicos y flujo de fluidos.

Incluye todas las capacidades de Map3D Fault-Slip y agrega la solución simultánea de esfuerzos térmicos y flujo de fluidos en estado estacionario. El programa está configurado de modo que solo se necesita especificar las condiciones de contorno de temperatura/carga hidráulica, y luego se resuelve simultáneamente el problema de esfuerzos térmicos. Esta función es útil para simular efectos de calentamiento/enfriamiento y la respuesta drenada/no drenada.

**Map3D Non-Linear** - agrega respuesta no lineal del macizo rocoso.

Incluye todas las capacidades de Map3D Fault-Slip y agrega la capacidad de que el macizo rocoso 3D ceda ante cargas que superan la resistencia de la roca y se deforme de forma no lineal para disipar los esfuerzos en exceso. Esta función es útil para simular vetas potentes, pilares sobreesforzados, estribos, relleno y respuesta de fluencia lenta. Esta formulación resuelve el problema no lineal en la superficie de los elementos de contorno e interpola estos efectos entre dichos contornos. Esto representa una primera aproximación al modelado inelástico que presenta la ventaja de admitir problemas de gran tamaño y una ejecución muy rápida.

**Map3D Visco-Plastic** - agrega respuesta elasto-visco-plástica 3D del macizo rocoso (aún en desarrollo; no está disponible comercialmente por el momento).

Incluye todas las capacidades de Map3D Fault-Slip y agrega la capacidad de que el macizo rocoso 3D se comporte de forma elasto-visco-plástica. Este modelo ofrece una solución completa de las ecuaciones de plasticidad incremental no asociada y agrega la capacidad de que el macizo rocoso 3D ceda ante cargas que superan la resistencia de la roca y se deforme de forma no lineal para disipar los esfuerzos en exceso. Esta función es útil para simular vetas potentes, pilares sobreesforzados, estribos, relleno y respuesta de fluencia lenta. Esta formulación resuelve el problema no lineal en todo el macizo rocoso.
