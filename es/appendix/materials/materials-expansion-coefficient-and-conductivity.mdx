---
title: "Materiales > Coeficiente de expansión y conductividad"
---

Map3D Thermal-Fluid Flow se puede usar para resolver simultáneamente el flujo de calor/fluidos en estado estacionario acoplado al análisis de esfuerzos. El programa está configurado de modo que solo se necesita especificar las condiciones de contorno de temperatura/carga hidráulica, y luego se resuelve simultáneamente el problema de esfuerzos acoplado con el flujo térmico/de fluidos. Esta función es útil para simular efectos de calentamiento o enfriamiento y la respuesta drenada o no drenada de suelos.

El problema de flujo térmico/de fluidos en estado estacionario se resuelve según la ecuación de Laplace en tres dimensiones. Este se acopla directamente al análisis de esfuerzos mediante un coeficiente de expansión A, donde el cambio de temperatura o de presión de fluido (respecto del valor de fondo) induce los esfuerzos iniciales

s° = _A_ D _T_

Los esfuerzos se pueden presentar sin o con los esfuerzos iniciales s°.

Plot > Stress > Value > Seff Esfuerzo efectivo

Plot > Stress > Value > Stotal Esfuerzo total

Para problemas de flujo de fluidos, el coeficiente de expansión debe establecerse en la unidad (uno positivo) para medios saturados

_A_ = 1

Para problemas térmicos, el coeficiente de expansión debe especificarse como una cantidad negativa dada por

_A_ = -a _E_ /(1-2n)

donde a, _E_ y n representan el coeficiente de expansión térmica (es decir, la expansividad lineal), el módulo de Young (a escala de macizo rocoso - deformación) y la relación de Poisson.

También es necesario especificar la conductividad _C_ . Este parámetro relaciona el gradiente con el flujo _q_ x de modo que

_q_ x = - _C_ ¶ _T_ /¶ _x_

Las unidades recomendadas para _C_ son J/(m s 8C).

Los distintos parámetros de flujo se pueden graficar con

Plot > Flow
