---
title: "Gráfico"
---

Grafica datos sísmicos. Los puntos pueden mostrarse como esferas sombreadas por una fuente de luz, con diámetro y/o color que varían según la magnitud (consulte Visualización).

Este botón puede colocarse en la barra de herramientas de vista o en la de contornos con

Tools > Configure View Toolbar

Tools > Configure Contouring Toolbar
