---
title: "Selección con la tecla Mayús"
---

Cuando esta opción está marcada, el usuario debe mantener presionada la tecla Mayús para hacer selecciones múltiples al crear una lista de entidades que editar con cualquiera de los comandos CAD > Edit. Si no se mantiene presionada la tecla Mayús, el comando de edición se ejecutará automáticamente después de la primera selección.

Cuando no está marcada, el comando de edición no se ejecutará automáticamente. Una vez completa la lista de entidades, el usuario debe:

- seleccionar cualquiera de los botones de edición,

ejecutar la función resaltada,

- hacer doble clic en cualquier vértice para ejecutar la función resaltada,

- o hacer clic con el botón derecho para ver una lista de opciones.
