---
title: "Factor de zoom"
---

Fija el factor de aumento del zoom.

Cada vez que acerca el zoom, el modelo se amplía según este factor. Cada vez que lo aleja, el modelo se reduce según este factor.

También puede fijarse simplemente escribiendo el factor de zoom y seleccionando luego cualquier botón o tecla de zoom.

Notas:

Antes de acercar el zoom, debe fijar el centro de rotación deseado

View > Centre of Rotation

#### Zoom In

Si la barra de herramientas de traslación no está visible, puede activarse con

Tools > Translation Toolbar.
