---
title: "Ver plano XY"
---

Reorienta la vista del modelo a una posición de vista especial:

View > View XY Plane: vista con el eje x hacia la derecha y el eje y hacia arriba.

View > View YZ Plane: vista con el eje y hacia la derecha y el eje z hacia arriba. View > View ZX Plane: vista con el eje x hacia la derecha y el eje z hacia arriba. View > View Grid Plane: el plano de grilla seleccionado ocupa toda la pantalla

#### CAD > Grid Selection

#### Plot > Grid Selection

View > View Digitizer Plane   el área de digitalización actual ocupa toda la pantalla

#### CAD > Digitizer Setup.

Notas:

La posición de vista actual puede guardarse

#### File > Save View

o restaurarse

File > Restore View

entre sesiones.
