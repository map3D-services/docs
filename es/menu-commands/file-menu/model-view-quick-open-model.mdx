---
title: "VISTA DEL MODELO (apertura rápida del modelo)..."
---

Carga rápidamente un modelo desde un archivo, pero omite todo el preprocesamiento. Tenga en cuenta que no puede usar ninguna de las funciones CAD hasta haber cargado el archivo con Open Model (CAD) o haber seleccionado "Go To CAD" en el menú principal del programa.

#### Combinar varios archivos en un modelo

Puede seleccionar varios archivos a la vez manteniendo presionadas las teclas estándar de Windows "Mayús" o "Ctrl" para hacer selecciones múltiples.

Estos archivos se combinarán en un solo modelo o base de datos.

Esto le permite mantener partes separadas de los datos del modelo en distintos archivos y combinarlas luego fácilmente en un solo modelo o base de datos.

Otra forma de combinar varios archivos es seleccionar la opción "Merge Geometries" antes de seleccionar el archivo adicional que desea añadir al modelo o base de datos existente.

Esto es útil si ya tiene un modelo abierto y desea añadirle más datos.
