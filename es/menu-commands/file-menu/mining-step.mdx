---
title: "Etapa de minado #"
---

Selecciona otra etapa de minado para visualizarla.

Si se ha completado el análisis BEM de Map3D para la etapa de minado seleccionada, se cargará el archivo de reinicio de esa etapa. Si el archivo de reinicio no existe (porque el análisis no se ha completado), solo se mostrará la geometría de esa etapa de minado.

Cambiar entre etapas de minado con esta función es más rápido que cargar un archivo de reinicio con

#### File > Open Analysis Results

ya que no es necesario repetir la clasificación de elementos y grillas para el mismo modelo.

Para acceder rápidamente a distintas etapas de minado, use

#### File > Mining Step.

desde la barra de herramientas de vista

#### Tools > View Toolbar.

Si lo desea, pueden colocarse botones individuales de etapas de minado en la barra de herramientas de vista con

#### Tools > View Toolbar Configure.

Puede avanzar o retroceder rápidamente una etapa de minado manteniendo presionada la tecla Alt y presionando, respectivamente, la tecla + o la tecla –.
