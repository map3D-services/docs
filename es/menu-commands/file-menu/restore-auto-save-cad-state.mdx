---
title: "Restaurar estado CAD guardado automáticamente"
---

Restaura el último estado CAD guardado automáticamente.

Durante la edición del modelo, cada vez que modifica la geometría, el estado CAD actual se guarda en un archivo temporal que se conserva entre sesiones de Map3D.

Esto incluye toda la información asociada a la sesión actual, como la geometría, los parámetros de control, las propiedades de material, las líneas de construcción, etc.

Esto le permite volver exactamente al punto en que se quedó en una nueva sesión de Map3D, o tras un cierre inesperado del programa.

#### Temas relacionados:

Save named CAD State: guarda manualmente el estado CAD en un archivo *.sav. Consulte Guardar estado CAD con nombre

Restore named CAD State: restaura un estado CAD con nombre desde un archivo *.sav. Consulte Restaurar estado CAD con nombre
