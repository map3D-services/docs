---
title: "Visor de imágenes"
---

Muestra en una ventana archivos PNG (Portable Network Graphics, *.PNG), GIF (Graphics Interchange Format) o BMP (mapa de bits independiente del dispositivo de Windows, *.BMP).

Al iniciar el visor se muestra la imagen actual de la pantalla.

El visor puede usarse para mostrar imágenes individuales, GIF animados y secuencias de imágenes.

Las imágenes de pantalla pueden guardarse en archivos con

- File > Output > PNG, GIF or BMP Image

- File > Output > PNG, GIF or BMP (B&W flipped)

- File > Output > Image Recorder
