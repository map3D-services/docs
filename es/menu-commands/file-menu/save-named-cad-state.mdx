---
title: "Guardar estado CAD con nombre"
---

Guarda el estado CAD actual en un archivo *.sav.

Esto incluye toda la información asociada a la sesión actual, como la geometría, los parámetros de control, las propiedades de material, las líneas de construcción, etc.

Esto le permite volver exactamente al punto en que se quedó en una sesión de Map3D guardada previamente, o tras un cierre inesperado del programa.

#### Temas relacionados:

Restore Auto-Save CAD State: restaura el último estado CAD guardado automáticamente. Consulte Restaurar estado CAD guardado automáticamente

Restore named CAD State: restaura un estado CAD con nombre desde un archivo *.sav. Consulte Restaurar estado CAD con nombre
