---
title: "Abrir líneas de construcción"
---

Carga líneas de construcción desde un archivo.

Las líneas de construcción se usan para definir la ubicación detallada de elementos subterráneos como excavaciones, contactos, estructuras, etc. Normalmente, un modelo de Map3D se construye sobre estos datos de líneas de construcción.

Se le pedirá que busque el nombre, la ubicación y el formato del archivo de líneas de construcción. Las líneas de construcción se pueden cargar desde varios tipos de archivo:

- El formato de archivo de puntos es un archivo de datos ASCII universal con la extensión ".PNT". Este formato es útil para intercambiar datos brutos de líneas de construcción con otro software CAD.

- El formato AutoCAD-DXF es un archivo de intercambio de dibujos muy difundido, con la extensión ".DXF". Este formato es útil para intercambiar datos de líneas de construcción con otro software CAD.

Los datos de líneas de construcción que se cargan pueden sobrescribir los datos existentes o fusionarse con ellos. La opción de sobrescribir/fusionar

#### File > Open > Merge Geometires

aparece en la parte inferior del cuadro de diálogo para abrir archivos.

#### Fusionar varios archivos en una sola base de datos

Puede seleccionar varios archivos a la vez manteniendo presionadas las teclas estándar de Windows "shift" o "ctrl" para hacer selecciones múltiples.

Estos archivos se fusionarán en una sola base de datos.

Esto le permite mantener partes separadas de los datos de líneas de construcción en distintos archivos y luego fusionarlas fácilmente en una sola base de datos.

Otra forma de fusionar varios archivos es seleccionar la opción "Merge Geometries" antes de seleccionar el archivo adicional que desea agregar a la base de datos existente.

Esto es útil si ya tiene datos de líneas de construcción abiertos y desea agregarles más datos de líneas de construcción.
