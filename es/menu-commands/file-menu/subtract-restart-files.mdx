---
title: "Restar archivos de reinicio"
---

Resta los resultados del archivo de reinicio seleccionado de los resultados cargados actualmente.

Se le pedirá que busque el nombre, la ubicación y el formato del archivo de reinicio.

Notas:

Solo se restan los resultados de los planos de grilla.

Esta función puede usarse para restar una etapa de minado de otra.

Si se restan resultados de modelos distintos, estos deben tener planos de grilla idénticos.

Al restar, se restan todas las componentes cartesianas (esfuerzo, deformación y desplazamiento) y luego se recalculan las componentes principales de estos cambios para su visualización.

Se conserva la geometría del modelo cargado actualmente para su visualización.
