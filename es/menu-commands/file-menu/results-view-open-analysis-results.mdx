---
title: "VISTA DE RESULTADOS (abrir resultados del análisis)..."
---

Carga los resultados del análisis desde un archivo de reinicio.

Se le pedirá que busque el nombre, la ubicación y el formato del archivo de reinicio.

Una vez cargados, el usuario puede ver y procesar los resultados del análisis. Pueden generarse gráficos de contornos de cualquier combinación deseada de componentes de esfuerzo, deformación y desplazamiento. Los resultados pueden mostrarse como valores totales o como la diferencia de valor entre etapas de minado.

Para cambiar de una etapa de minado a otra, use

#### File > Mining Step.

#### Notas:

Para acceder rápidamente en una sesión posterior, cada vez que abre un archivo su nombre se guarda en

#### File > Recent Files

y el directorio de trabajo se guarda en

#### File > Open > Recent Directories.

Para volver a cargar el archivo del modelo para editar bloques de minado y configurar el análisis de Map3D, use

#### Analysis > Go to CAD.

Para cargar otro archivo de modelo, use

#### File > Open (Model).
