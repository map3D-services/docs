---
title: "Abrir modelo (CAD)"
---

Carga un modelo desde un archivo.

Una vez cargado, se puede ejecutar cualquier etapa de análisis de Map3D que se desee.

Para agregar o editar bloques de explotación y configurar el análisis de Map3D, use

#### Analysis > Go to CAD.

Al cargar el modelo, Map3D verifica la consistencia básica de los parámetros de modelamiento (p. ej., si se usa un material, sus propiedades deben estar especificadas en la lista de materiales).

Se le pedirá que busque el nombre, la ubicación y el formato del archivo del modelo. Los modelos se pueden cargar desde varios tipos de archivo:

- El formato Map3D-INP es un archivo de datos ASCII editable con la extensión ".INP". Es el formato de modelo recomendado de Map3D. Todas las funciones de Map3D son compatibles con este formato.

- El formato AutoCAD-DXF es un archivo de intercambio de dibujos muy difundido, con la extensión ".DXF". Este formato es útil para intercambiar datos de modelos con otro software CAD.

- El formato de archivo de puntos es un archivo de datos ASCII universal con la extensión ".PNT". Este formato es útil para intercambiar datos brutos de modelos con otro software CAD.

Los datos geométricos y de materiales del modelo que se cargan pueden sobrescribir los datos existentes del modelo o fusionarse con ellos. Las opciones de sobrescribir/fusionar:

- File > Open > Merge Geometries

- File > Open > Merge Materials

aparecen en la parte inferior del cuadro de diálogo para abrir archivos.

#### Fusionar varios archivos en un solo modelo

Puede seleccionar varios archivos a la vez manteniendo presionadas las teclas estándar de Windows "shift" o "ctrl" para hacer selecciones múltiples.

Estos archivos se fusionarán en un solo modelo/base de datos.

Esto le permite mantener partes separadas de los datos del modelo en distintos archivos y luego fusionarlas fácilmente en un solo modelo/base de datos.

Otra forma de fusionar varios archivos es seleccionar la opción "Merge Geometries" antes de seleccionar el archivo adicional que desea agregar al modelo/base de datos existente.

Esto es útil si ya tiene un modelo abierto y desea agregarle más datos de modelo.

#### Notas:

Para un acceso rápido en una sesión posterior, cada vez que abre un archivo su nombre se guarda en

#### File > Recent Files

y el directorio de trabajo se guarda en

File > Open > Recent Directories.

Para cargar resultados de análisis use

File > Open Analysis Results.

Para reiniciar un análisis que fue abortado o interrumpido por un corte de energía o una falla del sistema operativo use

File > Restart an Analysis.
