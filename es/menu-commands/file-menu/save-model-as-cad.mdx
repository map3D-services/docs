---
title: "Guardar modelo como (CAD)"
---

Guarda el modelo actual con otro nombre de archivo, ubicación y formato.

Los modelos pueden guardarse en varios tipos de archivo:

- El formato Map3D-INP es un archivo de datos ASCII editable con la extensión ".INP". Es el formato de modelo recomendado para Map3D. Admite todas las funciones de Map3D.

- El formato AutoCAD-DXF es un formato popular de intercambio de dibujos con la extensión ".DXF". Este formato es útil para intercambiar datos del modelo con otros programas CAD.

- El formato de archivo de puntos es un archivo de datos ASCII universal con la extensión ".PNT". Este formato es útil para intercambiar datos brutos del modelo con otros programas CAD.

Para guardar con el mismo nombre, ubicación o formato, use

#### File > Save Model.
