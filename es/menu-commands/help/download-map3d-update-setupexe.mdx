Descarga: actualización de Map3D (setup.exe 18MB)

Descarga la última actualización de Map3D desde el sitio web de Map3D [www.map3d.com/update.htm](https://www.map3d.com/update.htm)

La actualización completa incluye todos los ejecutables de Map3D, las rutinas de instalación automatizada, el Manual del usuario de Map3D en formato HTML y los controladores de la llave Sentinel SuperPro, además de algunos archivos de ejemplo.

Como la actualización completa (setup.exe) es bastante grande (8MB), una alternativa es descargar solo los ejecutables actualizados (Map3D.zip).

Descarga: actualización de Map3D (Map3D.zip 8MB)

Esto

no incluye las rutinas de instalación, el Manual del usuario de Map3D en formato HTML ni los controladores de la llave Sentinel SuperPro. Tenga en cuenta que el Manual del usuario de Map3D en HTML (Map3D.chm) es necesario para que funcione la ayuda contextual dentro de Map3D.

El manual del usuario se puede descargar en varios formatos:

Descargar el Manual del usuario en HTML (Map3D.chm 4MB)

El Manual del usuario en HTML se puede descargar desde Help > Help > Download HTML User's Manual. Este manual está en el formato nativo de ayuda HTML de Windows.

Descargar el Manual del usuario en PDF (Map3D_Help.pdf 7MB)

El Manual del usuario en PDF se puede descargar desde Help > Download PDF User's Manual. Este manual está en formato PDF y es una buena opción para imprimir.

Descargar el Manual del usuario en libro electrónico (Map3D_Help.exe 5MB)

El Manual del usuario en libro electrónico se puede descargar desde Help > Download Ebook User's Manual. Este manual está en un formato de libro electrónico independiente.
