Descarga: actualización de Map3D (Map3D.zip, 8 MB)

Descarga la última actualización de Map3D desde el sitio web de Map3D [www.map3d.com/update.htm](https://www.map3d.com/update.htm)

No incluye las rutinas de instalación, el manual del usuario de Map3D en formato HTML ni los controladores de la llave Sentinel SuperPro. Tenga en cuenta que el manual del usuario de Map3D en HTML (Map3D.chm) es necesario para que funcione la ayuda contextual dentro de Map3D.

Descarga: actualización de Map3D (setup.exe, 18 MB)

La actualización completa incluye todos los ejecutables de Map3D, las rutinas de instalación automatizadas, el manual del usuario de Map3D en formato HTML y los controladores de la llave Sentinel SuperPro, además de algunos archivos de ejemplo.

El manual del usuario puede descargarse en varios formatos:

Descargar el manual del usuario en HTML (Map3D.chm, 4 MB)

El manual del usuario en HTML puede descargarse desde Help > Download HTML User's Manual. Este manual está en el formato nativo de ayuda HTML de Windows.

Descargar el manual del usuario en PDF (Map3D_Help.pdf, 7 MB)

El manual del usuario en PDF puede descargarse desde Help > Download PDF User's Manual. Este manual está en formato PDF y es una buena opción para imprimir.

Descargar el manual del usuario en libro electrónico (Map3D_Help.exe, 5 MB)

El manual del usuario en libro electrónico puede descargarse desde Help > Download Ebook User's Manual. Este manual está en un formato de libro electrónico independiente.
