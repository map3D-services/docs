---
title: "Descarga: manual del usuario en HTML"
---

Descargar el manual del usuario en HTML (Map3D.chm, 4 MB)

El manual del usuario en HTML puede descargarse desde Tools > Download HTML User's Manual. Este manual está en el formato nativo de ayuda HTML de Windows.

Descargar el manual del usuario en PDF (Map3D_Help.pdf, 7 MB)

El manual del usuario en PDF puede descargarse desde Tools > Download PDF User's Manual. Este manual está en formato PDF y es una buena opción para imprimir.

Descargar el manual del usuario en libro electrónico (Map3D_Help.exe, 5 MB)

El manual del usuario en libro electrónico puede descargarse desde Tools > Download Ebook User's Manual. Este manual está en un formato de libro electrónico independiente.
