---
title: "Caja poligonal"
---

Calcula el valor promedio ponderado de todos los puntos de contorno seleccionados. Esta función también se puede activar con View > Length.

Se le pedirá que seleccione una serie de vértices para definir un polígono cerrado, haciendo un solo clic con el mouse en cada uno:

- Debe mantener presionada la tecla Shift para poder seleccionar varios segmentos de línea.

- Una forma poligonal cerrada se define cerrando la polilínea al seleccionar el punto inicial.

- Si define una forma poligonal cerrada, los puntos de contorno encerrados en el polígono se incluirán en el promedio.

- La rutina de promedio no funcionará si define una polilínea abierta (al no seleccionar el punto inicial).

- Para ver la ubicación de los puntos de contorno reales, active la visualización de trayectorias (Plot > Options > Trajectories). Los puntos de contorno se ubican donde se dibujan las trayectorias.

El promedio se calcula multiplicando cada valor seleccionado por el área de su superficie o celda de grilla asociada y sumando luego estos productos. Este resultado se presenta como "Weighted Sum". El "Average" se determina dividiendo la suma ponderada por el área total.

Todos los valores se acumulan como componentes vectoriales. Los esfuerzos principales se determinan a partir de la media ponderada de las componentes cartesianas. Las componentes de desplazamiento, de flujo y de corte superficial se determinan a partir de la media ponderada de las componentes vectoriales.

Tenga en cuenta que, para los esfuerzos, la "Weighted Sum" es en realidad la fuerza total que actúa sobre la superficie.

Si multiplica por el módulo de corte, la "Weighted Sum" del desplazamiento plástico de corte (ride) es en realidad el momento sísmico.
