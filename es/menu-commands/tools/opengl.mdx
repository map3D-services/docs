## 5.6.4.1 OpenGL &lt;On/Off>

Habilita la compatibilidad con OpenGL.

OpenGL es una interfaz estándar de la industria para renderizado gráfico 3D de alta calidad. Las principales ventajas de usar OpenGL son la aceleración por hardware de la visualización gráfica y la compatibilidad con z-buffer. Por supuesto, para obtener la aceleración por hardware debe contar con un adaptador gráfico compatible con OpenGL y tener instalado el controlador de pantalla OpenGL.

Vea Tools > OpenGL Parameters para ver la configuración de OpenGL.

Vea Tools > OpenGL Anti-aliasing para suavizar las líneas.

## 5.6.4.2 Parámetros de OpenGL

Informa sobre la configuración de OpenGL:

Support OpenGL – indica si hay un controlador OpenGL instalado y habilitado.

Driver or Hardware Support - indica si su adaptador gráfico admite OpenGL.

Double Buffered – indica que hay memoria suficiente para admitir doble búfer.

Color Buffer Bits – indica el número de bits usados para el búfer de color.

Depth Buffer Bits – indica el número de bits usados para el z-buffer.

## 5.6.4.3 Suavizado (antialiasing) de OpenGL

Habilita el suavizado de puntos, líneas y aristas de polígonos.

Esta función de OpenGL mejora la apariencia, pero ralentiza el renderizado.

View > Render > Line Width se puede usar para habilitar el dibujo de líneas más anchas. Esto también ayudaría a suavizar el dibujo de líneas con un impacto similar en el rendimiento.

## 5.6.4.4 Redibujado de OpenGL

Habilita el redibujado de la pantalla con OpenGL cuando es necesario refrescar la ventana.

La ventana de visualización de Map3D debe refrescarse cada vez que se mueve o se cierra un cuadro de diálogo. Este refresco puede hacerse guardando la ventana de visualización en un búfer secundario (esta opción no está marcada) o simplemente redibujando la pantalla (esta opción está marcada).

Esta opción normalmente debe estar marcada, pero se puede desactivar para adaptadores gráficos problemáticos.

## 5.6.4.5 Selección con OpenGL

Habilita que OpenGL ubique las entidades gráficas en la pantalla.

Cuando hace clic izquierdo sobre una entidad, Map3D debe determinar cuál entidad seleccionó. Esto lo puede determinar OpenGL o el propio Map3D internamente.

Esta opción normalmente debe estar marcada, pero se puede desactivar para adaptadores gráficos problemáticos.

## 5.6.4.6 Cursor en cruz de OpenGL

Alterna entre el dibujo del cursor en cruz con OpenGL y con la API de Windows.

Esta opción normalmente debe estar marcada, pero se puede desactivar para adaptadores gráficos problemáticos.

Para desactivar por completo el dibujo del cursor en cruz, seleccione Tools > Crosshairs.

## 5.6.4.7 Edición interactiva con OpenGL

Habilita el dibujo interactivo con OpenGL de las formas modificadas durante las operaciones de edición.

Esta opción normalmente debe estar marcada, pero se puede desactivar para adaptadores gráficos problemáticos.
