---
title: "Prueba de rendimiento del disco"
---

Prueba el rendimiento del sistema de disco duro.

Esta prueba simula el comportamiento de Map3D durante la etapa de solución del análisis BEM.

Buffer Size: tamaño del búfer usado para las lecturas y escrituras en disco. Map3D usa un búfer de 256K para sus lecturas y escrituras de archivos.

Write Through: indica al sistema que escriba sin pasar por ninguna caché intermedia, directamente al disco. Map3D usa "Write Through" para sus escrituras de archivos.

No Buffering: indica al sistema que escriba en el archivo sin búfer ni caché intermedios. Map3D usa "No Buffering" para sus escrituras de archivos.

Asynchronous I/O: indica al sistema que permita realizar simultáneamente más de una operación de lectura y/o escritura. Esta opción solo se admite en Windows NT/2000. Se puede indicar a Map3D que use esta función con

#### Analysis > Options > Async I/O

Size MB: tamaño del archivo usado para la prueba. Se recomienda realizar esta prueba con un archivo grande (bastante mayor que la cantidad de RAM). Drive: unidad de disco usada para la prueba.

Los resultados importantes son:

Write rate: el número de MBytes escritos en el disco por segundo. Debería esperar más de 5-10 MB/segundo.

Read rate: el número de MBytes leídos del disco por segundo. Debería esperar más de 5-10 MB/segundo.

Multiply/sec: el número de multiplicaciones de punto flotante realizadas por segundo. Debería esperar más de 50 MFLOPS.
