---
title: "Materiais > Exportar para arquivo"
---

Permite exportar todos os dados de propriedades dos materiais para um arquivo, para visualização no Bloco de Notas ou no Excel.

Você será solicitado a selecionar um nome de arquivo para a exportação. As opções incluem:

- Open in Excel

- Open in Notepad

- Use commas as decimal points

Os formatos de arquivo disponíveis incluem:

- csv - valores separados por vírgula (útil para importação direta no Excel)

- tsv - valores separados por tabulação (útil para importação direta no Excel)

- txt - valores separados por espaço (útil para importação direta no Bloco de Notas)
