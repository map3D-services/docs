---
title: "Arquivo > Abrir > Mesclar geometrias"
---

Se esta opção estiver marcada, ao carregar o novo arquivo de modelo ou de linhas de construção, os dados geométricos são mesclados com os dados geométricos atuais.

Se esta opção não estiver marcada, ao carregar o novo arquivo de modelo ou de linhas de construção, os dados geométricos substituem/sobrescrevem os dados geométricos atuais.

Isso permite construir seu modelo ou seu banco de dados de linhas de construção em pequenas partes e mesclá-las conforme necessário.

Tópicos relacionados:

File > Open > Merge Materials.
