---
title: "Arquivo > Formato DXF de linhas de construção"
---

O formato DXF é um arquivo de troca de desenhos do AutoCAD com a extensão ".DXF".

Este formato é útil para trocar dados do modelo com outros softwares CAD.

As linhas de construção são salvas como uma série de entidades POLYLINE do AutoCAD DXF.

As linhas de construção podem ser importadas como uma série de entidades POLYLINE, LINE, 3DLINE ou 3DFACE do AutoCAD DXF.
