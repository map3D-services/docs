---
title: "Arquivo > Formato de arquivo de saída PNT"
---

O formato PNT é um arquivo de dados ASCII universal com a extensão ".PNT".

Este formato é útil para trocar dados brutos do modelo com outros softwares CAD.

As linhas de comentário começam com um asterisco "*" na coluna 1.

As superfícies são armazenadas como uma série de polilinhas, da seguinte forma:

x1 y1 z1 3 value1 x2 y2 z2 2 value2 x3 y3 z3 2 value3 x4 y4 z4 2 value4

xI yI zI representam as coordenadas de cada ponto.

3 indica que este ponto é o início de uma nova linha. 2 indica que este ponto é a continuação da mesma linha. valuei, para entidades geométricas, representa o número da cor da superfície

Para contornos, representa o valor do parâmetro contornado em cada canto da superfície.
