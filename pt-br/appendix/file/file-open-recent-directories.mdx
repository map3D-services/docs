---
title: "Arquivo > Abrir > Diretórios recentes"
---

Cada vez que você abre um arquivo de modelo ou de reinício, seu diretório de trabalho é salvo para acesso rápido em uma sessão posterior. Para reabrir um desses diretórios, basta escolhê-lo na lista.

Tópicos relacionados:

File > Open > Recent Files
