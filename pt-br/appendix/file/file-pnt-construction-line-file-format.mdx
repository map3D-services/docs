---
title: "Arquivo > Formato PNT de linhas de construção"
---

O formato PNT é um arquivo de dados ASCII universal com a extensão ".PNT".

Este formato é útil para trocar dados brutos do modelo com outros softwares CAD.

As linhas de comentário devem começar com um asterisco "*" na coluna 1.

As linhas de construção são armazenadas como uma série de polilinhas, da seguinte forma:

**x1 y1 z1 3 colour x2 y1 z1 2 x3 y3 z3 2 x4 y4 z4 2**

xi yi zi representam as coordenadas de cada ponto. 3 indica que este ponto é o início de uma nova linha. 2 indica que este ponto é a continuação da mesma linha. colour especifica o número da cor que será usada para exibir a linha de construção.

Há um total de 10 cores disponíveis para exibição.

Elas são numeradas de 1 a 10, de 11 a 20, de 21 a 30 etc., de modo que a mesma cor é exibida para os números 1, 11, 21, 31..., 2, 22, 32..., etc.

Qualquer número de pontos pode ser especificado para cada polilinha.

Polilinhas adicionais são especificadas repetindo-se a sequência (ou seja, iniciando uma nova linha com o número 3).

Notas

Devem ser usados números de cor diferentes para representar agrupamentos lógicos de linhas de construção (p. ex., para diferentes níveis, seções ou unidades lógicas de lavra, como desenvolvimento, realce etc.). Essas cores podem ser definidas pelo usuário usando

#### Tools > Custom Colours.

Como é fácil ativar e desativar a exibição de números de cor específicos de linhas de construção, isso fornece um método eficiente para trabalhar com dados complexos de linhas de construção

#### View > Hide Cline Colours.
