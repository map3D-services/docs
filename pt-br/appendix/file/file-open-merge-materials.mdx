---
title: "Arquivo > Abrir > Mesclar materiais"
---

Se esta opção estiver marcada, ao carregar o novo arquivo de modelo, os dados de material do novo arquivo são mesclados com os dados de material atuais.

Se esta opção não estiver marcada, ao carregar o novo arquivo de modelo, os dados de material do novo arquivo substituem os dados de material atuais.

Isso permite manter seus modelos de material em arquivos de dados separados e incorporá-los aos modelos conforme necessário.

Tópicos relacionados:

File > Open > Merge Geometries.
