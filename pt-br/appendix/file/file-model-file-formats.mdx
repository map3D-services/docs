---
title: "Arquivo > Formatos de arquivo de modelo"
---

Os modelos podem ser carregados a partir de vários tipos de arquivo:

O formato Map3D-INP é um arquivo de dados ASCII editável com a extensão ".INP". Este é o formato de modelo recomendado do Map3D. Todas as funcionalidades do Map3D são compatíveis com este formato.

O formato AutoCAD-DXF é um arquivo de troca de desenhos muito difundido, com a extensão ".DXF". Este formato é útil para trocar dados do modelo com outros softwares CAD.

O formato de arquivo de pontos é um arquivo de dados ASCII universal com a extensão ".PNT". Este formato é útil para trocar dados brutos do modelo com outros softwares CAD.

Modelos de arquivos diferentes podem ser mesclados. A opção de mesclagem

File > Open > Merge

aparece na parte inferior da caixa de diálogo de abertura de arquivo.

Tópicos relacionados:

File > Open File > Save As
