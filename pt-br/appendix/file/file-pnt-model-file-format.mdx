O formato PNT é um arquivo de dados ASCII universal com a extensão ".PNT".

Este formato é útil para trocar dados brutos do modelo com outros softwares CAD.

As linhas de comentário devem começar com um asterisco "*" na coluna 1.

Os blocos FF e os planos DD do Map3D são armazenados como uma série de polilinhas, da seguinte forma:

**x1 y1 z1 3 colour mtype x2 y1 z1 2 x3 y3 z3 2 x4 y4 z4 2 x5 y5 z5 1 x6 y6 z6 1 x7 y7 z7 1 x8 y8 z8 1**

em que **xi yi zi** representam as coordenadas de cada ponto,

- **3** indica que este ponto é o início de uma nova polilinha,

**2** indica que este ponto faz parte da base do bloco,

- **1** indica que este ponto faz parte do topo do bloco. Este item é usado apenas para a definição de formas de blocos 3D.

**colour** especifica o número da cor que será usada para exibir o bloco.

Há um total de 10 cores disponíveis para exibição.

- Elas são numeradas de 1 a 10, de 11 a 20, de 21 a 30 etc., de modo que a mesma cor é exibida para os números 1, 11, 21, 31..., 2, 22, 32..., etc.

**mtype** especifica o tipo de elemento de contorno que será usado para o bloco.

Para feições tridimensionais, como escavações, zonas de material alternativo, realces preenchidos etc., devem ser usados elementos de Força Fictícia (Fictitious Force) do tipo 1

CAD > Build > Block e CAD > Build > Block para detalhes.

- Elementos de Descontinuidade de Deslocamento (Displacement Discontinuity) do tipo 2 devem ser usados para escavações de lavra tabular, fraturas e planos de falha

CAD > Build > DDLoop para detalhes.

Elementos inativos (98 para blocos 3D inativos e 99 para planos DD inativos) podem ser usados para exibir feições que devem ser incluídas apenas para fins de visualização e não usadas na análise de tensões propriamente dita.

Polilinhas adicionais são especificadas repetindo-se a sequência (ou seja, iniciando uma nova linha com o número **3** ).

#### Notas

Devem ser usados números de cor diferentes para representar agrupamentos lógicos de blocos (p. ex., para diferentes níveis, seções ou unidades lógicas de lavra, como desenvolvimento, realce etc.). Essas cores podem ser definidas pelo usuário usando

#### Tools > Custom Colours

O Map3D combina automaticamente quaisquer blocos com o mesmo número de cor em formas complexas únicas.

Como é fácil ativar e desativar a exibição de números de cor específicos de blocos, isso fornece um método eficiente para trabalhar com dados complexos de modelo
