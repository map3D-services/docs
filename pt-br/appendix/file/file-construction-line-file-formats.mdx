---
title: "Arquivo > Formatos de arquivo de linhas de construção"
---

As linhas de construção podem ser salvas em vários tipos de arquivo:

O formato de arquivo de pontos é um arquivo de dados ASCII universal com a extensão ".PNT". Este formato é útil para trocar dados brutos de linhas de construção com outros softwares CAD.

O formato AutoCAD-DXF é um arquivo de troca de desenhos muito difundido, com a extensão ".DXF". Este formato é útil para trocar dados de linhas de construção com outros softwares CAD.

Linhas de construção de arquivos diferentes podem ser mescladas. A opção de mesclagem

#### File > Open > Merge

aparece na parte inferior da caixa de diálogo de abertura de arquivo.

Tópicos relacionados:

File > Open (Construction Lines).

File > Save As.
