---
title: "Análise > Opções > P-RAM"
---

Armazena parte da matriz de coeficientes na RAM física durante a análise BEM do Map3D.

Se o seu computador tiver uma grande quantidade de RAM instalada, esta opção pode acelerar significativamente a execução, pois os dados podem ser recuperados da RAM muito mais rapidamente do que do disco. Embora o Windows de 32 bits só permita que cada processo endereçe 2 GB, para usuários com grandes quantidades de RAM no computador, a RAM física pode ser acessada por meio do AWE (Address Windowing Extensions). O AWE permite o acesso a toda a RAM disponível no computador. A maioria dos sistemas suporta 4 GB de RAM. Alguns suportam mais de 64 GB. Diversas versões do Windows oferecem diferentes níveis de suporte a AWE, de 1 GB até 512 GB. O suporte a AWE está disponível nas seguintes versões do Windows:

- Windows 10 Professional e Server (máximo de 4 GB).

- Windows NT 4.0, Windows 2000 Professional e Server (máximo de 4 GB).

- Windows 2000 Advanced Server (máximo de 8 GB).

- Windows 2000 Datacenter Server (máximo de 32 GB).

- Windows XP Professional e Windows Server 2003 (máximo de 4 GB).

- Windows Server 2003 Enterprise Edition (máximo de 32 GB).

- Windows Server 2003 Datacenter Edition (máximo de 64 GB).

- Windows 7 e 8.

- Windows 10 e 11 Pro (a versão Home não oferece suporte a isso).

O AWE requer o privilégio "SE_LOCK_MEMORY". Para habilitar o AWE, siga estas etapas:

Control Panel > Administrative Tools > Local Security Policies

Em seguida, defina

Local Policies > User Rights Assignment > Lock Pages in Memory > Add User or Group > Everyone

Você deve reiniciar o computador para que essa configuração entre em vigor.

Notas:

Esta função deve ser marcada antes de executar a análise BEM do Map3D

#### Análise > Análise BEM.

Você deve alocar apenas a quantidade de RAM que deseja que o Map3D use, deixando espaço adequado para quaisquer outros aplicativos que pretenda executar.

Nunca defina este parâmetro com um valor maior que a RAM disponível, pois isso resultará em paginação excessiva do sistema operacional, o que reduzirá significativamente a velocidade da análise.
