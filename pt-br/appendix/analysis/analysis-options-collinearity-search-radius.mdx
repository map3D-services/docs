---
title: "Análise > Opções > Raio de busca de colinearidade"
---

Especifica o raio de busca usado na verificação de colinearidade durante o carregamento do arquivo (consulte Analysis > Options > Collinearity).

Pontos de coordenadas muito próximos entre si são unidos. Pontos de coordenadas muito próximos de uma aresta de uma superfície são movidos para essa aresta. Por padrão, o Map3D move esses pontos se eles estiverem dentro de um raio de busca de 1/1000 do comprimento da aresta em relação à superfície.

Se desejado, o usuário pode usar esta opção para definir um raio de busca inserindo um valor na caixa de dados. Outros pacotes CAD podem não ligar os cantos das superfícies entre si. Este recurso é útil para eliminar pequenas lacunas e sobreposições entre superfícies e blocos adjacentes.

#### Notas

Esta função deve ser marcada antes de carregar o arquivo de modelo

#### Analysis > Load Model.

Deve-se ter cautela se um raio de busca diferente de zero for especificado, pois um valor muito grande pode causar a união indesejada de pontos de coordenadas, destruindo a integridade do modelo.
