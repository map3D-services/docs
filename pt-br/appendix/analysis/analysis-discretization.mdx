title: "Análise > Discretização"
---

Discretiza o modelo.

Todas as superfícies de escavação são discretizadas automaticamente, concentrando elementos onde os resultados são solicitados

View > Render > Discretize

Os resultados da análise são calculados em superfícies DD e em uma série de planos de grade definidos pelo usuário

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane

ou em pontos definidos pelo usuário

#### Analysis > Options > MSCALC

Os planos de grade são discretizados automaticamente em uma série de pontos de campo nos quais são calculados deslocamentos, deformações e tensões.

A análise de discretização pode ser repetida quantas vezes se desejar, com diferentes parâmetros de controle.

O usuário tem controle total sobre a forma como o modelo é discretizado, especificando vários parâmetros de controle (comprimento do elemento _AL_ , espaçamento da grade _AG_ , discretização do elemento _DON_ , discretização da grade _DOL_ )

#### Analysis > CParams

e especificando a largura máxima de elemento para blocos FF 3D e planos DD

CAD > Edit > Entities > Maximum Element Width

assim como para grades de pontos de campo

CAD > Edit > Entities > Maximum Element Width

Consulte Discretization and Lumping para uma discussão detalhada sobre como definir esses parâmetros de controle.

Opções:

Analysis > Options > MSCALC Analysis > Options > LERD/LSS Analysis > Options > Lumping

Tópicos relacionados:

Analysis Dialog Analysis > Suspend Analysis > ABORT Analysis > Restart
