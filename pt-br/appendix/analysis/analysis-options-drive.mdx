---
title: "Análise > Opções > Unidade nº"
---

Especifica as unidades de rascunho para a matriz de coeficientes – durante a análise BEM do Map3D.

Se houver várias unidades de disco instaladas, esta opção pode ser usada para indicar ao Map3D onde armazenar a matriz de coeficientes. Quando a primeira unidade ficar cheia, o Map3D gravará o restante da matriz na próxima unidade de rascunho.

Quando a matriz de solução é grande demais para caber na RAM (consulte Analysis > Options > VRAM e Analysis > Options > PRAM) , a solução da matriz torna-se uma operação intensiva em E/S, que depende apenas da taxa de E/S do computador. Nesse caso, grande parte do tempo de análise pode ser gasta na etapa de solução devido ao desempenho lento do disco.

Para superar esse problema, é imprescindível que o usuário instale vários discos de alta velocidade.

O Map3D oferece suporte total ao processamento paralelo e à E/S de disco paralela com a opção multiprocessador/multiunidade.

Se você tiver licença para usar a opção multiprocessador/multiunidade, o Map3D configura essas unidades em uma matriz RAID, de modo que a E/S seja feita de forma sobreposta em todas as unidades, em paralelo com os cálculos.

Configurado dessa forma, você pode aumentar o desempenho de E/S em proporção ao número de unidades na matriz.

No benchmark a seguir, o mesmo modelo é executado com 1, 2 e 4 discos.

||1 disk|2 disks|4 disks|8GB PRAM|
|---|---|---|---|---|
|Measured Disk Throughput (MB/sec)|55|112|206|3000 equivalent|
|Matrix Solution (hours)|0.546|0.282|0.163|0.033|
|Solution Speed Increase|1x|1.9x|3.3x|16x|
|Total Analysis Time (4 cores)|0.640|0.376|0.257|0.107|
|Total Speed Increase|1x|1.7x|2.5x|6x|

Os discos usados neste benchmark são unidades mais antigas, de 50-60 MB/s (Seagate Barracuda 7200.7). Unidades mecânicas mais recentes têm desempenho de 100 MB/s (Seagate Momentus 7200.4). SSDs SATA2 podem fornecer mais de 250 MB/s por unidade. SSDs SATA3 podem fornecer mais de 500 MB/s por unidade. É de se esperar que vários SSDs e/ou unidades NVMe tenham desempenho quase tão rápido quanto a PRAM. Observe que algumas placas-mãe têm limitações quanto à taxa de transferência total combinada e podem exigir adaptadores de controladora adicionais.

Para determinar se você tem licença para usar a opção multiprocessador/multiunidade, verifique em Analysis > Options > #Threads.

Se você tiver licença para usar a opção multiprocessador/multiunidade, é possível obter taxas de disco mais altas se você definir o privilégio SE_MANAGE_VOLUME_NAME.

Este recurso está disponível nas seguintes versões do Windows:

- Windows NT 4.0, Windows 2000 Professional e Server (máximo de 4 GB).

- Windows 2000 Advanced Server (máximo de 8 GB).

- Windows 2000 Datacenter Server (máximo de 32 GB).

- Windows XP Professional e Windows Server 2003 (máximo de 4 GB).

- Windows Server 2003 Enterprise Edition (máximo de 32 GB).

- Windows Server 2003 Datacenter Edition (máximo de 64 GB).

- Windows 10 e 11 Pro (a versão Home não oferece suporte a isso).

Para definir o privilégio "SE_MANAGE_VOLUME_NAME", siga estas etapas:

Control Panel > Administrative Tools > Local Security Policies

Em seguida, defina

Local Policies > User Rights Assignment > Perform Volume Maintenance Tasks > Add User or Group > Everyone

Você deve reiniciar o computador para que esta configuração tenha efeito.

Notas:

Esta função deve ser marcada antes de realizar a análise BEM do Map3D

#### Analysis > BEM Analysis

Você deve especificar a unidade mais rápida do seu sistema. É possível testar o desempenho da unidade usando

Tools > Disk Performance Test
