---
title: "Análise > Opções > Inicialização"
---

Inicializa o modelo para que a análise continue do ponto em que uma análise anterior terminou.

Esta opção permite iniciar uma nova análise a partir do ponto em que um modelo anterior terminou. Todos os componentes não lineares, de deformação zero e de carregamento sísmico (carregamento sísmico apenas no Map3Di) são transferidos da análise anterior para o novo modelo.

Para que esta função opere corretamente, o novo modelo deve conter todos os dados (geometria) do modelo de inicialização, além de quaisquer novos dados, etapas de lavra ou grades. Não é necessário usar a mesma discretização ou os mesmos planos de grade.

Para inicializar, os seguintes arquivos devem estar íntegros:

file.00n, em que n representa o número da etapa de lavra em que a análise anterior terminou. file.dms, que só é usado com a opção de deformação zero (Análise > Opções > Colocação com deformação zero).

file.hms, que só é usado pelo Map3Di e serve para acumular o carregamento de campo à medida que a análise avança.

Notas:

Esta função deve ser marcada antes de executar a análise BEM do Map3D

#### Análise > Análise BEM

Esta opção requer cálculos adicionais e, portanto, aumenta o tempo de análise.

Consulte Análise > Opções > Reiniciar para reiniciar uma análise que foi abortada ou interrompida por uma queda de energia ou uma falha do sistema operacional.
