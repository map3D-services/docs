---
title: "Análise > Carregar modelo"
---

Carrega um modelo a partir de um arquivo (formato INP ou DXF). Depois de carregado, o usuário pode usar

Analysis > Go to CAD

para adicionar ou editar blocos de lavra e configurar a análise do Map3D.

Ao carregar o modelo, o Map3D verifica a consistência básica dos parâmetros de modelagem (por exemplo, se um material é usado, suas propriedades devem estar especificadas na lista de materiais).

Opções:

Analysis > Options > Reunmber Analysis > Options > Collinearity

Tópicos relacionados:

Analysis Dialog Analysis > Suspend Analysis > ABORT
