---
title: "Análise > Opções > V-RAM"
---

Armazena parte da matriz de coeficientes em RAM virtual durante a análise BEM do Map3D.

Se o seu computador tiver uma grande quantidade de RAM instalada, esta opção pode acelerar significativamente a execução, pois os dados podem ser recuperados da RAM muito mais rapidamente do que do disco. Infelizmente, o Windows de 32 bits só permite que cada processo endereçe 2 GB. Depois de descontar as sobrecargas, restam apenas cerca de 1 GB para armazenamento auxiliar, mesmo que você tenha bastante RAM. Para usuários com grandes quantidades de RAM no computador, uma alternativa é usar a RAM física (Análise > Opções > P-ram) em vez da RAM virtual.

Notas:

Esta função deve ser marcada antes de executar a análise BEM do Map3D

#### Análise > Análise BEM.

Você deve alocar apenas a quantidade de RAM que deseja que o Map3D use, deixando espaço adequado para quaisquer outros aplicativos que pretenda executar.

Nunca defina este parâmetro com um valor maior que a RAM disponível, pois isso resultará em paginação excessiva do sistema operacional, o que reduzirá significativamente a velocidade da análise.
