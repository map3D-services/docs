Realiza a análise de contatos e interseções.

Uma das chaves para a facilidade de uso do Map3D é a construção de modelos com tecnologia de modelagem de sólidos. Ela permite construir modelos usando uma série de blocos tridimensionais e planos DD. Essas entidades, que podem ter qualquer forma, tamanho e orientação desejados, são usadas para construir escavações e acessos, bem como para definir zonas não homogêneas (por exemplo, zonas de minério, diques e zonas de escoamento). O programa constrói automaticamente as interseções entre escavações, falhas e múltiplas zonas de materiais. Ao combinar essa capacidade com as operações booleanas integradas, é possível construir com facilidade sequências de lavra complexas com várias etapas.

Opções:

Analysis > Options > Collapse Analysis > Options > Planarity Analysis > Options > Closure

Tópicos relacionados:

Analysis Dialog Analysis > Suspend Analysis > ABORT
