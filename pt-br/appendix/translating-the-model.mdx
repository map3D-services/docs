---
title: "Translação do modelo"
---

Translação do modelo - É possível transladar o modelo mantendo pressionado o botão direito do mouse e aguardando

o aparecimento do ponteiro de arraste; em seguida, arraste para definir um vetor de deslocamento. Arrastar para cima ou para baixo translada o modelo para cima ou para baixo. Arrastar para a esquerda ou para a direita translada o modelo para a esquerda ou para a direita.

Zoom do modelo - É possível aplicar zoom ao modelo girando a roda do mouse, ou mantendo pressionados os botões

esquerdo e direito do mouse e aguardando o aparecimento do ponteiro de arraste; em seguida, arraste para definir um fator de zoom. Arrastar para cima reduz o zoom do modelo. Arrastar para baixo amplia o modelo.

O modelo também pode ser transladado e ampliado com a barra de ferramentas de translação ou com as teclas do teclado

Tools > Translation Toolbar
