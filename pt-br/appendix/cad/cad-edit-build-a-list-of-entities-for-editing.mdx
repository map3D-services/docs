---
title: "CAD > Editar > Criar uma lista de entidades para edição"
---

Esta rotina pode ser iniciada escolhendo qualquer função de edição (p. ex., um botão) ou simplesmente clicando com o botão direito em qualquer entidade.

Ao iniciar qualquer rotina de edição de entidades, você será primeiro solicitado a montar uma lista das entidades que deseja editar

![Figure from page 132](/images/page-132-img-1.png)

- Se Tools > Shift-key Selection estiver marcada, você deve manter pressionada a tecla Shift para fazer seleções múltiplas.

- Por padrão, as entidades selecionadas são adicionadas à lista; porém, se a tecla Ctrl for mantida pressionada, as entidades selecionadas serão removidas da lista.

- Enquanto mantém pressionada a tecla Shift ou Ctrl, você pode arrastar para abrir uma janela de interseção.

- Pressionar a barra de espaço ativa automaticamente a última função de edição usada.

- Manter a tecla Alt pressionada ao clicar com o botão direito repete automaticamente a última função de edição usada.

Esta barra de ferramentas controla as diversas funções usadas na montagem da lista.

Interrompe a edição. Seleciona entidades escolhendo uma superfície por vez. Seleciona entidades escolhendo grupos inteiros que compõem um bloco. Inclui todas as entidades com o número selecionado.

Inclui todas as entidades com a cor selecionada.

Inclui todas as entidades com o número de material selecionado.

- Um mesmo bloco pode ter materiais diferentes conforme a etapa de lavra ativa no momento.

- Ao usar esta função, certifique-se de selecionar a etapa de lavra apropriada File > Mining Step

Inclui todas as entidades escavadas com o número de etapa de lavra selecionado.

Inclui todas as entidades dentro da janela selecionada.

- As entidades só serão selecionadas se a entidade inteira estiver contida na janela.

- Se (modo de seleção de superfície) estiver ativo, apenas as superfícies serão incluídas.

- Se (modo de seleção de entidade) estiver ativo, todas as superfícies que compõem o bloco serão incluídas.

Inclui todas as entidades dentro da janela de interseção.

- As entidades serão selecionadas mesmo que apenas parte da entidade esteja dentro da janela.

- Esta função também pode ser ativada mantendo pressionada a tecla Shift ou Ctrl e arrastando para abrir uma janela de interseção.

- Se (modo de seleção de superfície) estiver ativo, apenas as superfícies serão incluídas.

- Se (modo de seleção de entidade) estiver ativo, todas as superfícies que compõem o bloco serão incluídas.

- As entidades selecionadas serão adicionadas à lista.

As entidades selecionadas serão removidas da lista. Desfaz a última seleção.

Refaz a última seleção.

Depois de selecionar as entidades desejadas, você pode escolher qualquer um dos botões de edição:

CAD > Edit > Entity Properties Edita o tipo de bloco, a cor, a sequência de lavra etc.

CAD > Edit > Erase Entities Apaga as entidades selecionadas. CAD > Edit > Move Entities Move as entidades selecionadas. CAD > Edit > Copy Entities Copia as entidades selecionadas. CAD > Edit > Scale Entities Dimensiona as entidades selecionadas. CAD > Edit > Rotate Azimuth Gira o azimute das entidades selecionadas. CAD > Edit > Rotate Dip Gira o mergulho das entidades selecionadas. CAD > Edit > Dump to File Despeja as entidades selecionadas em um arquivo. CAD > Edit > Group Agrupa as entidades selecionadas em um único bloco.

- clique duas vezes em qualquer vértice para executar a função destacada,

- clique com o botão direito para ver uma lista de opções.

Depois de concluir qualquer operação de edição, você tem uma chance de desfazer as modificações selecionando
