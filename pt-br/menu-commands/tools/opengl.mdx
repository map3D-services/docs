## 5.6.4.1 OpenGL &lt;On/Off>

Habilita o suporte a OpenGL.

OpenGL é uma interface padrão da indústria para renderização gráfica 3D de alta qualidade. As principais vantagens de usar OpenGL são a aceleração por hardware da exibição gráfica e o suporte a z-buffer. Naturalmente, para obter a aceleração por hardware, você precisa ter um adaptador gráfico que suporte OpenGL e o driver de vídeo OpenGL instalado.

Veja Tools > OpenGL Parameters para ver a configuração do OpenGL.

Veja Tools > OpenGL Anti-aliasing para suavizar linhas.

## 5.6.4.2 Parâmetros do OpenGL

Informa sobre a configuração do OpenGL:

Support OpenGL – indica se um driver OpenGL está instalado e habilitado.

Driver or Hardware Support - indica se o OpenGL é suportado pelo seu adaptador gráfico.

Double Buffered – indica que há memória suficiente para suportar buffer duplo.

Color Buffer Bits – indica o número de bits usados para o buffer de cor.

Depth Buffer Bits – indica o número de bits usados para o z-buffer.

## 5.6.4.3 Antisserrilhado (antialiasing) do OpenGL

Habilita a suavização de pontos, linhas e arestas de polígonos.

Este recurso do OpenGL melhora a aparência, mas deixa a renderização mais lenta.

View > Render > Line Width pode ser usado para habilitar o desenho de linhas mais largas. Isso também ajudaria a suavizar o desenho de linhas, com impacto semelhante no desempenho.

## 5.6.4.4 Redesenho do OpenGL

Habilita o redesenho da tela pelo OpenGL quando a janela precisa ser atualizada.

A janela de exibição do Map3D precisa ser atualizada toda vez que uma caixa de diálogo é movida ou removida. Essa atualização pode ser feita salvando a janela de exibição em um buffer secundário (esta opção não está marcada) ou simplesmente redesenhando a tela (esta opção está marcada).

Esta opção normalmente deve estar marcada, mas pode ser desabilitada para adaptadores gráficos problemáticos.

## 5.6.4.5 Seleção com OpenGL

Habilita o OpenGL a localizar entidades gráficas na tela.

Quando você clica com o botão esquerdo em uma entidade, o Map3D precisa determinar qual entidade foi selecionada. Isso pode ser determinado pelo OpenGL ou internamente pelo Map3D.

Esta opção normalmente deve estar marcada, mas pode ser desabilitada para adaptadores gráficos problemáticos.

## 5.6.4.6 Cursor em cruz do OpenGL

Alterna entre o desenho do cursor em cruz pelo OpenGL e pela API do Windows.

Esta opção normalmente deve estar marcada, mas pode ser desabilitada para adaptadores gráficos problemáticos.

Para desabilitar completamente o desenho do cursor em cruz, selecione Tools > Crosshairs.

## 5.6.4.7 Edição interativa com OpenGL

Habilita o desenho interativo pelo OpenGL das formas modificadas durante as operações de edição.

Esta opção normalmente deve estar marcada, mas pode ser desabilitada para adaptadores gráficos problemáticos.
