---
title: "Teste de desempenho do disco"
---

Testa o desempenho do sistema de disco rígido.

Este teste simula o comportamento do Map3D durante a etapa de solução da análise BEM.

Buffer Size: tamanho do buffer usado para leituras e gravações em disco. O Map3D usa um buffer de 256K para suas leituras e gravações de arquivos.

Write Through: instrui o sistema a gravar sem passar por nenhum cache intermediário, diretamente no disco. O Map3D usa "Write Through" para suas gravações de arquivos.

No Buffering: instrui o sistema a gravar no arquivo sem buffer ou cache intermediários. O Map3D usa "No Buffering" para suas gravações de arquivos.

Asynchronous I/O: instrui o sistema a permitir que mais de uma operação de leitura e/ou gravação seja realizada simultaneamente. Esta opção só é suportada no Windows NT/2000. O Map3D pode ser instruído a usar este recurso com

#### Analysis > Options > Async I/O

Size MB: tamanho do arquivo usado para o teste. Recomenda-se fazer este teste com um arquivo grande (consideravelmente maior que a quantidade de RAM). Drive: unidade de disco usada para o teste.

Os resultados importantes são:

Write rate: o número de MBytes gravados no disco por segundo. Você deve esperar mais de 5-10 MB/segundo.

Read rate: o número de MBytes lidos do disco por segundo. Você deve esperar mais de 5-10 MB/segundo.

Multiply/sec: o número de multiplicações de ponto flutuante realizadas por segundo. Você deve esperar mais de 50 MFLOPS.
