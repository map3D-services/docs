---
title: "Seleção com a tecla Shift"
---

Quando essa opção está marcada, o usuário precisa manter pressionada a tecla Shift para fazer seleções múltiplas ao criar uma lista de entidades a editar com qualquer um dos comandos CAD > Edit. Se a tecla Shift não estiver pressionada, o comando de edição será executado automaticamente após a primeira seleção.

Quando não está marcada, o comando de edição não é executado automaticamente. Quando a lista de entidades estiver completa, o usuário deve:

- selecionar qualquer um dos botões de edição,

executar a função destacada,

- clicar duas vezes em qualquer vértice para executar a função destacada,

- ou clicar com o botão direito para ver uma lista de opções.
