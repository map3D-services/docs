---
title: "Visualizar plano da grade"
---

View > View YZ Plane: vista com o eixo y para a direita e o eixo z para cima. View > View ZX Plane: vista com o eixo x para a direita e o eixo z para cima. View > View Grid Plane: o plano de grade selecionado ocupa toda a tela

No PDF, esta entrada abre a seção [Visualizar plano XY](/pt-br/menu-commands/view-menu/view-xy-plane).
