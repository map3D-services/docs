---
title: "Visualizar plano XY"
---

Reorienta a vista do modelo para uma posição de visualização especial:

View > View XY Plane: vista com o eixo x para a direita e o eixo y para cima.

View > View YZ Plane: vista com o eixo y para a direita e o eixo z para cima. View > View ZX Plane: vista com o eixo x para a direita e o eixo z para cima. View > View Grid Plane: o plano de grade selecionado ocupa toda a tela

#### CAD > Grid Selection

#### Plot > Grid Selection

View > View Digitizer Plane   a área de digitalização atual ocupa toda a tela

#### CAD > Digitizer Setup.

Observações:

A posição de visualização atual pode ser salva

#### File > Save View

ou restaurada

File > Restore View

entre sessões.
