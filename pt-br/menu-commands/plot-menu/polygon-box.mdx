---
title: "Caixa poligonal"
---

Calcula o valor médio ponderado de todos os pontos de contorno selecionados. Esta função também pode ser ativada com View > Length.

Você será solicitado a selecionar uma série de vértices para definir um polígono fechado, clicando uma vez com o mouse em cada um:

- Você deve manter pressionada a tecla Shift para que vários segmentos de linha possam ser selecionados.

- Uma forma poligonal fechada é definida fechando a polilinha ao selecionar o ponto inicial.

- Se você definir uma forma poligonal fechada, os pontos de contorno contidos no polígono serão incluídos na média.

- A rotina de média não funcionará se você definir uma polilinha aberta (ao não selecionar o ponto inicial).

- Para ver a localização dos pontos de contorno reais, ative a exibição de trajetórias (Plot > Options > Trajectories). Os pontos de contorno ficam onde as trajetórias são desenhadas.

A média é calculada multiplicando cada valor selecionado pela área da superfície ou célula de grade associada e somando esses produtos. Este resultado é apresentado como "Weighted Sum". O "Average" é determinado dividindo a soma ponderada pela área total.

Todos os valores são acumulados como componentes vetoriais. As tensões principais são determinadas a partir da média ponderada das componentes cartesianas. As componentes de deslocamento, de fluxo e de cisalhamento superficial são determinadas a partir da média ponderada das componentes vetoriais.

Observe que, para tensões, a "Weighted Sum" é na verdade a força total atuando sobre a superfície.

Se você multiplicar pelo módulo de cisalhamento, a "Weighted Sum" do deslocamento plástico de cisalhamento (ride) é na verdade o momento sísmico.
