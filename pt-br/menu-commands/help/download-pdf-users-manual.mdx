---
title: "Download: manual do usuário em PDF"
---

Baixar o manual do usuário em HTML (Map3D.chm, 4 MB)

O manual do usuário em HTML pode ser baixado em Tools > Download HTML User's Manual. Esse manual está no formato nativo de ajuda HTML do Windows.

Baixar o manual do usuário em PDF (Map3D_Help.pdf, 7 MB)

O manual do usuário em PDF pode ser baixado em Tools > Download PDF User's Manual. Esse manual está em formato PDF e é uma boa opção para impressão.

Baixar o manual do usuário em e-book (Map3D_Help.exe, 5 MB)

O manual do usuário em e-book pode ser baixado em Tools > Download Ebook User's Manual. Esse manual está em um formato de livro eletrônico independente.
