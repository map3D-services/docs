Download: atualização do Map3D (setup.exe 18MB)

Baixa a atualização mais recente do Map3D no site do Map3D [www.map3d.com/update.htm](https://www.map3d.com/update.htm)

A atualização completa inclui todos os executáveis do Map3D, as rotinas de instalação automatizada, o Manual do usuário do Map3D em formato HTML e os drivers da chave Sentinel SuperPro, além de alguns arquivos de exemplo.

Como a atualização completa (setup.exe) é bastante grande (8MB), uma alternativa é baixar apenas os executáveis atualizados (Map3D.zip).

Download: atualização do Map3D (Map3D.zip 8MB)

Isso

não inclui as rotinas de instalação, o Manual do usuário do Map3D em formato HTML nem os drivers da chave Sentinel SuperPro. Observe que o Manual do usuário do Map3D em HTML (Map3D.chm) é necessário para que a ajuda contextual funcione dentro do Map3D.

O manual do usuário pode ser baixado em vários formatos:

Baixar o Manual do usuário em HTML (Map3D.chm 4MB)

O Manual do usuário em HTML pode ser baixado em Help > Help > Download HTML User's Manual. Este manual está no formato nativo de ajuda HTML do Windows.

Baixar o Manual do usuário em PDF (Map3D_Help.pdf 7MB)

O Manual do usuário em PDF pode ser baixado em Help > Download PDF User's Manual. Este manual está em formato PDF e é uma boa opção para impressão.

Baixar o Manual do usuário em e-book (Map3D_Help.exe 5MB)

O Manual do usuário em e-book pode ser baixado em Help > Download Ebook User's Manual. Este manual está em um formato de e-book independente.
