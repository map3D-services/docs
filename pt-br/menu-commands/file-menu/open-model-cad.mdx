---
title: "Abrir modelo (CAD)"
---

Carrega um modelo a partir de um arquivo.

Depois de carregado, é possível executar qualquer etapa de análise do Map3D desejada.

Para adicionar ou editar blocos de lavra e configurar a análise do Map3D, use

#### Analysis > Go to CAD.

Ao carregar o modelo, o Map3D verifica a consistência básica dos parâmetros de modelagem (p. ex., se um material é usado, suas propriedades devem estar especificadas na lista de materiais).

Você será solicitado a procurar o nome, a localização e o formato do arquivo do modelo. Os modelos podem ser carregados de vários tipos de arquivo:

- O formato Map3D-INP é um arquivo de dados ASCII editável com a extensão ".INP". Este é o formato de modelo recomendado do Map3D. Todas as funcionalidades do Map3D são suportadas com este formato.

- O formato AutoCAD-DXF é um formato popular de intercâmbio de desenhos com a extensão ".DXF". Este formato é útil para trocar dados de modelo com outros softwares CAD.

- O formato de arquivo de pontos é um arquivo de dados ASCII universal com a extensão ".PNT". Este formato é útil para trocar dados brutos de modelo com outros softwares CAD.

Os dados geométricos e de materiais do modelo carregado podem sobrescrever os dados existentes do modelo ou ser mesclados a eles. As opções de sobrescrever/mesclar:

- File > Open > Merge Geometries

- File > Open > Merge Materials

aparecem na parte inferior da caixa de diálogo de abertura de arquivo.

#### Mesclar vários arquivos em um único modelo

Você pode selecionar vários arquivos ao mesmo tempo mantendo pressionadas as teclas padrão do Windows "shift" ou "ctrl" para seleções múltiplas.

Esses arquivos serão mesclados em um único modelo/banco de dados.

Isso permite manter partes separadas dos dados do modelo em arquivos diferentes e depois mesclá-las facilmente em um único modelo/banco de dados.

Outra forma de mesclar vários arquivos é selecionar a opção "Merge Geometries" antes de selecionar o arquivo adicional que você deseja adicionar ao modelo/banco de dados existente.

Isso é útil se você já tem um modelo aberto e deseja adicionar mais dados de modelo a ele.

#### Notas:

Para acesso rápido em uma sessão posterior, cada vez que você abre um arquivo, seu nome é salvo em

#### File > Recent Files

e o diretório de trabalho é salvo em

File > Open > Recent Directories.

Para carregar resultados de análise, use

File > Open Analysis Results.

Para reiniciar uma análise que foi abortada ou interrompida por queda de energia ou travamento do sistema operacional, use

File > Restart an Analysis.
