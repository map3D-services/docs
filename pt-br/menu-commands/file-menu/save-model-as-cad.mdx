---
title: "Salvar modelo como (CAD)"
---

Salva o modelo atual com outro nome de arquivo, local e formato.

Os modelos podem ser salvos em vários tipos de arquivo:

- O formato Map3D-INP é um arquivo de dados ASCII editável com a extensão ".INP". É o formato de modelo recomendado do Map3D. Todos os recursos do Map3D são compatíveis com esse formato.

- O formato AutoCAD-DXF é um formato popular de intercâmbio de desenhos com a extensão ".DXF". Esse formato é útil para trocar dados do modelo com outros softwares CAD.

- O formato de arquivo de pontos é um arquivo de dados ASCII universal com a extensão ".PNT". Esse formato é útil para trocar dados brutos do modelo com outros softwares CAD.

Para salvar com o mesmo nome, local ou formato, use

#### File > Save Model.
