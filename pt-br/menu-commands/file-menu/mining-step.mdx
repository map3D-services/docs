---
title: "Etapa de lavra nº"
---

Seleciona outra etapa de lavra para visualização.

Se a análise BEM do Map3D para a etapa de lavra selecionada tiver sido concluída, o arquivo de reinício dessa etapa será carregado. Se o arquivo de reinício não existir (porque a análise não foi concluída), apenas a geometria dessa etapa de lavra será exibida.

Alternar entre etapas de lavra com esse recurso é mais rápido do que carregar um arquivo de reinício com

#### File > Open Analysis Results

pois a ordenação de elementos e grades não precisa ser repetida para o mesmo modelo.

Para acesso rápido a diferentes etapas de lavra, use

#### File > Mining Step.

na barra de ferramentas de visualização

#### Tools > View Toolbar.

Se desejar, botões individuais de etapas de lavra podem ser colocados na barra de ferramentas de visualização com

#### Tools > View Toolbar Configure.

Você pode avançar ou voltar rapidamente uma etapa de lavra mantendo pressionada a tecla Alt e pressionando, respectivamente, a tecla + ou –.
