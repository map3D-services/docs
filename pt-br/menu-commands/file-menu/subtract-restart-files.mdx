---
title: "Subtrair arquivos de reinício"
---

Subtrai os resultados do arquivo de reinício selecionado dos resultados atualmente carregados.

Será solicitado que você localize o nome, o local e o formato do arquivo de reinício.

Observações:

Apenas os resultados nos planos de grade são subtraídos.

Esse recurso pode ser usado para subtrair uma etapa de lavra de outra.

Se forem subtraídos resultados de modelos diferentes, esses modelos devem ter planos de grade idênticos.

Na subtração, todas as componentes cartesianas (tensão, deformação e deslocamento) são subtraídas e, em seguida, as componentes principais dessas variações são recalculadas para exibição.

A geometria do modelo atualmente carregado é mantida para exibição.
