---
title: "Abrir linhas de construção"
---

Carrega linhas de construção a partir de um arquivo.

As linhas de construção são usadas para definir a localização detalhada de feições subterrâneas, como escavações, contatos, estruturas etc. Normalmente, um modelo do Map3D é construído sobre esses dados de linhas de construção.

Você será solicitado a procurar o nome, a localização e o formato do arquivo de linhas de construção. As linhas de construção podem ser carregadas de vários tipos de arquivo:

- O formato de arquivo de pontos é um arquivo de dados ASCII universal com a extensão ".PNT". Este formato é útil para trocar dados brutos de linhas de construção com outros softwares CAD.

- O formato AutoCAD-DXF é um formato popular de intercâmbio de desenhos com a extensão ".DXF". Este formato é útil para trocar dados de linhas de construção com outros softwares CAD.

Os dados de linhas de construção carregados podem sobrescrever os dados existentes ou ser mesclados a eles. A opção sobrescrever/mesclar

#### File > Open > Merge Geometires

aparece na parte inferior da caixa de diálogo de abertura de arquivo.

#### Mesclar vários arquivos em um único banco de dados

Você pode selecionar vários arquivos ao mesmo tempo mantendo pressionadas as teclas padrão do Windows "shift" ou "ctrl" para seleções múltiplas.

Esses arquivos serão mesclados em um único banco de dados.

Isso permite manter partes separadas dos dados de linhas de construção em arquivos diferentes e depois mesclá-las facilmente em um único banco de dados.

Outra forma de mesclar vários arquivos é selecionar a opção "Merge Geometries" antes de selecionar o arquivo adicional que você deseja adicionar ao banco de dados existente.

Isso é útil se você já tem dados de linhas de construção abertos e deseja adicionar mais dados de linhas de construção a eles.
