---
title: "VISTA DE RESULTADOS (abrir resultados da análise)..."
---

Carrega os resultados da análise a partir de um arquivo de reinício.

Será solicitado que você localize o nome, o local e o formato do arquivo de reinício.

Depois de carregados, o usuário pode visualizar e processar os resultados da análise. É possível gerar plotagens de contornos de qualquer combinação desejada de componentes de tensão, deformação e deslocamento. Os resultados podem ser exibidos como valores totais ou como a diferença de valor entre etapas de lavra.

Para mudar de uma etapa de lavra para outra, use

#### File > Mining Step.

#### Observações:

Para acesso rápido em uma sessão posterior, o nome de cada arquivo aberto é salvo em

#### File > Recent Files

e o diretório de trabalho é salvo em

#### File > Open > Recent Directories.

Para recarregar o arquivo do modelo a fim de editar blocos de lavra e configurar a análise do Map3D, use

#### Analysis > Go to CAD.

Para carregar outro arquivo de modelo, use

#### File > Open (Model).
