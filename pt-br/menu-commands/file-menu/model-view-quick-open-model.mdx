title: "VISTA DO MODELO (abertura rápida do modelo)..."
---

Carrega rapidamente um modelo de um arquivo, mas ignora todo o pré-processamento. Observe que você não pode usar nenhuma função CAD até carregar o arquivo com Open Model (CAD) ou selecionar "Go To CAD" no menu principal do programa.

#### Mesclar vários arquivos em um modelo

Você pode selecionar vários arquivos ao mesmo tempo mantendo pressionadas as teclas padrão do Windows "Shift" ou "Ctrl".

Esses arquivos serão mesclados em um único modelo ou banco de dados.

Isso permite manter partes separadas dos dados do modelo em arquivos diferentes e depois mesclá-las facilmente em um único modelo ou banco de dados.

Outra forma de mesclar vários arquivos é selecionar a opção "Merge Geometries" antes de selecionar o arquivo adicional que você deseja acrescentar ao modelo ou banco de dados existente.

Isso é útil se você já tem um modelo aberto e quer acrescentar mais dados a ele.
