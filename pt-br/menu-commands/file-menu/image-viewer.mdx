---
title: "Visualizador de imagens"
---

Exibe em uma janela arquivos PNG (Portable Network Graphics, *.PNG), GIF (Graphics Interchange Format) ou BMP (bitmap independente de dispositivo do Windows, *.BMP).

Quando o visualizador é iniciado, a imagem atual da tela é exibida.

O visualizador pode ser usado para exibir imagens individuais, GIFs animados e sequências de imagens.

As imagens da tela podem ser salvas em arquivos com

- File > Output > PNG, GIF or BMP Image

- File > Output > PNG, GIF or BMP (B&W flipped)

- File > Output > Image Recorder
