---
title: "View Grid plane"
---

View > View YZ Plane - view with the y-axis to the right and z-axis up. View > View ZX Plane - view with the x-axis to the right and z-axis up. View > View Grid Plane - currently selected grid plane fills the screen

In the PDF, this entry opens the [View XY plane](/menu-commands/view-menu/view-xy-plane) section.
