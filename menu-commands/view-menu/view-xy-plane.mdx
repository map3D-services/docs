---
title: "View XY plane"
---

Reorients the view of the model to a special view position:

View > View XY Plane - view with the x-axis to the right and y-axis up.

View > View YZ Plane - view with the y-axis to the right and z-axis up. View > View ZX Plane - view with the x-axis to the right and z-axis up. View > View Grid Plane - currently selected grid plane fills the screen

#### CAD > Grid Selection

#### Plot > Grid Selection

View > View Digitizer Plane   current digitizing area fills the screen

#### CAD > Digitizer Setup.

Notes:

The current view position can be saved

#### File > Save View

or restored

File > Restore View

between sessions.
