---
title: "Restore named CAD State"
---

Restores a previously saved CAD State *.sav file.

This includes all information associated with your current session including: geometry, control parameters, material properties, construction lines, etc.

This allows you to return to exactly where you left off in a previously saved Map3D session, or in the event of program crash.

#### Related topics:

Restore Auto-Save CAD State – restores the last automatically saved CAD State. Refer to Restore Auto-Saved CAD State

Save named CAD State – saves the current CAD State to a *.sav file. Refer to Save named CAD State
