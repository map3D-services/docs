---
title: "分析对话框"
---

显示可滚动的分析活动对话框，内容包括：

INFO：描述当前操作的消息。WARNING：描述可能导致问题的潜在不一致的消息。

ERROR：描述将导致程序终止运行的错误的消息。

在矩阵求解期间，Map3D 会尝试逐步求解保存在系数矩阵中的联立方程，以及描述其他材料区、断层滑动、蠕变等的任何其他方程。当最大表面应力误差

Plot > Surface Components > Serr Stress Error

和最大破坏准则误差

Plot > Surface Components > Ferr Failure Error

降至用户指定的应力容差 _STOL_ 以下时，即认为已得到收敛解

Analysis > CParams > STOL

随着求解的进行，会显示有关求解的汇总信息：

is=1   it=3   ser=-1.29E+01   fer= 0.00E+00   rms=5.85E+00   ratio=0.414   converging

is - 当前时间步编号。

- 此计数器仅用于非线性蠕变分析（包括断层滑动和三维材料非线性）。

- Map3D 使用隐式求解方法求解蠕变问题中的黏塑性部分。

- 每当 Map3D 得到平衡蠕变解时，会将蠕变应变增量加到总塑性应变中，然后开始新的时间步（即 is 计数器加 1）。

it - 当前迭代次数。

- Map3D 使用迭代求解方法求解保存在系数矩阵中的联立方程。

- 此计数器表示已执行的累计迭代次数。

ser - 最大表面应力误差。

- 迭代求解器的工作方式是先确定每个联立方程当前解的误差，再通过逐次逼近的过程减小这些误差。

- 此参数表示所有方程中的最大误差。

fer - 最大破坏准则误差。

- 此参数仅用于非线性蠕变分析（包括断层滑动和三维材料非线性）。

- 除非指定了某种黏性且问题进入非线性状态，否则此参数应始终接近于零。

- 在后一种情况下，黏性蠕变可使应力状态超出破坏准则，表明缺乏静力平衡。

- 此参数表示所有方程中的最大黏性应力。

rms - 所有表面应力误差的均方根。

ratio - 当前 rms 值与上一次迭代 rms 值之比。

- 它可以反映求解推进的快慢。

converging - 表示问题正在收敛的指示。

- 如果 ratio 大于 1，此指示也可能显示为 diverging（发散）。

注意：

由于平滑滚动会限制信息写入信息区的速率，可能会大大减慢 Map3D 分析。建议不要使用平滑滚动

Tools > Smooth Scroll
