---
title: "分析 > 选项 > 批处理"
---

设置分析批处理队列。

如果用户有多个模型需要运行，可以在此批处理队列中指定。选择

Analysis > Options > Batch > Execute Batch Queue

后，所有已选中的模型都将运行，无需用户进行任何交互响应。

选中某个批处理文件以供执行时，系统会提示你搜索模型文件名、位置和文件格式。如果搜索成功，该模型将被选中。

Batch File Setup 对话框中的第二列可用于设置分析选项（如有需要）。这些设置会覆盖 Analysis > Options 对话框中设置的任何选项。

#### 控制台模式：

Map3D 可以从 Windows 命令提示符或 *.bat 文件启动（如有需要）。命令行选项可用于文本文件脚本，也可在命令提示符中输入。操作步骤很简单，按如下方式创建一个 *.bat 文件：

**Map3D filename.inp -option1 - option2 ...** （其中“filename.inp”是要分析的模型文件的名称）。

选项如下：

- **-analysis** （指示 Map3D 运行分析，还必须提供“filename.inp”）。

- **-console** （Map3D 运行时仅显示“Analysis Dialog”）。

   - （Map3D 运行时不显示任何内容，并在分析完成后停止）。

- **-stop** （分析完成后停止 Map3D）。

你还可以按如下方式打开结果文件：

**Map3D filename.001** （其中“filename.001”是要显示的结果文件的名称）。

例如，如果要运行 Map3D 分析且仅显示日志窗口，可按如下方式启动：

#### Map3D filename.inp -console -analysis

例如，如果要运行 Map3D 分析且不显示日志窗口，可按如下方式启动：

#### Map3D filename.inp -silent -analysis

#### 注意：

批处理模型文件名会在每次执行 Map3D 时保存和恢复。

未选中的模型文件不会在批处理模式下执行。

只需中止当前分析，即可随时中断批处理队列

Analysis > Abort
