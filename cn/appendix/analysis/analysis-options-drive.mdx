---
title: "分析 > 选项 > 驱动器编号"
---

在 Map3D BEM 分析期间为系数矩阵指定临时驱动器。

如果安装了多个磁盘驱动器，可以使用此选项指示 Map3D 将系数矩阵存放在何处。当第一个驱动器已满时，Map3D 会将矩阵的其余部分写入下一个临时驱动器。

当求解矩阵过大而无法放入 RAM 时（参见 Analysis > Options > VRAM 和 Analysis > Options > PRAM），矩阵求解会变成 I/O 密集型操作，仅取决于计算机的 I/O 速率。在这种情况下，由于磁盘性能较慢，分析时间的很大一部分会耗费在求解阶段。

要解决此问题，用户必须安装多个高速磁盘。

Map3D 通过多处理器/多驱动器选项完全支持并行处理和并行磁盘 I/O。

如果你已获得使用多处理器/多驱动器选项的许可，Map3D 会将这些驱动器设置为 RAID 阵列，使 I/O 以重叠方式并行地在所有驱动器上进行，并与计算同时执行。

按此方式设置后，I/O 性能可随阵列中驱动器的数量成比例提高。

在下面的基准测试中，同一模型分别使用 1 个、2 个和 4 个磁盘运行。

||1 个磁盘|2 个磁盘|4 个磁盘|8GB PRAM|
|---|---|---|---|---|
|实测磁盘吞吐量 (MB/sec)|55|112|206|3000 equivalent|
|矩阵求解（小时）|0.546|0.282|0.163|0.033|
|求解速度提升|1x|1.9x|3.3x|16x|
|总分析时间（4 核）|0.640|0.376|0.257|0.107|
|总速度提升|1x|1.7x|2.5x|6x|

此基准测试中使用的磁盘是较旧的 50-60 MB/sec 驱动器（Seagate Barracuda 7200.7）。较新的机械硬盘速度可达 100 MB/sec（Seagate Momentus 7200.4）。SATA2 固态硬盘每个驱动器可提供超过 250 MB/sec。SATA3 固态硬盘每个驱动器可提供超过 500 MB/sec。多个固态硬盘和/或 NVMe 驱动器的性能有望接近 PRAM。请注意，某些主板对总吞吐量有限制，可能需要附加控制器适配卡。

要确定你是否已获得使用多处理器/多驱动器选项的许可，请查看 Analysis > Options > #Threads。

如果你已获得使用多处理器/多驱动器选项的许可，设置 SE_MANAGE_VOLUME_NAME 权限可获得更快的磁盘速率。

此功能适用于以下 Windows 版本：

- Windows NT 4.0、Windows 2000 Professional 和 Server（最大 4 GB）。

- Windows 2000 Advanced Server（最大 8 GB）。

- Windows 2000 Datacenter Server（最大 32 GB）。

- Windows XP Professional 和 Windows Server 2003（最大 4 GB）。

- Windows Server 2003 Enterprise Edition（最大 32 GB）。

- Windows Server 2003 Datacenter Edition（最大 64 GB）。

- Windows 10 和 11 Pro（家庭版不支持）。

要设置“SE_MANAGE_VOLUME_NAME”权限，请按以下步骤操作：

Control Panel > Administrative Tools > Local Security Policies

然后设置

Local Policies > User Rights Assignment > Perform Volume Maintenance Tasks > Add User or Group > Everyone

必须重新启动后此设置才会生效。

注意：

必须在进行 Map3D BEM 分析之前选中此功能

#### Analysis > BEM Analysis

应指定系统中最快的驱动器。你可以使用以下功能测试驱动器性能

Tools > Disk Performance Test
