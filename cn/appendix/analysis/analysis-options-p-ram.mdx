---
title: "分析 > 选项 > P-RAM"
---

在 Map3D BEM 分析期间将部分系数矩阵存储在物理 RAM 中。

如果您的计算机安装了大容量 RAM，此选项可能会显著加快执行速度，因为从 RAM 检索数据比从磁盘快得多。虽然 32 位 Windows 只允许每个进程寻址 2GB，但对于计算机中装有大容量 RAM 的用户，可以使用 AWE（Address Windowing Extensions，地址窗口扩展）访问物理 RAM。AWE 允许访问计算机中所有可用的 RAM。大多数系统可支持 4GB RAM，有些可支持超过 64GB。不同版本的 Windows 提供不同级别的 AWE 支持，范围从 1GB 到 512GB。以下 Windows 版本提供 AWE 支持：

- Windows 10 Professional 和 Server（最大 4 GB）。

- Windows NT 4.0、Windows 2000 Professional 和 Server（最大 4 GB）。

- Windows 2000 Advanced Server（最大 8 GB）。

- Windows 2000 Datacenter Server（最大 32 GB）。

- Windows XP Professional 和 Windows Server 2003（最大 4 GB）。

- Windows Server 2003 Enterprise Edition（最大 32 GB）。

- Windows Server 2003 Datacenter Edition（最大 64 GB）。

- Windows 7 和 8。

- Windows 10 和 11 Pro（家庭版不支持此功能）。

AWE 需要“SE_LOCK_MEMORY”权限。要启用 AWE，请按以下步骤操作：

Control Panel > Administrative Tools > Local Security Policies

然后设置

Local Policies > User Rights Assignment > Lock Pages in Memory > Add User or Group > Everyone

必须重新启动后此设置才能生效。

注意：

必须在进行 Map3D BEM 分析之前选中此功能

#### Analysis > BEM Analysis.

仅应分配您希望 Map3D 使用的 RAM 量，并确保为您打算运行的任何其他应用程序留出足够的空间。

切勿将此参数设置为大于可用 RAM 的值，否则会导致操作系统过度分页，从而显著减慢分析速度。
