对模型进行离散化。

所有开挖面都会通过在需要结果的位置加密单元而自动离散化

View > Render > Discretize

分析结果在 DD 表面和一系列用户定义的网格平面上计算

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane

或在用户定义的点上计算

#### Analysis > Options > MSCALC

网格平面会自动离散为一系列场点，并在这些场点上计算位移、应变和应力。

离散化分析可以使用不同的控制参数重复任意多次。

用户可以通过指定各种控制参数（单元长度 _AL_ 、网格间距 _AG_ 、单元离散化 _DON_ 、网格离散化 _DOL_ ），完全控制模型的离散化方式

#### Analysis > CParams

也可以通过指定三维 FF 块体和 DD 平面的最大单元宽度

CAD > Edit > Entities > Maximum Element Width

以及场点网格的最大单元宽度来控制

CAD > Edit > Entities > Maximum Element Width

有关如何设置这些控制参数的详细讨论，请参阅 Discretization and Lumping。

选项：

Analysis > Options > MSCALC Analysis > Options > LERD/LSS Analysis > Options > Lumping
