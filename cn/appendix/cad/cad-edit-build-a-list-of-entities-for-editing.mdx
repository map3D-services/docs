---
title: "CAD > 编辑 > 创建待编辑实体列表"
---

可通过选择任一编辑功能（如按钮），或直接右键单击任意实体来启动此例程。

启动任何实体编辑例程时，系统会首先提示您创建待编辑的实体列表

![Figure from page 132](/images/page-132-img-1.png)

- 如果选中了 Tools > Shift-key Selection，则必须按住 Shift 键才能进行多重选择。

- 默认情况下，所选实体会添加到列表中；但如果按住 Ctrl 键，所选实体将从列表中移除。

- 按住 Shift 键或 Ctrl 键时，可拖出一个交叉窗口。

- 按空格键会自动激活上次使用的编辑功能。

- 右键单击时按住 Alt 键，会自动重复上次使用的编辑功能。

该工具栏用于控制列表创建过程中的各项功能。

中止编辑。逐个选取表面来选择实体。通过选取构成块体的整组表面来选择实体。包含所有具有所选编号的实体。

包含所有具有所选颜色的实体。

包含所有具有所选材料编号的实体。

- 根据当前激活的开采步，同一块体可能包含不同的材料。

- 使用此功能时，请确保选择了正确的开采步 File > Mining Step

包含所有在所选开采步编号中开挖的实体。

包含所选窗口内的所有实体。

- 只有整个实体都位于窗口内时，才会被选中。

- 如果（表面选择模式）处于激活状态，则只包含表面。

- 如果（实体选择模式）处于激活状态，则包含构成该块体的所有表面。

包含交叉窗口内的所有实体。

- 只要实体有一部分位于窗口内，即会被选中。

- 也可以按住 Shift 键或 Ctrl 键并拖出交叉窗口来激活此功能。

- 如果（表面选择模式）处于激活状态，则只包含表面。

- 如果（实体选择模式）处于激活状态，则包含构成该块体的所有表面。

- 所选实体将添加到列表中。

所选实体将从列表中移除。撤销上一次选择。

重做上一次选择。

选好所需实体后，可以选择以下任一编辑按钮：

CAD > Edit > Entity Properties 编辑块体类型、颜色、开采顺序等。

CAD > Edit > Erase Entities 删除所选实体。CAD > Edit > Move Entities 移动所选实体。CAD > Edit > Copy Entities 复制所选实体。CAD > Edit > Scale Entities 缩放所选实体。CAD > Edit > Rotate Azimuth 旋转所选实体的方位角。CAD > Edit > Rotate Dip 旋转所选实体的倾角。CAD > Edit > Dump to File 将所选实体转储到文件。CAD > Edit > Group 将所选实体合并为单个块体。

- 双击任意顶点以执行高亮显示的功能，

- 右键单击可查看选项列表。

完成任何编辑操作后，您有一次撤销修改的机会，方法是选择

#### Undo

您也可以恢复相同的选择集并再次修改同一组实体，方法是选择

Redo

您可以使用以下命令调整双击时间

Tools > Double Click Time
