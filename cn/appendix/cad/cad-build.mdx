title: "CAD > 构建"
---

激活 Build 工具栏。

该工具栏用于快速访问 Map3D 边界元分析模型构建与编辑阶段所使用的实体构建功能 Analysis > Go to CAD。

CAD > Build > FF Loop 构建多角点的三维 FF 型块体，用于开挖空间和替代材料区。

CAD > Build > DD Loop 构建多角点的 DD 型块体，用于层状开采、薄矿层或断层面。

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane 构建用于计算分析结果的网格平面。

![Figure from page 320](/images/page-320-img-13.png)

CAD > Build > Grid Line 构建用于计算分析结果的网格线。

CAD > Build > Construction Lines 构建构造线，以定义开挖空间、接触面、构造等地下特征的详细位置。

CAD > Build > Enter Point 输入点的坐标值。

CAD > Build > Offset Remaining 偏移其余各点。

CAD > Build > Undo Point 撤销上一次选点。

CAD > Build > Redo Point 重做上一次选点。

按空格键会自动激活上次使用的构建编辑功能。
