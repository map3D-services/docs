---
title: "文件 > PNT 输出文件格式"
---

PNT 格式是一种通用的 ASCII 数据文件，扩展名为 ".PNT"。

该格式适用于与其他 CAD 软件交换原始模型数据。

注释行以星号 "*" 开头，且位于第 1 列。

曲面按如下方式存储为一系列折线：

x1 y1 z1 3 value1 x2 y2 z2 2 value2 x3 y3 z3 2 value3 x4 y4 z4 2 value4

xI yI zI 表示各点的坐标。

3 表示该点是新线的起点。2 表示该点是同一条线的延续。valuei 对于几何实体，表示曲面的颜色编号

对于等值线，表示曲面各角点处被绘制等值线的参数值。
