---
title: "文件 > 模型文件格式"
---

模型可从多种文件类型加载：

Map3D-INP 格式是一种可编辑的 ASCII 数据文件，扩展名为 ".INP"。这是推荐使用的 Map3D 模型格式。该格式支持 Map3D 的全部功能。

AutoCAD-DXF 格式是一种常用的图形交换文件，扩展名为 ".DXF"。该格式适用于与其他 CAD 软件交换模型数据。

点文件格式是一种通用的 ASCII 数据文件，扩展名为 ".PNT"。该格式适用于与其他 CAD 软件交换原始模型数据。

来自不同文件的模型可以合并。合并选项

File > Open > Merge

位于打开文件对话框的底部。

相关主题：

File > Open File > Save As
