---
title: "文件 > PNT 构造线文件格式"
---

PNT 格式是一种通用的 ASCII 数据文件，扩展名为 ".PNT"。

该格式适用于与其他 CAD 软件交换原始模型数据。

注释行必须以星号 "*" 开头，且位于第 1 列。

构造线按如下方式存储为一系列折线：

**x1 y1 z1 3 colour x2 y1 z1 2 x3 y3 z3 2 x4 y4 z4 2**

xi yi zi 表示各点的坐标。3 表示该点是新线的起点。2 表示该点是同一条线的延续。colour 指定用于显示构造线的颜色编号。

共有 10 种显示颜色。

它们依次编号为 1 至 10、11 至 20、21 至 30 等，因此编号 1、11、21、31……，2、22、32……等显示相同的颜色。

每条折线可指定任意数量的点。

重复该序列（即以数字 3 开始新的一行）即可指定更多折线。

注意

应使用不同的颜色编号来表示构造线的逻辑分组（例如不同的水平、剖面，或开拓、采场回采等逻辑开采单元）。这些颜色可通过以下命令自定义

#### Tools > Custom Colours.

由于可以方便地开关特定构造线颜色编号的显示，因此这为处理复杂的构造线数据提供了一种高效的方法

#### View > Hide Cline Colours.
