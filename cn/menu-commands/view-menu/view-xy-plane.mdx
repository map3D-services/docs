---
title: "查看 XY 平面"
---

将模型视图调整到特定的视图位置：

View > View XY Plane：x 轴向右、y 轴向上的视图。

View > View YZ Plane：y 轴向右、z 轴向上的视图。View > View ZX Plane：x 轴向右、z 轴向上的视图。View > View Grid Plane：当前选定的网格平面充满屏幕

#### CAD > Grid Selection

#### Plot > Grid Selection

View > View Digitizer Plane   当前数字化区域充满屏幕

#### CAD > Digitizer Setup.

注意：

当前视图位置可以在各会话之间保存

#### File > Save View

或恢复

File > Restore View
