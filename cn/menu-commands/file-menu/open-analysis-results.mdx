---
title: "打开分析结果"
---

从重启文件加载分析结果。

系统将提示您查找重启文件的名称、位置和文件格式。

加载后，用户可以查看和处理分析结果。可以生成应力、应变和位移分量任意组合的等值线图。结果既可以显示为总值，也可以显示为各开采步骤之间的差值。

要从一个开采步骤切换到另一个开采步骤，请使用

#### File > Mining Step.

注意：

为便于在以后的会话中快速访问，每次打开文件时，其文件名都会保存在

#### File > Recent Files

工作目录则保存在

#### File > Open > Recent Directories.

如需重新加载模型文件以编辑开采块体并设置 Map3D 分析，请使用

#### Analysis > Go to CAD.

如需加载其他模型文件，请使用

#### File > Open (Model).

如需重启因停电或操作系统崩溃而中止或中断的分析，请使用

File > Restart an Analysis.
