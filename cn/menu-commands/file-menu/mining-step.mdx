title: "开采步骤编号"
---

选择另一个开采步骤进行查看。

如果所选开采步骤的 Map3D BEM 分析已经完成，将加载该开采步骤的重启文件。如果重启文件不存在（因为分析尚未完成），则只显示该开采步骤的几何形状。

使用此功能在开采步骤之间切换，比使用以下命令加载重启文件更快

#### File > Open Analysis Results

因为对于同一模型，无需重复进行单元和网格排序。

如需快速访问不同的开采步骤，请在视图工具栏中使用

#### File > Mining Step.

#### Tools > View Toolbar.

如有需要，可使用以下命令将各个开采步骤按钮放置在视图工具栏上

#### Tools > View Toolbar Configure.

按住 Alt 键并分别按 + 键或 – 键，即可快速前进或后退一个开采步骤。
