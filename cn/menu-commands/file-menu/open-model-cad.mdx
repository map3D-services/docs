---
title: "打开模型（CAD）"
---

从文件加载模型。

加载后，用户可以执行任意所需的 Map3D 分析阶段。

要添加或编辑开采块体并设置 Map3D 分析，请使用

#### Analysis > Go to CAD.

加载模型时，Map3D 会检查建模参数的基本一致性（例如，如果使用了某种材料，则必须在材料列表中指定其属性）。

系统会提示您选择模型文件的名称、位置和文件格式。模型可从以下几种文件类型加载：

- Map3D-INP 格式是一种可编辑的 ASCII 数据文件，扩展名为 ".INP"。这是推荐使用的 Map3D 模型格式。该格式支持 Map3D 的所有功能。

- AutoCAD-DXF 格式是一种常用的图形交换文件，扩展名为 ".DXF"。该格式便于与其他 CAD 软件交换模型数据。

- 点文件格式是一种通用 ASCII 数据文件，扩展名为 ".PNT"。该格式便于与其他 CAD 软件交换原始模型数据。

加载的模型几何数据和材料数据可以覆盖现有模型数据，也可以与之合并。覆盖/合并选项：

- File > Open > Merge Geometries

- File > Open > Merge Materials

位于打开文件对话框的底部。

#### 将多个文件合并为一个模型

您可以按住 Windows 标准的 "shift" 或 "ctrl" 键同时选择多个文件。

这些文件将合并为一个模型/数据库。

这样，您可以将模型数据的不同部分保存在不同文件中，然后轻松地将它们合并为一个模型/数据库。

合并多个文件的另一种方法是，在选择要添加到现有模型/数据库的其他文件之前，先选中 "Merge Geometries" 选项。

如果您已打开一个模型，并希望向其中添加更多模型数据，此方法非常有用。

#### 注意：

为便于以后的会话快速访问，每次打开文件时，其文件名都会保存在

#### File > Recent Files

中，工作目录则保存在

File > Open > Recent Directories 中。

要加载分析结果，请使用

File > Open Analysis Results。

要重新启动因中止、断电或操作系统崩溃而中断的分析，请使用

File > Restart an Analysis。
