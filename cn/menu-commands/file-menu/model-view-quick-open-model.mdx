从文件快速加载模型，但跳过所有前处理。请注意，在使用 Open Model (CAD) 加载文件或在主程序菜单中选择"Go To CAD"之前，无法使用任何 CAD 功能。

#### 将多个文件合并为一个模型

按住 Windows 标准的"Shift"或"Ctrl"键进行多选，即可同时选择多个文件。

这些文件将合并为一个模型/数据库。

这样就可以将模型数据的不同部分保存在不同文件中，然后轻松地合并为一个模型/数据库。

合并多个文件的另一种方法是：在选择要添加到现有模型/数据库的附加文件之前，先选择"Merge Geometries"选项。

当您已经打开一个模型并希望向其中添加更多模型数据时，这种方法很有用。
