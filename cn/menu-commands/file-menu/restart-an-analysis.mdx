---
title: "重启分析"
---

重启因停电或操作系统崩溃而中止或中断的分析。

此功能会扫描与所选重启文件相关的所有开采步骤，以确定分析在哪个开采步骤中断。然后验证重启分析所需的所有临时文件是否可用。最后显示这些信息，并在可能的情况下提供从中断处继续分析的选项。

要进行重启，以下临时文件必须完好：

- file.00n，其中 n 为分析中断时所在的开采步骤编号。

- file.1 和 file.2 —— 这些文件用于重启求解器。

- file.dms —— 此文件仅在使用零应变选项 (Analysis > Options > Zero Strain Support Placement) 时使用。

- file.hms —— 此文件仅由 Map3Di 使用，用于在分析过程中累积场荷载。

注意：

如需从先前模型完成时的状态开始新的分析，请参见 Analysis > Options > Initialize。
