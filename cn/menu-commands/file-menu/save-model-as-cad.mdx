---
title: "模型另存为 (CAD)"
---

以不同的文件名、位置和文件格式保存当前模型。

模型可以保存为以下几种文件类型：

- Map3D-INP 格式是一种可编辑的 ASCII 数据文件，扩展名为".INP"。这是推荐使用的 Map3D 模型格式，支持 Map3D 的全部功能。

- AutoCAD-DXF 格式是一种常用的图形交换文件，扩展名为".DXF"。此格式便于与其他 CAD 软件交换模型数据。

- 点文件格式是一种通用的 ASCII 数据文件，扩展名为".PNT"。此格式便于与其他 CAD 软件交换原始模型数据。

如需以相同的文件名、位置或文件格式保存，请使用

#### File > Save Model.
