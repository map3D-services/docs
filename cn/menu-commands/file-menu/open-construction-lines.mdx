---
title: "打开构造线"
---

从文件加载构造线。

构造线用于确定地下要素（如采掘空间、接触面、构造等）的详细位置。Map3D 模型通常建立在这些构造线数据之上。

系统会提示您选择构造线文件的名称、位置和文件格式。构造线可从以下几种文件类型加载：

- 点文件格式是一种通用 ASCII 数据文件，扩展名为 ".PNT"。该格式便于与其他 CAD 软件交换原始构造线数据。

- AutoCAD-DXF 格式是一种常用的图形交换文件，扩展名为 ".DXF"。该格式便于与其他 CAD 软件交换构造线数据。

加载的构造线数据可以覆盖现有数据，也可以与现有数据合并。覆盖/合并选项

#### File > Open > Merge Geometires

位于打开文件对话框的底部。

#### 将多个文件合并到一个数据库

您可以按住 Windows 标准的 "shift" 或 "ctrl" 键同时选择多个文件。

这些文件将合并到一个数据库中。

这样，您可以将构造线数据的不同部分保存在不同文件中，然后轻松地将它们合并到一个数据库中。

合并多个文件的另一种方法是，在选择要添加到现有数据库的其他文件之前，先选中 "Merge Geometries" 选项。

如果您已打开构造线数据，并希望在其中添加更多构造线数据，此方法非常有用。
