---
title: "图像查看器"
---

在窗口中显示 PNG（Portable Network Graphics，*.PNG）、GIF（Graphics Interchange Format）或 BMP（Windows 设备无关位图，*.BMP）文件。

启动查看器时会显示当前屏幕图像。

查看器可用于显示单张图像、GIF 动画和图像序列。

可使用以下命令将屏幕图像保存到文件

- File > Output > PNG, GIF or BMP Image

- File > Output > PNG, GIF or BMP (B&W flipped)

- File > Output > Image Recorder
