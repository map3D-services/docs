---
title: "恢复自动保存的 CAD 状态"
---

恢复最近一次自动保存的 CAD 状态。

在模型编辑过程中，每次修改几何模型时，当前 CAD 状态都会保存到一个临时文件中，该文件在各次 Map3D 会话之间保留。

其中包含与当前会话相关的所有信息，包括几何模型、控制参数、材料属性、构造线等。

这样即可在新的 Map3D 会话中或程序崩溃后，准确回到之前的工作位置。

Save named CAD State —— 手动将 CAD 状态保存到 *.sav 文件。参见"保存已命名的 CAD 状态"
