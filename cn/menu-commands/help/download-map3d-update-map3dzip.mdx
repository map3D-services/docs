下载：Map3D 更新 (Map3D.zip 8MB)

从 Map3D 网站 [www.map3d.com/update.htm](https://www.map3d.com/update.htm) 下载最新的 Map3D 更新

该更新不包括安装程序、HTML 格式的 Map3D 用户手册以及 Sentinel SuperPro 密钥驱动程序。请注意，Map3D 内的上下文相关帮助需要 HTML 版 Map3D 用户手册 (Map3D.chm) 才能正常工作。

下载：Map3D 更新 (setup.exe 18MB)

完整更新包括所有 Map3D 可执行文件、自动安装程序、HTML 格式的 Map3D 用户手册、Sentinel SuperPro 密钥驱动程序以及一些示例文件。

用户手册可以下载以下几种格式：

下载 HTML 版用户手册 (Map3D.chm 4MB)

可通过 Help > Download HTML User's Manual 下载 HTML 版用户手册。该手册采用 Windows 原生 HTML 帮助格式。

下载 PDF 版用户手册 (Map3D_Help.pdf 7MB)

可通过 Help > Download PDF User's Manual 下载 PDF 版用户手册。该手册为 PDF 格式，适合打印。

下载电子书版用户手册 (Map3D_Help.exe 5MB)

可通过 Help > Download Ebook User's Manual 下载电子书版用户手册。该手册采用独立的电子书格式。
