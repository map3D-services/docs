---
title: "下载电子书版用户手册"
---

下载 HTML 版用户手册 (Map3D.chm 4MB)

可通过 Tools > Download HTML User's Manual 下载 HTML 版用户手册。该手册采用 Windows 原生 HTML 帮助格式。

下载 PDF 版用户手册 (Map3D_Help.pdf 7MB)

可通过 Tools > Download PDF User's Manual 下载 PDF 版用户手册。该手册为 PDF 格式，适合打印。

下载电子书版用户手册 (Map3D_Help.exe 5MB)

可通过 Tools > Download Ebook User's Manual 下载电子书版用户手册。该手册采用独立的电子书格式。
