---
title: "磁盘性能测试"
---

测试硬盘系统的性能。

此测试模拟 Map3D 在 BEM 分析求解阶段的行为。

Buffer Size：磁盘读写所用缓冲区的大小。Map3D 的文件读写使用 256K 缓冲区。

Write Through：指示系统绕过所有中间缓存，直接写入磁盘。Map3D 的文件写入使用 "Write Through"。

No Buffering：指示系统在不使用中间缓冲或缓存的情况下写入文件。Map3D 的文件写入使用 "No Buffering"。

Asynchronous I/O：指示系统允许同时执行多个读和/或写操作。此选项仅在 Windows NT/2000 下受支持。可通过以下方式让 Map3D 使用此功能：

#### Analysis > Options > Async I/O

Size MB：测试所用的文件大小。建议使用较大的文件进行测试（远大于内存容量）。Drive：测试所用的磁盘驱动器。

重要的结果包括：

Write rate：每秒写入磁盘的 MB 数。预期应超过 5-10 MB/秒。

Read rate：每秒从磁盘读取的 MB 数。预期应超过 5-10 MB/秒。

Multiply/sec：每秒完成的浮点乘法次数。预期应超过 50 MFLOPS。
