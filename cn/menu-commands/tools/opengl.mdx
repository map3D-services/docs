## 5.6.4.1 OpenGL &lt;On/Off>

启用 OpenGL 支持。

OpenGL 是业界标准的高质量 3D 图形渲染接口。使用 OpenGL 的主要优点是图形显示的硬件加速以及对 z 缓冲的支持。当然，要获得硬件加速，您必须拥有支持 OpenGL 的显卡，并安装 OpenGL 显示驱动程序。

参见 Tools > OpenGL Parameters 查看 OpenGL 设置。

参见 Tools > OpenGL Anti-aliasing 使线条平滑。

## 5.6.4.2 OpenGL 参数

报告 OpenGL 设置：

Support OpenGL – 指示是否已安装并启用 OpenGL 驱动程序。

Driver or Hardware Support - 指示您的显卡是否支持 OpenGL。

Double Buffered – 指示是否有足够的内存支持双缓冲。

Color Buffer Bits – 指示颜色缓冲区使用的位数。

Depth Buffer Bits – 指示 z 缓冲区使用的位数。

## 5.6.4.3 OpenGL 抗锯齿

启用点、线和多边形边缘的平滑。

此 OpenGL 功能可改善外观，但会降低渲染速度。

View > Render > Line Width 可用于启用更宽线条的绘制。这同样有助于使线条绘制更平滑，对性能的影响与之相当。

## 5.6.4.4 OpenGL 重绘

在窗口需要刷新时，启用 OpenGL 重绘屏幕。

每当移动或关闭对话框时，都必须刷新 Map3D 显示窗口。刷新方式可以是将显示窗口保存到后台缓冲区（不勾选此选项），也可以是直接重绘屏幕（勾选此选项）。

通常应勾选此选项，但对于有问题的显卡可以禁用。

## 5.6.4.5 OpenGL 拾取

启用 OpenGL 来定位屏幕上的图形实体。

当您左键单击某个实体时，Map3D 必须确定您选中了哪个实体。这可以由 OpenGL 确定，也可以由 Map3D 内部确定。

通常应勾选此选项，但对于有问题的显卡可以禁用。

## 5.6.4.6 OpenGL 十字光标

在使用 OpenGL 和 Windows API 绘制光标十字线之间切换。

通常应勾选此选项，但对于有问题的显卡可以禁用。

要完全禁用光标十字线的绘制，请选择 Tools > Crosshairs。

## 5.6.4.7 OpenGL 交互式编辑

在编辑操作期间，启用 OpenGL 对修改后的形状进行交互式绘制。

通常应勾选此选项，但对于有问题的显卡可以禁用。
