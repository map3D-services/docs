title: "边界元公式"
---

数值模拟试图用数学方法模拟岩体对开采的响应。这需要考虑以下因素的影响：

- 荷载条件：开采之前，岩体承受上覆岩层和构造力的作用。

- 结构支护单元：还可能存在由机械支护、充填体、加热等产生的荷载。

- 几何形状：开挖时，这些原有荷载会在开挖体周围重新分布，并集中在拱座和矿柱中。刚性岩墙和软弱矿带也会影响岩体响应。

- 弹性：在应力未超过强度的位置，岩石以大致弹性的方式变形。这仅仅意味着变形量相对较小，而且大部分是可恢复的。

- 非线性：在应力集中到超过强度的位置，岩石会在这些荷载作用下屈服并变形。这意味着变形量可能相对较大，而且大部分不可恢复。这可能包括断层滑移、开裂以及广义三维非线性屈服的影响。

#### 数值模拟如何工作？

数值模拟通过对岩体可能的响应方式施加某些物理约束来实现这种模拟：

**平衡**：在模型的所有位置，作用力必须始终相互平衡。如果从材料中切出一个小立方体并考察作用在其上的应力，这些应力必须处于平衡状态。

- ¶sxx /¶ _x_ + ¶txy /¶ _y_ + ¶txz /¶ _z_ + _X_ = 0

- ¶txy /¶ _x_ + ¶syy/¶ _y_ + ¶tyz /¶ _z_ + _Y_ = 0

- ¶txz /¶ _x_ + ¶tyz /¶ _y_ + ¶szz /¶ _z_ + _Z_ = 0

请注意，_X_、_Y_ 和 _Z_ 项表示体力，可用于施加任何类型的外部场荷载。这种场荷载可能由加热、流体压力、材料非线性等引起。此外，这些项还可以通过多种原位监测手段确定，例如流体压力（如井水位下降、大坝、水力压裂）、加热（如自然加热、核废料储存）、变形（如用伸长计监测）以及地震活动（如根据地震数据确定断层滑移或材料非线性）。Map3Di 正是利用这些项将数值模拟与地震监测相结合。

**连续性**：在岩体连续介质中，材料的质量必须守恒，材料不能消失，也不能凭空产生。

- ¶²exx /¶ _y_ ² + ¶²eyy/¶ _x_ ² = 2 ¶²exy/¶ _x_ /¶ _y_

- ¶²eyy /¶ _z_ ² + ¶²ezz/¶ _y_ ² = 2 ¶²eyz/¶ _y_ /¶ _z_

- ¶²ezz /¶ _x_ ²  + ¶²exx/¶ _z_ ² = 2 ¶²ezx/¶ _z_ /¶ _x_

- ¶²exx /¶ _y_ /¶ _z_ = ¶/¶ _x ( -_ ¶eyz /¶ _x +_ ¶ezx /¶ _y +_ ¶exy /¶ _z )_

- ¶²eyy/¶ _z_ /¶ _x_ = ¶/¶ _y ( -_ ¶ezx /¶ _y +_ ¶exy/¶ _z +_ ¶eyz /¶ _x )_

- ¶²ezz /¶ _x_ /¶ _y_ = ¶/¶ _z ( -_ ¶exy/¶ _z +_ ¶eyz /¶ _x +_ ¶ezx /¶ _y )_

**弹性**：在应力未超过强度的位置，岩石以线弹性方式变形：应力与弹性应变成正比变化。

sxx  = s°xx + [ (1-u) exx + u ( eyy + ezz  ) ] _E_ /[(1+u)(1-2u)] syy = s°yy + [ (1-u) eyy + u ( ezz + exx  ) ] _E_ /[(1+u)(1-2u)] szz  = s°zz  + [ (1-u) ezz  + u ( exx + eyy ) ] _E_ /[(1+u)(1-2u)] txy  = t°xy + exy _E_ /(1+u) tyz  = t°yz + eyz _E_ /(1+u) tzx  = t°zx  + ezx _E_ /(1+u)

请注意，开采前应力或远场应力 (s°) 正是在这里被纳入物理模型的。

**非线性**：在应力集中到超过强度的位置，岩石会在这些荷载作用下屈服并变形。变形会持续发展，直到应力松弛至强度水平。这一过程可能伴随一定的剪胀。这可能包括断层滑移、开裂以及广义三维非线性屈服的影响。

请注意，平衡方程和连续性方程均以微分方程的形式表示。要求解这些方程，需要在岩体体积上对其进行积分，使相应的边界条件得到满足。实现这一点的方法有很多。边界元法对方程进行解析积分，然后采用数值近似来满足边界条件。有限元法和有限差分法则采用数值积分方案对微分方程进行积分。

无论采用哪种方法，最终都要使用某种数值近似，并得到一个描述岩体各部分之间相互作用的大型方程组。在 BEM 中，所得方程的形式为

ssurface = sfar_field + _M P_

其中 _M_ 为联立方程组，_P_ 表示为使开挖面上的应力为零而需要施加的荷载或变形。这构成了对岩体响应方式的数学描述。所有数值模型都使用这一方法的某种变体。

这些方程需要联立求解，使边界条件得到满足。通过在整个岩体范围内结合荷载条件和几何形状求解这些方程，即可完成"应力分析"。

Map3D 基于一种非常高效的间接边界元法 (Banerjee and Butterfield, 1981)，并同时使用虚拟力单元和位移不连续单元。热分析和非线性分析版本中集成了专有的特殊边界单元。

与其他应力分析技术相比，这种边界元公式具有许多优势。与 Map3D 使用的间接法相比，直接边界元公式在组装和求解边界元矩阵时所需的计算量约为其两倍。

程序采用矩阵集总技术来减小矩阵规模，因此可以在个人计算机上处理非常大的问题（超过 333333 个单元，即 1000000 个自由度）。如果不进行集总，一个 64000 个单元的问题将占用 147 GB 磁盘空间；采用集总后，可减少到 1 GB 以下。这使用户能够详细地定义现有开采几何形状，并根据需要添加新的开采。这大大减少了建立和运行分析所需的工作量，并能在必要时考虑整个矿山。

采用边界元公式时，首先从一个无限、均质的弹性介质（岩体）出发。建模过程包括进行开挖，以及叠加非均质区域（岩墙、矿带或屈服区）和可能发生滑移的断层或节理。由于从无限介质出发，远场边界会被自动考虑。

这与有限元法或有限差分法等区域公式不同，后者从空白空间出发。对于这些方法，建模需要组装整个岩体及其所有组成部分，单元必须一直组装到距离开挖体许多倍直径之外的远场边界。

虽然有限元和有限差分公式在塑性、瞬态热流和流体流动以及动力模拟等非线性问题方面已经非常成熟，但它们也非常难以使用，并且需要很长的运行时间。使用上的困难来自于离散围岩所需的大量信息。尽管可以借助网格生成器和强大的前端图形界面来减少这些工作，但学习这些界面的成本和精力，远远超过了使用 Map3D 进行边界元分析的简便性。

这些根本差异使得边界元法在岩体问题上更为适用，也更为经济（就分析时间而言）。

Map3D 克服了边界元法的许多所谓局限。程序可以处理多步开采顺序，以及具有不同材料属性和应力状态的多个材料区，并允许这些区域表现出非线性行为。多个相交的断层面可以根据用户指定的抗剪强度发生滑移和张开。程序还可以模拟稳态热/流体应力分析。

内置的实体建模技术会在内部构建复杂的交线，使模型构建变得非常简单。Map3D 内置的离散化程序会自动将单元仅集中在需要结果的位置，使用户无需费力优化单元的使用。内部集总程序将矩阵规模和计算量降低到与问题规模近乎线性相关的程度。
