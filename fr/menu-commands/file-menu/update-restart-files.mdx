---
title: "Mettre à jour les fichiers de reprise"
---

Enregistre dans les fichiers de résultats les propriétés de résistance des matériaux modifiées.

Une fois les analyses élastiques terminées, vous pouvez modifier librement les propriétés de résistance, car les contraintes calculées n'en dépendent pas. Cette option permet d'enregistrer ces réglages modifiés dans le fichier de résultats.
