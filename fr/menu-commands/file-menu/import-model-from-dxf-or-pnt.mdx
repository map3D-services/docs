---
title: "Importer un modèle depuis un fichier DXF ou PNT"
---

Charge un modèle depuis un fichier DXF (AutoCAD-DXF) ou PNT (format de fichier de points).

Une fois le modèle chargé, vous pouvez exécuter n'importe quelle étape d'analyse Map3D.

Pour ajouter ou modifier des blocs d'exploitation et configurer l'analyse Map3D, utilisez

#### Analysis > Go to CAD.

Pendant le chargement du modèle, Map3D vérifie la cohérence de base des paramètres de modélisation (p. ex. si un matériau est utilisé, ses propriétés doivent figurer dans la liste des matériaux).

Vous serez invité à rechercher le nom, l'emplacement et le format du fichier de modèle. Les modèles peuvent être chargés depuis plusieurs types de fichiers :

- Le format AutoCAD-DXF est un format d'échange de dessins très répandu, portant l'extension « .DXF ». Ce format est utile pour échanger des données de modèle avec d'autres logiciels de CAO.

- Le format de fichier de points est un fichier de données ASCII universel portant l'extension « .PNT ». Ce format est utile pour échanger des données brutes de modèle avec d'autres logiciels de CAO.

Notez que les informations géométriques sont importées sous forme d'éléments de type Fictitious Force - FF (utilisés pour les éléments tridimensionnels tels que les excavations, les zones de matériaux alternés, les chantiers remblayés, etc.). Si vous souhaitez les utiliser comme éléments de type Displacement Discontinuity - DD (utilisés pour les excavations tabulaires, les fractures et les plans de faille), vous devrez les modifier avec CAD > Edit > Entity Properties et changer le type d'élément.

#### Fusionner plusieurs fichiers en un seul modèle

Vous pouvez sélectionner plusieurs fichiers à la fois en maintenant les touches Windows standard « shift » ou « ctrl » enfoncées pour une sélection multiple.

Ces fichiers seront fusionnés en un seul modèle/une seule base de données.

Cela vous permet de conserver des parties distinctes des données du modèle dans des fichiers différents, puis de les fusionner facilement en un seul modèle/une seule base de données.

Une autre façon de fusionner plusieurs fichiers consiste à sélectionner l'option « Merge Geometries » avant de sélectionner le fichier supplémentaire à ajouter au modèle/à la base de données existant(e). C'est utile si un modèle est déjà ouvert et que vous souhaitez y ajouter d'autres données de modèle.

#### Remarques :

Pour un accès rapide lors d'une session ultérieure, chaque fois que vous ouvrez un fichier, son nom est enregistré sous

#### File > Recent Files

et le répertoire de travail est enregistré sous

File > Open > Recent Directories.

Pour charger des résultats d'analyse, utilisez

File > Open Analysis Results.

Pour redémarrer une analyse interrompue ou arrêtée par une panne de courant ou un plantage du système d'exploitation, utilisez

File > Restart an Analysis.
