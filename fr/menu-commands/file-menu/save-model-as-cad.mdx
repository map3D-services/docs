---
title: "Enregistrer le modèle sous (CAO)"
---

Enregistre le modèle actuel sous un autre nom, à un autre emplacement et dans un autre format.

Les modèles peuvent être enregistrés dans plusieurs types de fichiers :

- Le format Map3D-INP est un fichier de données ASCII modifiable d'extension « .INP ». C'est le format de modèle Map3D recommandé. Toutes les fonctions de Map3D sont prises en charge avec ce format.

- Le format AutoCAD-DXF est un format d'échange de dessins courant, d'extension « .DXF ». Ce format est utile pour échanger des données de modèle avec d'autres logiciels de CAO.

- Le format de fichier de points est un fichier de données ASCII universel d'extension « .PNT ». Ce format est utile pour échanger des données brutes de modèle avec d'autres logiciels de CAO.

Pour enregistrer sous le même nom, au même emplacement et dans le même format, utilisez

#### File > Save Model.
