---
title: "Restaurer l'état CAO enregistré automatiquement"
---

Restaure le dernier état CAO enregistré automatiquement.

Pendant la modification du modèle, chaque fois que vous modifiez la géométrie, l'état CAO actuel est enregistré dans un fichier temporaire conservé d'une session Map3D à l'autre.

Cela comprend toutes les informations associées à votre session en cours : géométrie, paramètres de contrôle, propriétés des matériaux, lignes de construction, etc.

Vous pouvez ainsi reprendre exactement là où vous vous étiez arrêté dans une nouvelle session Map3D, ou après un plantage du programme.
