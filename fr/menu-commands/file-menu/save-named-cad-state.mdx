---
title: "Enregistrer un état CAO nommé"
---

Enregistre l'état CAO actuel dans un fichier *.sav.

Cela comprend toutes les informations associées à votre session en cours : géométrie, paramètres de contrôle, propriétés des matériaux, lignes de construction, etc.

Vous pouvez ainsi reprendre exactement là où vous vous étiez arrêté lors d'une session Map3D enregistrée, ou après un plantage du programme.

Restore Auto-Save CAD State : restaure le dernier état CAO enregistré automatiquement. Voir Restaurer l'état CAO enregistré automatiquement

Restore named CAD State : restaure un état CAO nommé à partir d'un fichier *.sav. Voir Restaurer un état CAO nommé
