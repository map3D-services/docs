---
title: "Ouverture rapide des lignes de construction (affichage seul)"
---

Charge rapidement des données de lignes de construction depuis un fichier, mais saute tout le prétraitement. Notez que vous ne pouvez utiliser aucune des fonctions CAD tant que vous n'avez pas chargé le fichier avec Open Construction Lines,

Les lignes de construction servent à définir l'emplacement détaillé des éléments souterrains tels que les excavations, les contacts, les structures, etc. Un modèle Map3D est normalement construit sur ces données de lignes de construction.

Vous serez invité à rechercher le nom, l'emplacement et le format du fichier de lignes de construction. Les lignes de construction peuvent être chargées depuis plusieurs types de fichiers :

- Le format de fichier de points est un fichier de données ASCII universel portant l'extension « .PNT ». Ce format est utile pour échanger des données brutes de lignes de construction avec d'autres logiciels de CAO.

- Le format AutoCAD-DXF est un format d'échange de dessins très répandu, portant l'extension « .DXF ». Ce format est utile pour échanger des données de lignes de construction avec d'autres logiciels de CAO.

Les données de lignes de construction chargées peuvent soit remplacer les données existantes, soit être fusionnées avec elles. L'option remplacer/fusionner

#### File > Open > Merge Geometires

apparaît en bas de la boîte de dialogue d'ouverture de fichier.

#### Fusionner plusieurs fichiers en une seule base de données

Vous pouvez sélectionner plusieurs fichiers à la fois en maintenant les touches Windows standard « shift » ou « ctrl » enfoncées pour une sélection multiple.

Ces fichiers seront fusionnés en une seule base de données.

Cela vous permet de conserver des parties distinctes des données de lignes de construction dans des fichiers différents, puis de les fusionner facilement en une seule base de données.

Une autre façon de fusionner plusieurs fichiers consiste à sélectionner l'option « Merge Geometries » avant de sélectionner le fichier supplémentaire à ajouter à la base de données existante.

C'est utile si vous avez déjà des données de lignes de construction ouvertes et souhaitez y ajouter d'autres
