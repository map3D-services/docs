---
title: "Ouverture rapide (lecture seule)"
---

Charge rapidement un modèle à partir d'un fichier, sans aucun prétraitement. Notez que vous ne pouvez utiliser aucune fonction de CAO tant que vous n'avez pas chargé le fichier avec Open Model (CAD) ou sélectionné « Go To CAD » dans le menu principal du programme.

#### Fusionner plusieurs fichiers en un modèle

Vous pouvez sélectionner plusieurs fichiers à la fois en maintenant enfoncées les touches Windows standard « Maj » ou « Ctrl ».

Ces fichiers sont fusionnés en un seul modèle ou une seule base de données.

Vous pouvez ainsi conserver différentes parties des données du modèle dans des fichiers distincts, puis les fusionner facilement en un seul modèle ou une seule base de données.

Une autre façon de fusionner plusieurs fichiers consiste à sélectionner l'option « Merge Geometries » avant de sélectionner le fichier à ajouter au modèle ou à la base de données existants.

C'est utile si un modèle est déjà ouvert et que vous voulez y ajouter des données.
