---
title: "Visionneuse d'images"
---

Affiche dans une fenêtre des fichiers PNG (Portable Network Graphics, *.PNG), GIF (Graphics Interchange Format) ou BMP (bitmap Windows indépendant du périphérique, *.BMP).

Au démarrage de la visionneuse, l'image actuelle de l'écran s'affiche.

La visionneuse permet d'afficher des images isolées, des GIF animés et des séquences d'images.

Les images d'écran peuvent être enregistrées dans des fichiers avec

- File > Output > PNG, GIF or BMP Image

- File > Output > PNG, GIF or BMP (B&W flipped)

- File > Output > Image Recorder
