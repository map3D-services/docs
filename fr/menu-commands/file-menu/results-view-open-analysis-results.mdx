---
title: "VUE DES RÉSULTATS (ouvrir les résultats d'analyse)..."
---

Charge les résultats d'analyse à partir d'un fichier de reprise.

Vous êtes invité à rechercher le nom, l'emplacement et le format du fichier de reprise.

Une fois les résultats chargés, vous pouvez les visualiser et les traiter. Il est possible de générer des tracés de contours de toute combinaison de composantes de contrainte, de déformation et de déplacement. Les résultats peuvent être affichés en valeurs totales ou en écarts entre étapes d'exploitation.

Pour passer d'une étape d'exploitation à une autre, utilisez

#### File > Mining Step.

#### Remarques :

Pour un accès rapide lors d'une session ultérieure, le nom de chaque fichier ouvert est enregistré sous

#### File > Recent Files

et le répertoire de travail sous

#### File > Open > Recent Directories.

Pour recharger le fichier du modèle afin de modifier les blocs d'exploitation et de configurer l'analyse Map3D, utilisez

#### Analysis > Go to CAD.

Pour charger un autre fichier de modèle, utilisez

#### File > Open (Model).
