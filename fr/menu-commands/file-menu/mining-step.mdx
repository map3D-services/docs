---
title: "Étape d'exploitation n°"
---

Sélectionne une autre étape d'exploitation à afficher.

Si l'analyse BEM Map3D de l'étape sélectionnée est terminée, le fichier de reprise de cette étape est chargé. S'il n'existe pas (parce que l'analyse n'est pas terminée), seule la géométrie de cette étape est affichée.

Passer d'une étape à l'autre avec cette fonction est plus rapide que de charger un fichier de reprise avec

#### File > Open Analysis Results

car le tri des éléments et des grilles n'a pas à être répété pour le même modèle.

Pour accéder rapidement aux différentes étapes d'exploitation, utilisez

#### File > Mining Step.

depuis la barre d'outils d'affichage

#### Tools > View Toolbar.

Si vous le souhaitez, des boutons d'étape individuels peuvent être placés dans la barre d'outils d'affichage avec

#### Tools > View Toolbar Configure.

Vous pouvez avancer ou reculer rapidement d'une étape en maintenant la touche Alt enfoncée et en appuyant respectivement sur la touche + ou –.
