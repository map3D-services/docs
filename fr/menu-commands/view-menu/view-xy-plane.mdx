---
title: "Afficher le plan XY"
---

Réoriente la vue du modèle vers une position de vue particulière :

View > View XY Plane : vue avec l'axe x vers la droite et l'axe y vers le haut.

View > View YZ Plane : vue avec l'axe y vers la droite et l'axe z vers le haut. View > View ZX Plane : vue avec l'axe x vers la droite et l'axe z vers le haut. View > View Grid Plane : le plan de grille sélectionné occupe tout l'écran

#### CAD > Grid Selection

#### Plot > Grid Selection

View > View Digitizer Plane   la zone de numérisation actuelle occupe tout l'écran

#### CAD > Digitizer Setup.

Remarques :

La position de vue actuelle peut être enregistrée

#### File > Save View

ou restaurée

File > Restore View

d'une session à l'autre.
