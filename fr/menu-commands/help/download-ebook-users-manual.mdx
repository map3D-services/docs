---
title: "Télécharger le manuel d'utilisation en livre numérique"
---

Télécharger le manuel d'utilisation HTML (Map3D.chm, 4 Mo)

Le manuel d'utilisation HTML peut être téléchargé depuis Tools > Download HTML User's Manual. Ce manuel est au format d'aide HTML natif de Windows.

Télécharger le manuel d'utilisation PDF (Map3D_Help.pdf, 7 Mo)

Le manuel d'utilisation PDF peut être téléchargé depuis Tools > Download PDF User's Manual. Ce manuel est au format PDF et convient bien à l'impression.

Télécharger le manuel d'utilisation en livre numérique (Map3D_Help.exe, 5 Mo)

Le manuel d'utilisation en livre numérique peut être téléchargé depuis Tools > Download Ebook User's Manual. Ce manuel est au format livre numérique autonome.
