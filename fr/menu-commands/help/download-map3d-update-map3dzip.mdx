Téléchargement : mise à jour de Map3D (Map3D.zip, 8 Mo)

Télécharge la dernière mise à jour de Map3D depuis le site web de Map3D [www.map3d.com/update.htm](https://www.map3d.com/update.htm)

Elle n'inclut ni les routines d'installation, ni le manuel d'utilisation de Map3D au format HTML, ni les pilotes de la clé Sentinel SuperPro. Notez que le manuel d'utilisation HTML de Map3D (Map3D.chm) est nécessaire au fonctionnement de l'aide contextuelle dans Map3D.

Téléchargement : mise à jour de Map3D (setup.exe, 18 Mo)

La mise à jour complète comprend tous les exécutables de Map3D, les routines d'installation automatisées, le manuel d'utilisation de Map3D au format HTML et les pilotes de la clé Sentinel SuperPro, ainsi que quelques fichiers d'exemple.

Le manuel d'utilisation peut être téléchargé dans plusieurs formats :

Télécharger le manuel d'utilisation HTML (Map3D.chm, 4 Mo)

Le manuel d'utilisation HTML peut être téléchargé depuis Help > Download HTML User's Manual. Ce manuel est au format d'aide HTML natif de Windows.

Télécharger le manuel d'utilisation PDF (Map3D_Help.pdf, 7 Mo)

Le manuel d'utilisation PDF peut être téléchargé depuis Help > Download PDF User's Manual. Ce manuel est au format PDF et convient bien à l'impression.

Télécharger le manuel d'utilisation en livre numérique (Map3D_Help.exe, 5 Mo)

Le manuel d'utilisation en livre numérique peut être téléchargé depuis Help > Download Ebook User's Manual. Ce manuel est au format livre numérique autonome.
