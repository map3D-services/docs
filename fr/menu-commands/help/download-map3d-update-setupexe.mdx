Téléchargement : mise à jour de Map3D (setup.exe 18MB)

Télécharge la dernière mise à jour de Map3D depuis le site web de Map3D [www.map3d.com/update.htm](https://www.map3d.com/update.htm)

La mise à jour complète comprend tous les exécutables de Map3D, les routines d'installation automatisée, le Manuel de l'utilisateur de Map3D au format HTML et les pilotes de la clé Sentinel SuperPro, ainsi que quelques fichiers d'exemple.

Comme la mise à jour complète (setup.exe) est assez volumineuse (8MB), une autre solution consiste à télécharger uniquement les exécutables mis à jour (Map3D.zip).

Téléchargement : mise à jour de Map3D (Map3D.zip 8MB)

Ceci

n'inclut ni les routines d'installation, ni le Manuel de l'utilisateur de Map3D au format HTML, ni les pilotes de la clé Sentinel SuperPro. Notez que le Manuel de l'utilisateur de Map3D en HTML (Map3D.chm) est nécessaire au fonctionnement de l'aide contextuelle dans Map3D.

Le manuel de l'utilisateur peut être téléchargé en plusieurs formats :

Télécharger le Manuel de l'utilisateur HTML (Map3D.chm 4MB)

Le Manuel de l'utilisateur HTML peut être téléchargé depuis Help > Help > Download HTML User's Manual. Ce manuel est au format d'aide HTML natif de Windows.

Télécharger le Manuel de l'utilisateur PDF (Map3D_Help.pdf 7MB)

Le Manuel de l'utilisateur PDF peut être téléchargé depuis Help > Download PDF User's Manual. Ce manuel est au format PDF, un bon choix pour l'impression.

Télécharger le Manuel de l'utilisateur en livre électronique (Map3D_Help.exe 5MB)

Le Manuel de l'utilisateur en livre électronique peut être téléchargé depuis Help > Download Ebook User's Manual. Ce manuel est au format livre électronique autonome.
