---
title: "Test de performance du disque"
---

Teste les performances du système de disque dur.

Ce test simule le comportement de Map3D pendant l'étape de résolution de l'analyse BEM.

Buffer Size : taille du tampon utilisé pour les lectures et écritures sur disque. Map3D utilise un tampon de 256K pour ses lectures et écritures de fichiers.

Write Through : demande au système d'écrire sans passer par un cache intermédiaire, directement sur le disque. Map3D utilise « Write Through » pour ses écritures de fichiers.

No Buffering : demande au système d'écrire dans le fichier sans tampon ni cache intermédiaire. Map3D utilise « No Buffering » pour ses écritures de fichiers.

Asynchronous I/O : demande au système d'autoriser plusieurs opérations de lecture et/ou d'écriture simultanées. Cette option n'est prise en charge que sous Windows NT/2000. Vous pouvez demander à Map3D d'utiliser cette fonction avec

#### Analysis > Options > Async I/O

Size MB : taille du fichier utilisé pour le test. Il est recommandé d'effectuer ce test avec un fichier volumineux (nettement plus grand que la quantité de RAM). Drive : lecteur de disque utilisé pour le test.

Les résultats importants sont :

Write rate : le nombre de Mo écrits sur le disque par seconde. Vous devriez obtenir plus de 5-10 Mo/seconde.

Read rate : le nombre de Mo lus sur le disque par seconde. Vous devriez obtenir plus de 5-10 Mo/seconde.

Multiply/sec : le nombre de multiplications en virgule flottante effectuées par seconde. Vous devriez obtenir plus de 50 MFLOPS.
