## 5.6.4.1 OpenGL &lt;On/Off>

Active la prise en charge d'OpenGL.

OpenGL est une interface standard de l'industrie pour le rendu graphique 3D de haute qualité. Les principaux avantages d'OpenGL sont l'accélération matérielle de l'affichage graphique et la prise en charge du z-buffer. Bien sûr, pour bénéficier de l'accélération matérielle, vous devez disposer d'une carte graphique compatible OpenGL et avoir installé le pilote d'affichage OpenGL.

Voir Tools > OpenGL Parameters pour consulter la configuration d'OpenGL.

Voir Tools > OpenGL Anti-aliasing pour lisser les lignes.

## 5.6.4.2 Paramètres OpenGL

Indique la configuration d'OpenGL :

Support OpenGL – indique si un pilote OpenGL est installé et activé.

Driver or Hardware Support - indique si OpenGL est pris en charge par votre carte graphique.

Double Buffered – indique que la mémoire est suffisante pour prendre en charge le double tampon.

Color Buffer Bits – indique le nombre de bits utilisés pour le tampon de couleur.

Depth Buffer Bits – indique le nombre de bits utilisés pour le z-buffer.

## 5.6.4.3 Anticrénelage OpenGL

Active le lissage des points, des lignes et des arêtes de polygones.

Cette fonction d'OpenGL améliore l'apparence mais ralentit le rendu.

View > Render > Line Width permet d'activer le tracé de lignes plus épaisses. Cela contribue aussi à lisser le tracé des lignes, avec un impact similaire sur les performances.

## 5.6.4.4 Rafraîchissement OpenGL

Active le redessin de l'écran par OpenGL lorsque la fenêtre doit être rafraîchie.

La fenêtre d'affichage de Map3D doit être rafraîchie chaque fois qu'une boîte de dialogue est déplacée ou fermée. Ce rafraîchissement peut se faire soit en enregistrant la fenêtre d'affichage dans un tampon arrière (cette option n'est pas cochée), soit en redessinant simplement l'écran (cette option est cochée).

Cette option doit normalement être cochée, mais elle peut être désactivée pour les cartes graphiques posant problème.

## 5.6.4.5 Sélection OpenGL

Permet à OpenGL de localiser les entités graphiques à l'écran.

Lorsque vous cliquez avec le bouton gauche sur une entité, Map3D doit déterminer quelle entité vous avez sélectionnée. Cela peut être déterminé soit par OpenGL, soit en interne par Map3D.

Cette option doit normalement être cochée, mais elle peut être désactivée pour les cartes graphiques posant problème.

## 5.6.4.6 Réticule OpenGL

Bascule entre le tracé du réticule du curseur par OpenGL et par l'API Windows.

Cette option doit normalement être cochée, mais elle peut être désactivée pour les cartes graphiques posant problème.

Pour désactiver complètement le tracé du réticule du curseur, sélectionnez Tools > Crosshairs.

## 5.6.4.7 Modification interactive OpenGL

Active le tracé interactif par OpenGL des formes modifiées pendant les opérations de modification.

Cette option doit normalement être cochée, mais elle peut être désactivée pour les cartes graphiques posant problème.
