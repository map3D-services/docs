---
title: "Tracé"
---

Trace les données sismiques. Les points peuvent être affichés sous forme de sphères ombrées par une source lumineuse, dont le diamètre et/ou la couleur varient selon la magnitude (voir Visualisation).

Ce bouton peut être placé dans la barre d'outils d'affichage ou dans celle des contours avec

Tools > Configure View Toolbar

Tools > Configure Contouring Toolbar
