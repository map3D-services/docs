---
title: "Analyse > Charger le modèle"
---

Charge un modèle depuis un fichier (format INP ou DXF). Une fois le modèle chargé, l'utilisateur peut utiliser

Analysis > Go to CAD

pour ajouter ou modifier des blocs d'exploitation et configurer l'analyse Map3D.

Pendant le chargement du modèle, Map3D vérifie la cohérence de base des paramètres de modélisation (p. ex. si un matériau est utilisé, ses propriétés doivent être spécifiées dans la liste des matériaux).

Options :

Analysis > Options > Reunmber Analysis > Options > Collinearity

Rubriques connexes :

Analysis Dialog Analysis > Suspend Analysis > ABORT
