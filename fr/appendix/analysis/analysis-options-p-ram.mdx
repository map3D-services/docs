---
title: "Analyse > Options > P-RAM"
---

Stocke une partie de la matrice des coefficients en RAM physique pendant l'analyse BEM de Map3D.

Si votre ordinateur dispose d'une grande quantité de RAM, cette option peut accélérer considérablement l'exécution, car les données peuvent être récupérées beaucoup plus rapidement depuis la RAM que depuis le disque. Bien que Windows 32 bits ne permette à chaque processus d'adresser que 2 Go, les utilisateurs disposant de beaucoup de RAM peuvent accéder à la RAM physique grâce à AWE (Address Windowing Extensions). AWE permet d'accéder à toute la RAM disponible de l'ordinateur. La plupart des systèmes prennent en charge 4 Go de RAM. Certains en prennent en charge plus de 64 Go. Selon les versions de Windows, la prise en charge d'AWE varie de 1 Go à 512 Go. La prise en charge d'AWE est disponible dans les versions suivantes de Windows :

- Windows 10 Professionnel et Server (maximum de 4 Go).

- Windows NT 4.0, Windows 2000 Professionnel et Server (maximum de 4 Go).

- Windows 2000 Advanced Server (maximum de 8 Go).

- Windows 2000 Datacenter Server (maximum de 32 Go).

- Windows XP Professionnel et Windows Server 2003 (maximum de 4 Go).

- Windows Server 2003 Enterprise Edition (maximum de 32 Go).

- Windows Server 2003 Datacenter Edition (maximum de 64 Go).

- Windows 7 et 8.

- Windows 10 et 11 Pro (la version Famille ne prend pas cette fonction en charge).

AWE exige le privilège « SE_LOCK_MEMORY ». Pour activer AWE, procédez comme suit :

Control Panel > Administrative Tools > Local Security Policies

Définissez ensuite

Local Policies > User Rights Assignment > Lock Pages in Memory > Add User or Group > Everyone

Vous devez redémarrer pour que ce paramètre prenne effet.

Notes :

Cette fonction doit être cochée avant de lancer l'analyse BEM de Map3D

#### Analysis > BEM Analysis.

Allouez uniquement la quantité de RAM que vous souhaitez que Map3D utilise, en veillant à laisser suffisamment d'espace aux autres applications que vous comptez exécuter.

Ne définissez jamais ce paramètre à une valeur supérieure à la RAM disponible, car cela provoquerait une pagination excessive du système d'exploitation et ralentirait considérablement l'analyse.
