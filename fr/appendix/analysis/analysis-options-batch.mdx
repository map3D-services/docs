---
title: "Analyse > Options > Traitement par lots"
---

Configure la file d'attente de traitement par lots des analyses.

Si l'utilisateur a plusieurs modèles à exécuter, il peut les spécifier dans cette file d'attente. En sélectionnant

Analysis > Options > Batch > Execute Batch Queue

tous les modèles cochés seront exécutés sans aucune demande de réponse interactive de l'utilisateur.

Lorsque vous cochez un fichier de lot pour exécution, vous êtes invité à rechercher le nom, l'emplacement et le format du fichier de modèle. Si la recherche aboutit, le modèle est coché.

La deuxième colonne de la boîte de dialogue Batch File Setup permet de définir des options d'analyse si vous le souhaitez. Ces paramètres remplacent toute option définie dans la boîte de dialogue Analysis > Options.

#### Mode console :

Map3D peut être lancé depuis l'invite de commandes Windows ou depuis un fichier *.bat si vous le souhaitez. Les options de ligne de commande peuvent être utilisées dans un script en fichier texte ou saisies depuis une invite de commandes. La procédure consiste simplement à créer un fichier *.bat comme suit :

**Map3D filename.inp -option1 - option2 ...** (où « filename.inp » est le nom du fichier de modèle à analyser).

Les options sont les suivantes :

- **-analysis** (demande à Map3D d'exécuter une analyse - vous devez aussi fournir « filename.inp »).

- **-console** (affiche uniquement la fenêtre « Analysis Dialog » pendant l'exécution de Map3D).

   - (n'affiche rien pendant l'exécution de Map3D et s'arrête à la fin de l'analyse).

- **-stop** (arrête Map3D à la fin de l'analyse).

Vous pouvez aussi ouvrir des fichiers de résultats comme suit :

**Map3D filename.001** (où « filename.001 » est le nom du fichier de résultats à afficher).

Par exemple, pour exécuter une analyse Map3D en n'affichant qu'une fenêtre de journalisation, vous la lanceriez ainsi :

#### Map3D filename.inp -console -analysis

Par exemple, pour exécuter une analyse Map3D sans afficher de fenêtre de journalisation, vous la lanceriez ainsi :

#### Map3D filename.inp -silent -analysis

#### Remarques :

Les noms des fichiers de modèle du lot sont enregistrés et restaurés à chaque exécution de Map3D.

Les fichiers de modèle qui ne sont pas cochés ne seront pas exécutés en mode lot.

La file d'attente peut être interrompue à tout moment simplement en abandonnant l'analyse en cours

Analysis > Abort
