---
title: "Analyse > Options > Initialisation"
---

Initialise le modèle afin que l'analyse reprenne là où une analyse précédente s'est terminée.

Cette option permet de démarrer une nouvelle analyse à partir de l'état final d'un modèle précédent. Toutes les composantes non linéaires, de déformation nulle et de chargement sismique (chargement sismique uniquement dans Map3Di) sont transmises au nouveau modèle depuis l'analyse précédente.

Pour que cette fonction opère correctement, le nouveau modèle doit contenir toutes les données (géométrie) du modèle d'initialisation, plus toute nouvelle donnée, étape d'exploitation ou grille. Il n'est pas nécessaire d'utiliser la même discrétisation ni les mêmes plans de grille.

Pour initialiser, les fichiers suivants doivent être intacts :

file.00n, où n représente le numéro de l'étape d'exploitation à laquelle la précédente analyse s'est terminée. file.dms, ce fichier n'est utilisé qu'avec l'option de déformation nulle (Analysis > Options > Zero Strain Support Placement).

file.hms, ce fichier n'est utilisé que par Map3Di et sert à accumuler le chargement du champ au fil de l'analyse.

Notes :

Cette fonction doit être cochée avant de lancer l'analyse BEM de Map3D

#### Analysis > BEM Analysis

Cette option nécessite des calculs supplémentaires et augmente donc le temps d'analyse.

Reportez-vous à Analysis > Options > Restart pour redémarrer une analyse interrompue ou abandonnée à cause d'une coupure de courant ou d'un plantage du système d'exploitation.
