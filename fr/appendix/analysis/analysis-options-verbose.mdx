Écrit tous les vecteurs solution et tous les résultats aux points de champ dans le fichier journal pendant l'analyse BEM de Map3D.

Notes :

Cette fonction doit être cochée avant de lancer l'analyse BEM de Map3D

#### Analysis > BEM Analysis

Il est recommandé de ne pas cocher cette option, sauf si vous souhaitez expressément voir ces informations dans le fichier journal.
