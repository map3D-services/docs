---
title: "Analyse > Options > Lecteur n°"
---

Spécifie les lecteurs temporaires pour la matrice des coefficients – pendant l'analyse BEM de Map3D.

Si plusieurs lecteurs de disque sont installés, cette option permet d'indiquer à Map3D où stocker la matrice des coefficients. Lorsque le premier lecteur est plein, Map3D écrit le reste de la matrice sur le lecteur temporaire suivant.

Lorsque la matrice de solution est trop grande pour tenir en mémoire vive (consultez Analysis > Options > VRAM et Analysis > Options > PRAM) , la résolution matricielle devient une opération à forte intensité d'E/S, qui dépend uniquement du débit d'E/S de votre ordinateur. Dans ce cas, une grande partie du temps d'analyse peut être consacrée à l'étape de résolution en raison de la lenteur des disques.

Pour résoudre ce problème, il est impératif que l'utilisateur installe plusieurs disques rapides.

Map3D prend entièrement en charge le traitement parallèle et les E/S disque parallèles avec l'option multiprocesseur/multilecteur.

Si vous avez une licence pour l'option multiprocesseur/multilecteur, Map3D configure ces lecteurs en grappe RAID de sorte que les E/S s'effectuent de façon superposée sur tous les lecteurs, en parallèle avec les calculs.

Avec cette configuration, vous pouvez augmenter les performances d'E/S proportionnellement au nombre de lecteurs de la grappe.

Dans le test de performance suivant, le même modèle est exécuté avec 1, 2 et 4 disques.

||1 disque|2 disques|4 disques|8GB PRAM|
|---|---|---|---|---|
|Débit disque mesuré (Mo/s)|55|112|206|3000 équivalent|
|Résolution matricielle (heures)|0.546|0.282|0.163|0.033|
|Gain de vitesse de résolution|1x|1.9x|3.3x|16x|
|Temps d'analyse total (4 cœurs)|0.640|0.376|0.257|0.107|
|Gain de vitesse total|1x|1.7x|2.5x|6x|

Les disques utilisés dans ce test sont d'anciens disques de 50 à 60 Mo/s (Seagate Barracuda 7200.7). Les disques mécaniques plus récents atteignent 100 Mo/s (Seagate Momentus 7200.4). Les SSD SATA2 peuvent offrir plus de 250 Mo/s par lecteur. Les SSD SATA3 peuvent offrir plus de 500 Mo/s par lecteur. On peut s'attendre à ce que plusieurs SSD ou lecteurs NVMe soient presque aussi rapides que la PRAM. Notez que certaines cartes mères limitent le débit total combiné et peuvent nécessiter des cartes contrôleur supplémentaires.

Pour savoir si vous avez une licence pour l'option multiprocesseur/multilecteur, consultez Analysis > Options > #Threads.

Si vous avez une licence pour l'option multiprocesseur/multilecteur, vous pouvez obtenir des débits de disque plus élevés en définissant le privilège SE_MANAGE_VOLUME_NAME.

Cette capacité est disponible dans les versions suivantes de Windows :

- Windows NT 4.0, Windows 2000 Professional et Server (maximum de 4 Go).

- Windows 2000 Advanced Server (maximum de 8 Go).

- Windows 2000 Datacenter Server (maximum de 32 Go).

- Windows XP Professional et Windows Server 2003 (maximum de 4 Go).

- Windows Server 2003 Enterprise Edition (maximum de 32 Go).

- Windows Server 2003 Datacenter Edition (maximum de 64 Go).

- Windows 10 et 11 Pro (la version Famille ne la prend pas en charge).

Pour définir le privilège « SE_MANAGE_VOLUME_NAME », procédez comme suit :

Control Panel > Administrative Tools > Local Security Policies

Définissez ensuite

Local Policies > User Rights Assignment > Perform Volume Maintenance Tasks > Add User or Group > Everyone

Vous devez redémarrer pour que ce paramètre prenne effet.

Remarques :

Cette fonction doit être cochée avant d'effectuer l'analyse BEM de Map3D

#### Analysis > BEM Analysis

Vous devez spécifier le lecteur le plus rapide de votre système. Vous pouvez tester les performances de votre lecteur avec

Tools > Disk Performance Test
