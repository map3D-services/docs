Discrétise le modèle.

Toutes les surfaces d'excavation sont discrétisées automatiquement en concentrant les éléments aux endroits où des résultats sont demandés

View > Render > Discretize

Les résultats de l'analyse sont calculés sur les surfaces DD et sur une série de plans de grille définis par l'utilisateur

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane

ou en des points définis par l'utilisateur

#### Analysis > Options > MSCALC

Les plans de grille sont discrétisés automatiquement en une série de points de champ où les déplacements, les déformations et les contraintes sont calculés.

L'analyse de discrétisation peut être répétée autant de fois que souhaité avec différents paramètres de contrôle.

L'utilisateur contrôle entièrement la façon dont le modèle est discrétisé en spécifiant divers paramètres de contrôle (longueur d'élément _AL_ , espacement de grille _AG_ , discrétisation d'élément _DON_ , discrétisation de grille _DOL_ )

#### Analysis > CParams

et en spécifiant la largeur maximale d'élément pour les blocs FF 3D et les plans DD

CAD > Edit > Entities > Maximum Element Width

ainsi que pour les grilles de points de champ

CAD > Edit > Entities > Maximum Element Width

Consultez Discretization and Lumping pour une discussion approfondie sur la définition de ces paramètres de contrôle.

Options :

Analysis > Options > MSCALC Analysis > Options > LERD/LSS Analysis > Options > Lumping
