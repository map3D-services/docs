---
title: "Matériaux > Exporter vers un fichier"
---

Permet d'exporter toutes les données de propriétés des matériaux vers un fichier à consulter dans le Bloc-notes ou dans Excel.

Vous êtes invité à choisir un nom de fichier pour l'exportation. Les options comprennent :

- Open in Excel

- Open in Notepad

- Use commas as decimal points

Les formats de fichier disponibles comprennent :

- csv - valeurs séparées par des virgules (utile pour l'importation directe dans Excel)

- tsv - valeurs séparées par des tabulations (utile pour l'importation directe dans Excel)

- txt - valeurs séparées par des espaces (utile pour l'importation directe dans le Bloc-notes)
