---
title: "CAO > Modifier > Créer une liste d'entités à modifier"
---

Vous pouvez lancer cette routine en choisissant une fonction de modification (par exemple un bouton) ou simplement en cliquant avec le bouton droit sur une entité.

Lorsque vous lancez une routine de modification d'entités, vous êtes d'abord invité à créer la liste des entités à modifier

![Figure from page 132](/images/page-132-img-1.png)

- Si Tools > Shift-key Selection est coché, vous devez maintenir la touche Shift enfoncée pour effectuer des sélections multiples.

- Par défaut, les entités sélectionnées sont ajoutées à la liste. Toutefois, si vous maintenez la touche Ctrl enfoncée, les entités sélectionnées sont retirées de la liste.

- Tout en maintenant la touche Shift ou Ctrl enfoncée, vous pouvez tracer une fenêtre de sélection par intersection.

- Appuyer sur la barre d'espace active automatiquement la dernière fonction de modification utilisée.

- Maintenir la touche Alt enfoncée lorsque vous cliquez avec le bouton droit répète automatiquement la dernière fonction de modification utilisée.

Cette barre d'outils commande les différentes fonctions utilisées pour créer la liste.

Interrompt la modification. Sélectionne des entités en choisissant une surface à la fois. Sélectionne des entités en choisissant des groupes entiers constituant un bloc. Inclut toutes les entités portant le numéro sélectionné.

Inclut toutes les entités de la couleur sélectionnée.

Inclut toutes les entités portant le numéro de matériau sélectionné.

- Un même bloc peut contenir des matériaux différents selon l'étape d'exploitation actuellement active.

- Lorsque vous utilisez cette fonction, veillez à sélectionner l'étape d'exploitation appropriée File > Mining Step

Inclut toutes les entités excavées à l'étape d'exploitation sélectionnée.

Inclut toutes les entités situées dans la fenêtre sélectionnée.

- Les entités ne sont sélectionnées que si l'entité entière est contenue dans la fenêtre.

- Si le mode (sélection de surface) est actif, seules les surfaces sont incluses.

- Si le mode (sélection d'entité) est actif, toutes les surfaces constituant le bloc sont incluses.

Inclut toutes les entités situées dans la fenêtre d'intersection.

- Les entités sont sélectionnées même si une partie seulement de l'entité se trouve dans la fenêtre.

- Vous pouvez aussi activer cette fonction en maintenant la touche Shift ou Ctrl enfoncée et en traçant une fenêtre d'intersection.

- Si le mode (sélection de surface) est actif, seules les surfaces sont incluses.

- Si le mode (sélection d'entité) est actif, toutes les surfaces constituant le bloc sont incluses.

- Les entités sélectionnées sont ajoutées à la liste.

Les entités sélectionnées sont retirées de la liste. Annule la dernière sélection.

Rétablit la dernière sélection.

Une fois les entités souhaitées sélectionnées, vous pouvez choisir l'un des boutons de modification :

CAD > Edit > Entity Properties Modifie le type de bloc, la couleur, la séquence d'exploitation, etc.

CAD > Edit > Erase Entities Efface les entités sélectionnées. CAD > Edit > Move Entities Déplace les entités sélectionnées. CAD > Edit > Copy Entities Copie les entités sélectionnées. CAD > Edit > Scale Entities Met à l'échelle les entités sélectionnées. CAD > Edit > Rotate Azimuth Fait pivoter l'azimut des entités sélectionnées. CAD > Edit > Rotate Dip Fait pivoter le pendage des entités sélectionnées. CAD > Edit > Dump to File Exporte les entités sélectionnées dans un fichier. CAD > Edit > Group Regroupe les entités sélectionnées en un seul bloc.

- double-cliquez sur un sommet pour exécuter la fonction en surbrillance,

- cliquez avec le bouton droit pour afficher une liste d'options.

Une fois toute opération de modification terminée, vous avez une seule possibilité d'annuler les modifications en sélectionnant

#### Undo

Vous pouvez aussi restaurer le même ensemble de sélection et modifier à nouveau le même ensemble d'entités en sélectionnant

Redo

Vous pouvez ajuster le délai du double-clic avec

Tools > Double Click Time
