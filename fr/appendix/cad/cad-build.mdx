---
title: "CAO > Construire"
---

Active la barre d'outils Build.

Cette barre d'outils donne un accès rapide aux fonctions de construction d'entités utilisées lors de l'étape de construction et de modification du modèle de l'analyse BEM Map3D Analysis > Go to CAD.

CAD > Build > FF Loop Construit un bloc polygonal 3D de type FF à plusieurs sommets, utilisé pour les excavations et les zones de matériaux alternatifs.

CAD > Build > DD Loop Construit un bloc polygonal de type DD à plusieurs sommets, utilisé pour l'exploitation tabulaire, les filons minces ou les plans de faille.

![Figure from page 116](/images/page-116-img-10.png)

CAD > Build > Grid Plane Construit un plan de grille où les résultats d'analyse sont calculés.

![Figure from page 320](/images/page-320-img-13.png)

CAD > Build > Grid Line Construit une ligne de grille où les résultats d'analyse sont calculés.

CAD > Build > Construction Lines Construit des lignes de construction pour définir l'emplacement détaillé des éléments souterrains tels que les excavations, les contacts, les structures, etc.

CAD > Build > Enter Point Saisit les valeurs de coordonnées d'un point.

CAD > Build > Offset Remaining Décale les points restants.

CAD > Build > Undo Point Annule la dernière sélection de point.

CAD > Build > Redo Point Rétablit la dernière sélection de point.

Appuyer sur la barre d'espace active automatiquement la dernière fonction de construction utilisée.
