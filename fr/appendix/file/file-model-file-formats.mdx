---
title: "Fichier > Formats de fichiers de modèle"
---

Les modèles peuvent être chargés à partir de plusieurs types de fichiers :

Le format Map3D-INP est un fichier de données ASCII modifiable dont l'extension est « .INP ». C'est le format de modèle Map3D recommandé. Toutes les fonctionnalités de Map3D sont prises en charge avec ce format.

Le format AutoCAD-DXF est un fichier d'échange de dessins très répandu dont l'extension est « .DXF ». Ce format est utile pour échanger des données de modèle avec d'autres logiciels de CAO.

Le format de fichier de points est un fichier de données ASCII universel dont l'extension est « .PNT ». Ce format est utile pour échanger des données brutes de modèle avec d'autres logiciels de CAO.

Les modèles provenant de fichiers différents peuvent être fusionnés. L'option de fusion

File > Open > Merge

se trouve au bas de la boîte de dialogue d'ouverture de fichier.
