---
title: "Fichier > Formats de fichiers de lignes de construction"
---

Les lignes de construction peuvent être enregistrées dans plusieurs types de fichiers :

Le format de fichier de points est un fichier de données ASCII universel dont l'extension est « .PNT ». Ce format est utile pour échanger des données brutes de lignes de construction avec d'autres logiciels de CAO.

Le format AutoCAD-DXF est un fichier d'échange de dessins très répandu dont l'extension est « .DXF ». Ce format est utile pour échanger des données de lignes de construction avec d'autres logiciels de CAO.

Les lignes de construction provenant de fichiers différents peuvent être fusionnées. L'option de fusion

#### File > Open > Merge

se trouve au bas de la boîte de dialogue d'ouverture de fichier.

Sujets connexes :

File > Open (Construction Lines).

File > Save As.
