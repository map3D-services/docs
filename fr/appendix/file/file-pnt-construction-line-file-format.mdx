---
title: "Fichier > Format PNT des lignes de construction"
---

Le format PNT est un fichier de données ASCII universel dont l'extension est « .PNT ».

Ce format est utile pour échanger des données brutes de modèle avec d'autres logiciels de CAO.

Les lignes de commentaire doivent commencer par un astérisque « * » en colonne 1.

Les lignes de construction sont stockées sous la forme d'une série de polylignes, comme suit :

**x1 y1 z1 3 colour x2 y1 z1 2 x3 y3 z3 2 x4 y4 z4 2**

xi yi zi représentent les coordonnées de chaque point. 3 indique que ce point est le début d'une nouvelle ligne. 2 indique que ce point est la continuation de la même ligne. colour spécifie le numéro de couleur utilisé pour afficher la ligne de construction.

Un total de 10 couleurs sont disponibles pour l'affichage.

Elles sont numérotées respectivement de 1 à 10, de 11 à 20, de 21 à 30, etc., de sorte que la même couleur soit affichée pour les numéros 1, 11, 21, 31..., 2, 22, 32..., etc.

Vous pouvez spécifier autant de points que vous le souhaitez pour chaque polyligne.

Les polylignes supplémentaires sont spécifiées en répétant la séquence (c'est-à-dire en commençant une nouvelle ligne avec le numéro 3).

Remarques

Utilisez des numéros de couleur différents pour représenter des regroupements logiques de lignes de construction (par exemple pour différents niveaux, sections ou unités d'exploitation logiques telles que le développement, l'abattage, etc.). Vous pouvez personnaliser ces couleurs avec

#### Tools > Custom Colours.

Comme il est facile d'activer et de désactiver l'affichage de numéros de couleur de lignes de construction précis, cela offre une méthode efficace pour travailler avec des données complexes de lignes de construction

#### View > Hide Cline Colours.
