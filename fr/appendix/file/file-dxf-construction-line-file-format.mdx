---
title: "Fichier > Format DXF des lignes de construction"
---

Le format DXF est un fichier d'échange de dessins AutoCAD dont l'extension est « .DXF ».

Ce format est utile pour échanger des données de modèle avec d'autres logiciels de CAO.

Les lignes de construction sont enregistrées sous la forme d'une série d'entités AutoCAD DXF POLYLINE.

Les lignes de construction peuvent être importées sous la forme d'une série d'entités AutoCAD DXF POLYLINE, LINE, 3DLINE ou 3DFACE.
