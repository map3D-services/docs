title: "Fichier > Format de fichier de modèle PNT"

Le format PNT est un fichier de données ASCII universel dont l'extension est « .PNT ».

Ce format est utile pour échanger des données brutes de modèle avec d'autres logiciels de CAO.

Les lignes de commentaire doivent commencer par un astérisque « * » en colonne 1.

Les blocs FF et les plans DD de Map3D sont stockés sous la forme d'une série de polylignes, comme suit :

**x1 y1 z1 3 colour mtype x2 y1 z1 2 x3 y3 z3 2 x4 y4 z4 2 x5 y5 z5 1 x6 y6 z6 1 x7 y7 z7 1 x8 y8 z8 1**

où **xi yi zi** représentent les coordonnées de chaque point,

- **3** indique que ce point est le début d'une nouvelle polyligne,

**2** indique que ce point fait partie de la base du bloc,

- **1** indique que ce point fait partie du sommet du bloc. Cet élément n'est utilisé que pour la définition de formes de blocs 3D.

**colour** spécifie le numéro de couleur utilisé pour afficher le bloc.

Un total de 10 couleurs sont disponibles pour l'affichage.

- Elles sont numérotées respectivement de 1 à 10, de 11 à 20, de 21 à 30, etc., de sorte que la même couleur soit affichée pour les numéros 1, 11, 21, 31..., 2, 22, 32..., etc.

**mtype** spécifie le type d'élément de frontière utilisé pour le bloc.

Pour les éléments tridimensionnels tels que les excavations, les zones de matériaux alternatifs, les chantiers remblayés, etc., il faut utiliser des éléments à forces fictives de type 1

CAD > Build > Block et CAD > Build > Block pour plus de détails.

- Il faut utiliser des éléments à discontinuité de déplacement de type 2 pour les excavations d'exploitation tabulaire, les fractures et les plans de faille

CAD > Build > DDLoop pour plus de détails.

Les éléments inactifs (98 pour les blocs 3D inactifs et 99 pour les plans DD inactifs) permettent d'afficher des éléments qui ne sont inclus qu'à des fins de visualisation et qui ne servent pas à l'analyse des contraintes proprement dite.

Les polylignes supplémentaires sont spécifiées en répétant la séquence (c'est-à-dire en commençant une nouvelle ligne avec le numéro **3** ).

#### Notes

Utilisez des numéros de couleur différents pour représenter des regroupements logiques de blocs (par exemple pour différents niveaux, sections ou unités d'exploitation logiques telles que le développement, l'abattage, etc.). Vous pouvez personnaliser ces couleurs avec

#### Tools > Custom Colours

Map3D combine automatiquement les blocs ayant le même numéro de couleur en formes complexes uniques.

Comme il est facile d'activer et de désactiver l'affichage de numéros de couleur de blocs précis, cela offre une méthode efficace pour travailler avec des données de modèle complexes
