---
title: "Fichier > Ouvrir > Répertoires récents"
---

Chaque fois que vous ouvrez un fichier de modèle ou un fichier de reprise, son répertoire de travail est enregistré pour un accès rapide lors d'une session ultérieure. Pour rouvrir l'un de ces répertoires, sélectionnez-le dans la liste.

Sujets connexes :

File > Open > Recent Files
