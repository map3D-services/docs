---
title: "Fichier > Ouvrir > Fusionner les géométries"
---

Si cette option est cochée, lors du chargement du nouveau fichier de modèle ou de lignes de construction, les données géométriques sont fusionnées avec les données géométriques actuelles.

Si cette option n'est pas cochée, lors du chargement du nouveau fichier de modèle ou de lignes de construction, les données géométriques remplacent (écrasent) les données géométriques actuelles.

Cela vous permet de construire votre modèle ou votre base de données de lignes de construction par petits morceaux et de les fusionner au besoin.

File > Open > Merge Materials.
