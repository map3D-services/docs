---
title: "Fichier > Ouvrir > Fusionner les matériaux"
---

Si cette option est cochée, lors du chargement du nouveau fichier de modèle, les données de matériaux du nouveau fichier sont fusionnées avec les données de matériaux actuelles.

Si cette option n'est pas cochée, lors du chargement du nouveau fichier de modèle, les données de matériaux du nouveau fichier remplacent les données de matériaux actuelles.

Cela vous permet de conserver vos modèles de matériaux dans des fichiers de données distincts, puis de les incorporer aux modèles au besoin.

Sujets connexes :

File > Open > Merge Geometries.
