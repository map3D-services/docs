---
title: "Fichier > Format de fichier de sortie PNT"
---

Le format PNT est un fichier de données ASCII universel dont l'extension est « .PNT ».

Ce format est utile pour échanger des données brutes de modèle avec d'autres logiciels de CAO.

Les lignes de commentaire commencent par un astérisque « * » en colonne 1.

Les surfaces sont stockées sous la forme d'une série de polylignes, comme suit :

x1 y1 z1 3 value1 x2 y2 z2 2 value2 x3 y3 z3 2 value3 x4 y4 z4 2 value4

xI yI zI représentent les coordonnées de chaque point.

3 indique que ce point est le début d'une nouvelle ligne. 2 indique que ce point est la continuation de la même ligne. valuei pour les entités géométriques, cette valeur représente le numéro de couleur de la surface

Pour les contours, elle représente la valeur du paramètre tracé en contours à chaque coin de la surface.
